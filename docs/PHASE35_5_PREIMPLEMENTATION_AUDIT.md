## 3. 도로 (명세 §30–31)

**원인**: 처음 실행하면 보이는 기본 월드는 `sampleTown()`(`app/actions.ts:276-295` → `world/sampleScene.ts`)이고, 그 도로 두 개는 폭을 직접 적은
**도로 객체**입니다 — 큰길 10 m(`sampleScene.ts:28`), 옆길 8 m(`:29`). 팔레트의 "2차로 도로"(`env.road`)는 정의 기본값 **7 m**(`objects/definitions/road.ts:21`).
차선 폭이라는 값은 어디에도 없고 폭 ÷ 차로 수로 그려질 뿐입니다(5.0 / 4.0 / 3.5 m).

**두 번째 원인**: 같은 "2차로 도로"라는 이름으로 서로 다른 두 시스템이 있습니다.

| | 도로 **객체** (`type:'road'`) | 도로 **네트워크** (`doc.roads`, 도로 도구·템플릿) |
|---|---|---|
| 폭 | 전체 시각 폭 = `width`(기본 7, 기본 월드 10·8) | 차도 `width` 7 m(`street`) + 보도 2 m × 2 = 11 m |
| 차선 폭 | width / lanes | width / lanes (3.5 m) |
| 갓길·중앙분리대 | 없음 | 없음 |
| 충돌체 | **없음**(`road.ts:39`, 지면 그대로) | 지형에 굽기(아스팔트·연석 0.15 m·경사 정리) |
| 노면 마찰(차량) | 잔디 μ 0.45 | 아스팔트 μ 0.9 |
| 노면 높이 | 지형 + 0.04 m | 지형 + 0.03 m |
| 차선 표시 | 노란 실선 1줄 0.20 m, 가장자리 ±(w/2 − 0.25) | 노란 복선 0.10 m |
| 교차로·곡선 | 없음(겹쳐 그리기) | `roads/intersections.ts`, `curve.ts`, 굽기 `bake.ts` |

- 두 종류는 연결이 안 됩니다(스냅은 네트워크만 봄). 맞닿으면 z-fighting, 연석 위로 덮임, 폭·표시·마찰이 갑자기 바뀝니다. 다리는 `convertLegacyRoads`(객체 → 네트워크, 폭 유지)뿐.
- 저장: `SCHEMA_VERSION` 7, 네트워크 형식 1, 이전 형식 변환은 `world/serialization.ts:259-412`의 `parseDocument` 안. 프로필 칸이 없으면 `defaultProfile()`로 채우므로,
  기본값을 바꾸면 옛 파일이 조용히 바뀝니다 → 기본값은 그대로 두어야 함.
- 위험: `sampleTown()`의 폭은 홍수 포장 셀·탐침 점을 통해 골든·회귀·결정론·충돌체·홍수·현상 시험에 들어갑니다 → `sampleTown()`은 고정하고, 기본 월드를 바꾸려면 새 빌더를 씀.

## 5. 구현 결정 (이 감사에서 나온 설계)

1. **인스턴스 모델은 새로 만들지 않고 `PhenomenonInstance`를 단일 출처로 씀**(저장 스키마 v5 그대로). 라이브러리·배치·명령어의 새 재난은 모두 이 목록의 항목.
   단일 폼(지진·홍수·바람)은 그대로 두되, 같은 내부 경로를 씀.
2. **결정론적 이름·키**: 실행되는 이벤트가 인스턴스 id를 가지고, 장부 키·결과 이름은 인스턴스 id 기반(`폭발 #2` 같은 표시 이름과 분리). 무작위 이벤트 id는
   결과 계산에 쓰지 않음.
3. **지진 다중**: `GroundMotionField`가 여러 지진을 동시에 가지고 가속도·속도·변위를 선형 중첩(지반을 선형 매질로 보는 근사, 문서화). 지진 하나일 때는 비트 동일.
4. **비 다중**: 영역이 있는 비는 인스턴스별 채널. 지도 전체 비는 지금처럼 하나(두 번째 전체 비는 날씨 변경 = 대체, 문서화).
5. **바람/태풍**: 전역 바람은 하나의 날씨 상태라 그대로(대체). 위치가 있는 **소용돌이(태풍·회오리 근사, Holland/Rankine 형상)**를 새 인스턴스형 바람원으로
   추가하고 전역 바람 위에 벡터로 더함 — 소용돌이가 없으면 바람장은 비트 동일.
6. **인스턴스별 제어**: 스케줄러에 `cancel(id)`(정지·제거), `pause/resume`(지속형 원천만: 화재·열원·물 유입·비·바람·소용돌이·지진은 시간 이동),
   이미 방출된 것(폭발 파면, 떨어진 운석)은 되돌리지 않음 — 표에 명시.
7. **도로**: `src/roads/crossSection.ts` 공통 단면(차로 수·차선 폭·갓길·중앙분리대·보도) + 프리셋(좁은 6 m / 일반 7 m = 현 `street` / 넓은 10 m).
   팔레트 "2차로 도로"는 네트워크 도로를 만들고, 첫 실행 기본 월드는 같은 프리셋의 네트워크 도로를 쓰는 새 빌더로 바꿈(`sampleTown()`은 시험용으로 고정).
   옛 파일의 도로 객체·네트워크 폭은 바꾸지 않음(명시적 변환만).
8. **건물**: `settings.simulation.structure.model: 'v1' | 'v2'`(없으면 v1 → 옛 결과 비트 동일). v2: legacy 상자 건물을 실행 시에만 모듈식으로 변환(문서는 그대로),
   구조 형식별 표(강성·강도·연성·접합·파괴 모드·잔해), 부재 단계(탄성·항복·소성·연화·파괴)와 접합부 힌지·해제, 블록 회전(피벗)·Rapier 몸체화, 홍수·운석을 부재 단위로,
   충돌체가 부분 붕괴를 따라감, 층별 변위 시각화. 새로 만드는 문서·새 기본 월드는 v2.
