# Phase 14 — 홍수 · 강우 · 물 시뮬레이션

> **교육·시각화용 근사 홍수 모델입니다.** 실제 침수 예측, 대피 판단, 건축물 안전 평가에 쓰는 검증된 수리 모델이 아니며, 실제 하천·해안 홍수의 정확도를 보장하지 않습니다. (홍수 폼·결과 패널에 같은 문구가 표시됩니다.)

## 2. Water Grid (지형 격자와의 연결)

- 지형: 201×201 **정점**(1 m 간격, 높이·Ground Type·Soil). 물: 200×200 **셀 중심** 격자 — 지형의 셀과 1:1, 같은 원점·좌표계(+X 동, +Z 남).
- 셀 바닥고 = 그 셀을 덮는 두 충돌 삼각형(대각선 (x1,z0)–(x0,z1))의 **정확한 평균** `(h00 + 2·h10 + 2·h01 + h11) / 6` → 셀 위 물의 부피 = 렌더링·물리 지형과 수면 사이의 부피.
- 셀 상태(TypedArray): 수심 `h`(Float64 — 질량 수지가 반올림 오차 수준으로 닫히도록), 면 유량 `qx`((nx+1)×nz), `qz`(nx×(nz+1)) — **엇갈림 격자**, 셀 중심 유속 `u, v`(Float32), 누적 침투량, 최대 수심, 침수 시간. 수면고 = 바닥고 + 수심, 젖음/마름 = 수심 임계값.
- 정적 레이어: Manning n², 침투 용량·토양 저류량, 배수 용량, 지표 종류, 장애물(건물, 두께 ≥ 0.2 m 조적 담장), 지붕 빗물의 배수 대상 셀(BFS), 도로 오브젝트(아스팔트로 취급).
- 메모리: 상태 + 정적 레이어 약 4.6 MB (40,000 셀).

## 3. 유동 모델과 선택 이유

**Local inertial 천수 근사** (Bates, Horritt & Fewtrell 2010, LISFLOOD-FP; de Almeida et al. 2012의 θ 가중):

```
q⁽ⁿ⁺¹⁾ = [θ·q + (1−θ)/2·(q₋ + q₊) − g·h_f·Δt·∂η/∂x] / [1 + g·Δt·n²·|q| / h_f^(7/3)]
h⁽ⁿ⁺¹⁾ = h + Δt·(Σq_in − Σq_out)/Δx
```

- 운동량 방정식에서 수면 경사(압력)·마찰·국부 가속도를 유지하고 대류 가속도를 뺀 형태. 범람원 침수처럼 느린 흐름에 적합하고, 완전 천수 방정식(리만 해법)보다 훨씬 싸서 40,000 셀을 실시간으로 돌릴 수 있습니다.
- **보존형 유한체적**: 모든 면 유량을 한 셀에서 빼고 이웃 셀에 더하므로 물이 생기거나 사라지지 않습니다.
- 높은 수면 → 낮은 수면으로 흐르고(∂η/∂x), 저지대에 모이며, 지형·건물을 따라 우회합니다(면 유량은 `h_f = max(η_L, η_R) − max(z_L, z_R)`이 있어야 생김).
- 한계: 대류항이 없어 초임계 흐름·도수·댐 붕괴 전면은 정확하지 않습니다(Froude 제한으로 안정만 보장).

## 4. 시간 적분과 안정성

- 솔버는 10 Hz(고정 6스텝마다, 0.1 s)로 호출되고, 호출 안에서 **적응형 서브스텝** `Δt_sub ≤ 0.7·Δx / max(√(g·h_f) + |u|)` (Courant 0.7)로 나눕니다. 정지한 깊은 물도 파속 √(g·h)로 제한(흐름이 없는 면 포함). 고정 수위 경계의 유령 셀 수심도 포함.
- 얕은 홍수는 호출당 1 서브스텝, 수 m 깊이는 2–4. 안전장치: 400 서브스텝.
- 마찰은 암시적(분모), θ = 0.9로 얕은 물의 수치 진동 억제, **Froude 제한**(|q| ≤ h_f·√(g·h_f)). 셀 중심 유속(오브젝트·표시·통계용)도 같은 한계 — 젖음 전선에서 거의 마른 셀의 수심으로 나눠 과대해지는 것을 방지(유량·질량에는 영향 없음).
- **음수 수심 방지**: 수심 갱신 전에 셀의 유출 유량 합이 보유량을 넘으면 유출 면만 비율로 줄임(보존형 제한기 — 줄어든 값이 이웃의 유입이 됨). 정확한 산술에서 h ≥ 0이며, 반올림으로 생긴 −1e−18 수준 값의 0 처리 효과는 수지 오차에 포함됩니다.
- 젖음/마름: 유동 임계 h_f > 0.1 mm, 젖음 표시 1 cm, 침수 0.1 m.
- 호출 시간 간격과 무관하게 안정: 1/60, 1/15, 0.5, 2 s로 같은 60 s를 계산해도 수심 차 < 5 cm, 질량 오차 < 1e−10 (테스트).
- 마찰 항의 `∛h_f`는 보간 표(오차 < 7·10⁻⁴; Math.cbrt는 솔버 시간의 40 %)로 계산 — Manning n 자체의 불확실성보다 훨씬 작고 결정론적.

## 5. 질량 보존

수지 항목(m³)을 발생 지점에서 바로 누적합니다:

| 항목 | 의미 |
|---|---|
| Initial Water Volume | 활성화 시점의 물(기준 수면 채우기 / 불러온 물 상태) |
| Rainfall Input | 강우율 × 셀 면적 × 시간 (지붕 위 비 포함 → 인접 도로 셀로) |
| Source Inflow | 공급원 유입 |
| Boundary Inflow / Outflow | 경계 면을 통과한 유입·유출 |
| Infiltration Loss / Drainage Loss | 침투(토양 저류), 배수(빗물받이) — 별개 과정 |
| Current Water Volume | Σ h·A |
| Numerical Conservation Error | 현재 − (초기 + 유입 − 유출) |

결과:
- 닫힌 경계, 굴곡 지형, 120 s: 상대 오차 < 1e−10 (경계 유출입 0).
- 모든 항이 있는 장면(강우·공급원·침투·배수·열린 경계): < 1e−10.
- 전체 시뮬레이션에서 강우 유입 = 강도 × 시간 × 지도 면적 (솔버 호출 간격 0.1 s 이내), 공급원 100 m³ ± 반올림.
- 브라우저 실행(샘플 도시, 150 s, 경계 유입 46,000 m³): 오차 7.6·10⁻¹⁰ m³ = **상대 1.6·10⁻¹⁴**. HUD·결과 패널에 실시간 표시.

## 8. 경계 조건

| 유형 | 동작 |
|---|---|
| Closed | 벽 — 유입·유출 없음 (질량 정확히 보존) |
| Open | 지형이 같은 경사(최소 0.2 %)로 이어진 것처럼 자유 유출, 유입 없음 |
| Fixed Water Level | 경계 밖에 일정한 수면 — 유입·유출 모두 (바다·강) |
| **Auto (기본값)** | 기준 수면(terrain `waterLevel`)이 있고 경계 일부가 그보다 낮으면 그 수위의 Fixed Level, 아니면 Open |

- 프리셋 연결: **Coastal**(기준 수면 0 m) → 남쪽 해안 경계가 자동으로 고정 수위 0 m, 나머지는 열림. 새 **Lowland 범람원** 프리셋(서→동 하천, 기준 수면 −0.6 m) → 하천이 닿는 동·서 경계가 고정 수위, 북·남은 열림. Flat/Hills/Valley → 모두 열림.
- **기준 수면 vs 동적 수심**: 기준 수면은 정적인 지형 설정(편집기의 파란 평면)이고 스스로 흐르지 않습니다. 물 모델은 활성화 시 "고정 수위 경계와 연결된 기준 수면 아래 지면"만 그 높이까지 채우고(설정으로 끌 수 있음) 이후 수심은 솔버가 계산합니다. 인스펙터는 두 값을 따로 표시합니다.

## 9. 오브젝트 상호작용

**WaterPhysicsAdapter** (모든 자유 물체: 차량, 사람, 쓰러진 가로등·나무, 파편):
- 부력 `F_b = ρ_w·g·V_eff·(잠긴 높이 비율)`, 항력 `F_d = ½·ρ_w·C_d·A_잠김·|u−v|·(u−v)`, 둘 다 잠긴 부분 중심에 작용 → 들림·기울어짐·미끄러짐·떠내려감이 Rapier 접촉·마찰에서 나옵니다(스크립트 없음).
- **접지력 감소**: 부력이 접촉면의 수직력을 줄이므로 마찰력(∝ 수직력)이 자동으로 감소 + 젖은 지면 마찰 ×0.8.
- 가벼운 파편의 강성 문제: 한 스텝에 상대속도를 뒤집지 않도록 항력 상한. 정지한 물 속에서 잠든 물체는 깨우지 않고 정적 부력만 유지(수위가 1 cm 이상 변하거나 흐름이 생기면 깨움).

**차량**: 밀폐 차체의 배수체적 = 경계상자 × (0.05 + 0.55·(1 − 실내 침수율)). **수심이 기준에 도달했다고 떠오르지 않음** — 부력/무게 ≥ 1이 되어 실제로 들릴 때만 `FLOATED` 기록. 무게·크기에 따라 다름(테스트: 무거운 트럭은 승용차가 뜨는 0.9 m에서 바닥에 남음). 바닥(0.35 m) 위로 물이 차면 실내가 시간에 따라 침수(τ 120 s) → 부력 감소, 실내·전장 손상(얕은/깊은/매우 깊은 침수 단계), 흐름에 밀리면 `MOVED`(원인 hydrodynamic/buoyancy).

**사람**: 안정성 비 = max(항력 / (μ·(무게 − 부력)), 항력 모멘트 / ((무게 − 부력)·발 지렛대)). ≥ 1이면 넘어짐, 0.6–1이면 균형 여유가 서서히 소진. 문헌의 성인 h·v 불안정 범위(약 0.6–1.2 m²/s)와 같은 규모(테스트: h·v ≈ 1에서 불안정, 정지한 0.3 m 물에서는 서 있음). 넘어진 뒤 흐름에 실려 감. 물 속 이동 저항은 항력(상대속도 기준)으로 나타납니다. **안전·생존 여부는 예측하지 않습니다.**

**건물** (특정 수심 붕괴 규칙 없음):
- 침수 깊이: 외곽 둘레 표본점(2 m 간격)의 최대/평균, 침수 지속시간.
- 실내 수위가 외부를 지연 추종(문틈 τ 600 s, 저층 창 파손 후 90 s).
- 마감재·내부 손상: 깊이–피해 곡선 √(d_in/6 m)에 노출 시간(τ 1200 s)으로 접근 — 최대 DAMAGED.
- 외피 부품(창문, 외부 설비): 수면 아래에서 수두 차 + 동압 vs 바람 설계압 × 3 × 산포(±35 %, 오브젝트 시드).
- 구조: 횡하중 `F = ½ρg(d_out² − d_in²)·B + ½ρ·C_d·v²·d_out·B` vs 구조 형식의 횡강도 `c_y·W`(지진 모델과 같은 c_y). 50 % 초과부터 손상 누적, 지수 1 → 붕괴(잔해는 물을 막지 않음). 무거운 RC 건물은 사실상 도달하지 않고, 가벼운 주택은 깊고 빠른 물에서 가능.

**인프라**: 가로등·간판 — 잠긴 부분 유수 모멘트 vs 바람 설계 기초 모멘트. 담장 — 양쪽 수심 차의 정수압 모멘트 ρg·Δ(d³)/6 + 직교 유속 항력 vs 설계 모멘트(테스트: 한쪽 1.4 m 물에서 붕괴 → 물이 통과, 0.4 m에서 유지). 도로 — 0.15 m 침수, 0.3 m 통행 곤란, 2 m/s 이상 지속 유속 세굴.

## 10. 지면 마찰 개선 (Phase 12 문제)

- 이전: 차량·사람 마찰 = **시작 위치** 지표. 이제 `GroundContactSystem`이 자유 물체마다 6 Hz(개체 순서로 분산, 결정론적)로 **현재 위치**의 Ground Type을 조회해 바뀌었을 때만 `PhysicsEngine.setFriction`(Rapier `collider.setFriction`, **충돌체 재생성 없음**)으로 갱신. 물 ≥ 5 mm면 ×0.8.
- **회귀 분석**: 균일 지표·물 없음이면 계수가 절대 바뀌지 않으므로 호출 0회 → Phase 11 골든 3종 비트 일치. 지표가 칠해진 지형에서 물체가 다른 지표로 이동하는 경우에만 결과가 달라집니다(의도된 개선). Phase 13 커밋에서 생성한 Coastal(모래 칠함) 바람+지진 픽스처도 비트 일치 — 8 s 동안 지표 경계를 넘은 자유 물체가 없음.

## 11. 피해 기록 통합

`DamageEventRecord`에 추가(기존 바람·지진 필드 유지): `hazard: 'flood'`, `waterDepth`(m), `flowSpeed`(m/s), `exposure`(s, 0.1 m 이상), `force`(적용 하중 N), `state`(기록 직후 피해 상태). 새 이벤트: `INUNDATED`(단계 = response), `FLOATED`, `SCOURED`. 원인: hydrostatic, hydrodynamic, buoyancy, inundation, scour. 물에 실려 간 물체의 충돌도 hazard flood. ## 16. 복합재난 호환성

- 스케줄러: 물 이벤트는 자기 채널을 쓰므로 바람·지진과 동시에 진행. 정착 시간은 물 이벤트가 있으면 60 s.
- 힘: 같은 강체에 풍항력 + 지반 관성력 + 부력·수항력이 합산. 피해: 손상 채널별 health를 `min()`, 상태를 `worst()`로 합성 — 서로 덮어쓰지 않음. 파편·충돌의 hazard 태그 유지.
- 지진·바람으로 붕괴한 건물·담장은 물 격자에서 장애물이 제거되어 물이 잔해 사이로 흐름. 강우는 태풍의 비 시각 효과와 합쳐짐.
- 테스트: 태풍 + 폭우 + 지진 + 물을 한 번에 실행 — 세 재난의 이벤트·지표가 모두 기록되고 NaN·충돌 없음.

## 18. 결정론

- 같은 지형 + 월드 + 물 이벤트 + 시드 + 시간 간격 → 비트 단위로 같은 수심 배열(SHA-256), 피해 이벤트, 최종 포즈(Rapier 포함 테스트).
- 솔버는 난수를 쓰지 않고 순회 순서가 고정. 부품 용량 산포는 오브젝트 시드 + 부품 id 해시(시뮬레이션 RNG와 독립). `Math.random()` 사용 없음.

## 22. 과학적 한계

- 교육·시각화용 근사 모델이며 검증된 수리 모델이 아닙니다. 실제 침수 예측·대피 판단·건축물 안전 평가에 쓰지 마십시오.
- Local inertial 근사: 대류 가속도 없음 → 초임계 흐름, 도수, 댐 붕괴 전면, 건물 주변 와류·후류는 부정확. 1 m 격자보다 작은 지형(연석, 배수로)은 표현되지 않음.
- 침투는 버킷 모델(지하수·포화 지표류 없음), 배수는 용량 상한만(하수관망·역류·맨홀 범람 없음).
- 물체는 물을 밀어내지 않음(배수체적·후류가 물에 반영되지 않음), 건물 내부 유동·지하 공간 없음, 잔해에 의한 막힘 없음.
- 피해 모델(깊이–피해 곡선, 횡하중 용량, 안정성 비)은 상대적 경향을 위한 근사 매개변수이며 특정 건물·사람에 대한 판정이 아닙니다.
- 강우는 공간적으로 균일(영역 내), 증발·눈 녹음 없음. 파랑·조석·해일은 고정 수위 경계로만 근사.

## 23. Phase 15 복합재난 준비사항

- **상호작용 지점이 이미 분리됨**: 재난별 health 채널(`seismic`, `flood`) + `worst()`/`min()` 합성 → 복합 피해 공식(예: 지진 손상 후 홍수 하중 용량 감소)을 `floodHealth`·용량 계산에 손상 지수를 곱하는 식으로 추가 가능.
- 바람 → 물: `WaterForcing`에 수면 바람 응력(wind setup, 파랑) 항을 추가할 자리(`env.wind`를 솔버가 읽기만 하면 됨).
- 지진 → 물: 붕괴 건물의 장애물 제거는 구현됨. 액상화(`LiquefactionModel`의 지하수위 입력)를 홍수 침투 저류량·수위와 공유 가능. 지반 변형(침하)은 `WaterField` 바닥고 재계산으로 연결.
- 물 → 지진: 침수된 기초의 지지력 저하를 `SeismicEntityState.bearing`에 반영할 수 있음.
- 잔해 → 물: 파편이 셀을 막는 기능은 `WaterField.blocked`/장애물 목록에 동적으로 추가하는 방식으로 확장.
- 스케줄러·시스템 순서·hazard 태그·결과 패널 필터·CSV/JSON이 재난 수와 무관하게 동작하므로 새 재난(화재 등)도 같은 패턴으로 추가 가능.
