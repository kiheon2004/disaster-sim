# Phase 31 — Variable Gravity Engine

중력의 크기·방향·공간 분포·시간 변화를 사용자가 정하면, 그 중력장 **g(x, t)** 하나를 모든 주요 물리 시스템이 같은 방식으로 읽습니다.
물체가 떨어지거나 떠오르고(Rapier), 구조물의 자중·적설 하중이 바뀌어 부재가 파괴되고(구조 엔진), 물·용암·흙·공기 기둥·대류·화재·
화산 분출물·운석이 각 모델의 적용 범위 안에서 반응하는 단계입니다.

> **사용자 정의 가속도장 실험입니다.** 실제 천체의 중력장 계산이 아니고, 일반상대론을 계산하지 않으며, 실제 천체 환경이나 안전 판단에 쓸
> 수 없습니다. 구조 모델은 인증된 FEM이 아닙니다.

## 2. Phase 30 감사 잔여 문제

### 2.1 R1 — 눈만으로 지붕이 무너지지 않던 문제: **해결**

원인: 지붕 피복 부재(`role: 'roofing'`)가 구조 그래프에서 비구조(`structural = 0`)라 용량·이용률 검사가 없었습니다. 눈 하중은 받침 부재로만
전달됐고, 창고 보는 27 kPa에서도 이용률 0.77이었습니다.

해결(임계값을 낮추지 않음, 기존 부재 강도·하중 경로 재사용):

- **걸쳐진 지붕 패널**(보·벽·기둥이 받치는 패널, 경사 패널 전부)을 축약 지붕 시스템(피복 + 모델에 없는 중도리·서까래)으로 봅니다.
  특성 용량 = **1.5·(자중 + 1.0 kPa·평면 면적)** (`structure/capacity.ts`): 지붕은 계수 하중 1.2·D + 1.6·S ≈ 1.5·(D + S)로 설계되고 지붕
  활하중·설계 적설 1.0 kN/m²(KDS 41 10 15 지붕 활하중, 국내 지상 적설 0.5–2.0 kN/m²)를 씁니다. 엔진의 평균/특성 강도비 OVERLOAD = 1.25와
  합치면 패널은 ≈ 1.9·(D + 1 kPa)에서 파괴: 주택(목조 박공) 총하중 2.74 kPa, 창고(강구조 박공) 2.60 kPa.
- 슬래브 위에 놓인 평지붕 피복은 마감층이라 검사하지 않습니다(슬래브가 하중을 받음) — 아파트·사무동·공장·타워 평지붕.
- 검사는 지붕 패널에 위험원 표면하중(적설·화산재·폭탄 등, `CollapseModel.addLoad`)이 실리거나 중력 실험이 있을 때 켜집니다
  (`solver.roofCheck`) — Phase 31 점검(M1)에서 화산재도 눈과 같은 하중이면 같은 판정이 되도록 고쳤습니다(이전에는 눈·중력만). 표면하중이
  없는 장면은 그대로입니다(§41; 화산재 장면은 이용률 배열만 달라짐 — `docs/PHASE31_AUDIT.md` §6).
- 휨으로 파괴된 패널은 **자기를 받치던 부재 사이로** 떨어집니다(그 받침 위에 얹히지 않음) — 바닥·지면에 떨어져 잔해가 되고, 낙하 중
  외벽 피복·창을 부술 수 있습니다. 받침 부재(보·기둥)는 패널 하중이 빠져 하중이 줄어듭니다(재분배).
- 파괴 원인: 해저드 `climate`이면 `snowLoad`, `gravity`이면 `gravityLoad`.

검증(자동): `src/structure/roofGravity.test.ts` 15개 — 요구 1–10(정상 중력 무/경/중 적설, 고중력 + 적설, 고중력 + 얼음, 저중력 같은 질량,
부분 파괴(국소 중력 비율), 재분배, 잔해, 붕괴 후 질량·에너지 장부) + 용량 정의, k = 1 비트 동일, 1.5 g 선형 하중, 4 g 골조 붕괴, 저중력
파편 처리. 시뮬레이션: `src/simulation/gravity/roof.sim.test.ts` 4개(Phase 30 기후 적설로 정상 중력 붕괴, 같은 눈이 중력 램프로 붕괴, 달
중력에서 유지). Chrome: §45 항목 22–23 (`docs/verify/gravity/23-roof-failure-*.png`).

### 2.2 R2 — 붕괴 지붕의 눈이 즉시 지면으로: **개선**

- 지붕 패널이 파괴되면(어떤 해저드든) 그 패널 몫의 지붕 눈(M·a_i/A_살아있는 지붕)이 지붕 저장소에서 빠져 **묶음(packet)**이 됩니다
  (`ClimateWorld.splitStore`).
- 묶음 질량은 붕괴 모델에서 그 부재가 운반하는 질량(`CollapseModel.carry`)입니다: 낙하 블록 질량, 아래 층과의 충돌, 얹힌 동안의 정적
  하중에 포함되고, 구조 질량 장부·잔해 더미 질량에는 들어가지 않습니다.
- 부재가 지면에 정착하거나 파편으로 나가거나 건물이 전체 붕괴하면 묶음을 그 위치 바닥 셀에 내려놓습니다(`depositPacket`). 아래에 격자
  셀이 없으면(월드 밖) 질량·엔탈피를 경계 유출(`water/energy.boundaryOut`)로 기록합니다 — 목적지에 기록한 뒤에만 완료(Phase 31 점검 H2).
  바닥에 얹혀 있는 동안은 묶음으로 남고(실내 눈 — 상변화 없음), 얹힌 부재의 무게와 함께 수신 부재의 하중이 됩니다(점검 M2).
- 묶음은 질량·엔탈피·얼음분을 그대로 유지하고(낙하 수 초 동안 상변화 없음 — 근사), 저장량 합계에 포함되어 물·에너지 장부가 닫힙니다.
  같은 눈이 지붕과 지면에 동시에 있지 않고, 잠열이 두 번 계산되지 않습니다.
- 남은 지붕 눈의 하중은 서 있는 패널 면적에만 나눕니다.

### 2.3 R3 — 영하 기준 온도의 유입수: **수정**

범위: 기준 온도가 0 °C 아래인 열 실행에서 Phase 14 유입수(비 이벤트, 수원, 고정 수위 경계)가 기준 온도(과냉각)로 들어와 c_w·ΔT/L_f만큼
즉시 얼었습니다(−10 °C: 12.5 %). 가변 중력은 경계 유입량을 √g만큼 키우므로 이 효과가 같은 비율로 커집니다(증폭 확인).

수정: 그런 실행에서 액체 유입수는 **융점(0 °C)**으로 들어옵니다(`WaterField.inflowExcess`, 수원·비: `applySources`, 지도 가장자리 유입:
`advectHeat`). 들어온 엔탈피는 물 경계 열로 기록(`heatOut`의 음수 — 열 장부 `lost.water`는 물이 가지고 나간 순 열). 기준 온도가 0 °C
이상이면 0이라 기존과 비트 단위로 같습니다. 테스트: `residual.sim.test.ts` R3 2개(−10 °C 수원, 3 g).

### 2.4 R4 — 극소량 덮개 에너지 이전: **확인(재현 없음)**

저중력 + 얇은 물막(일사), 고중력 + 얇은 물막, 무중력 + 얼음(가열), 반전 중력 + 얇은 눈, 빠른 중력 펄스 + 융설을 40 s씩 실행: 안전망 작동
0회(`floorClamps`), 덮개 온도 범위 정상, 물·에너지·열 장부 잔차 < 10⁻⁸. 중력은 덮개 에너지 경로에 들어가지 않으므로(압밀 과하중과 날림
눈만 g 의존) 새로운 불안정은 없습니다. 테스트: `residual.sim.test.ts` R4 5개.

## 4. 중력장 아키텍처

g(x, t) = G(t) + Σ 국소 중력원(x, t).

- `GravityField.prepare(t)`가 시간 의존 스칼라를 한 번 계산하고, `sample(x, y, z, out)`은 할당 없이 벡터를 씁니다. 국소 중력원이 없으면
  `uniform = true`이고 표본은 G 그대로(빠른 경로).
- 표본 정보: 가속도 벡터·크기(호출자가 계산)·위치·시각(필드 준비 시각)·중력원(전역 소유 실험 index, 국소 비트마스크 — `attr`)·
  적용 범위(`outlook.supportOf`)·제한 경고(`limits`).
- 단위: m/s², kg, N, J, s. **질량은 절대 바뀌지 않습니다** — 무게 = m·g(x).
- 퍼텐셜: 전역 Φ = −G·x, 방사형 Φ(r) = −∫_r^R S·a(r')·w(r') dr'(닫힌 형식 + 감쇠 구간 Simpson). 영역 중력원이 작동하면 `potentialDefined =
  false`(경계에서 회전 성분이 있는 비보존장) — 퍼텐셜을 만들어 내지 않고 경로 일만 기록합니다.

## 5. 중력 모드

| 모드 | 스펙 | 비고 |
|---|---|---|
| 지구 | magnitude = 9.81, 아래 | 실험 없음과 비트 단위로 같음(테스트) |
| 저·고중력 | magnitude | 달 1.62, 화성 3.71(크기만), 1.5 g₀, 2 g₀, 램프 3 g₀ |
| 무중력 | magnitude = 0 | 물체는 관성 운동, 지면 솔버 정지 |
| 반전 | direction (0, 1, 0) | vector 전이는 0을 지남, rotate 전이는 수평을 지나 크기 유지 |
| 수평·임의 방향 | direction 벡터(정규화) | rotate: 대원 위 회전(slerp) + 크기 보간 |
| 국소 영역 | region: 구 / 수직 기둥, add / replace | replace: 영역 안 총 중력을 그 벡터로(국소 무중력 등) |
| 방사형 | radial: 연화 역제곱 / 선형 / 일정, ±S | 연화 ε > 0 필수, 중심 최대 0.385·S·r₀²/ε² ≤ 50 m/s² |

입력 한계: |g| ≤ 50 m/s²(≈ 5 g — 구조·유체 모델 범위 밖, 극한은 Phase 32), 지속 1 s–6 h, 반경 1–400 m, 중력원 ≤ 8개.

## 6. 시간 프로파일

blend s(t)는 t의 순수 함수입니다(스텝 크기와 무관하게 같은 값 — 테스트). smooth는 5차 smootherstep(양 끝 기울기·곡률 0 → 정지 물체에 충격
없음), pulse는 가장자리 램프(0이면 사각). restore + linear/smooth는 창 끝에서 같은 램프로 되돌아옵니다(대칭 사다리꼴). hold는 마지막 값을
유지합니다. 크기뿐 아니라 방향도 같은 s로 바뀝니다. 중력 변화가 계에 에너지를 넣거나 빼는 양은 장부의 W_field(§28)입니다.

## 7. 복수 중력원

- 전역: 창이 열려 있는 실험 중 **가장 늦게 시작한 것의 전역 부분이 기본 중력을 대체**합니다(더하지 않음 — 중복 중력 없음). 각 실험은
  시작 직전에 작용하던 전역 벡터에서 출발합니다(시작 시각에 고정 — 필드 연속).
- 국소: 열린 실험들의 중력원을 **정렬된 순서**(매개변수로 만든 정규 키)로 더하고, replace 영역을 그 뒤에 정규 순서로 적용합니다.
- 실험·중력원을 추가한 순서는 부동소수 합에 영향을 주지 않습니다(비트 단위 테스트, 객체 ID·이벤트 순서 독립 테스트).

## 8. Rapier 통합

- 균일 부분 G는 **Rapier 월드 중력**(`setGravity`)으로 — 바뀔 때만 한 번 씀. 균일 무게를 거는 곳은 Rapier뿐입니다.
- 공간장은 동적 물체마다 **차이** m·(g(x) − G)만 ForceLedger 소스 `gravityField`로(중복 거부 장치 그대로; 테스트에서 duplicates = 0).
- 정적·운동학적 물체(건물·고정 물체·서 있는 나무)는 움직이지 않습니다 — 무게는 구조 모델 하중으로 작용(§13).
- 깨우기: 전역 벡터가 마지막 깨우기 이후 max(|G|, 0.05 g₀)의 2 % 넘게 바뀌면 모든 동적 물체를 깨웁니다(1 g에서 잠든 물체가 0 g에서
  공중에 멈춰 있지 않도록 — 반전 중력 테스트). 국소장 힘은 장이 변하는 동안에만 깨움(일정한 장에서 잠든 물체는 그 장과 평형).
- 접촉력 이벤트 임계값을 max(|G|, g₀)에 맞춰 갱신 — 3 g에서 정지 접촉을 충돌로 보고하지 않음.
- 무중력에서 물체는 속도를 유지합니다(선형 감쇠 0.05/s만 — Phase 0 설정). 지형 휴면 처리(PoseSync)는 그대로.

## 9–12. 물체 운동 · 접촉 · 차량 · 사람

- 자유낙하: 정지에서 시작한 선형 동역학이라 변위가 g에 정확히 비례(달/지구 비 = 1.62/9.81, f32 위치로 10⁻⁶ 상대 오차), ½gt²(1 − ct/3)와
  2 % 이내. 무중력·반전·수평 이동, 국소 우물(차이 힘만 — 중력 중복 없음) 테스트.
- 접촉·마찰: 마찰 계수는 바뀌지 않고 Rapier 접촉이 법선력을 계산합니다(경사·가속·복수 접촉 포함 — N = mg를 따로 쓰지 않음). 검증:
  0.3 g 수평 + 1 g 하향에서 주차된 차는 버티고, 같은 수평 + 달 중력에서는 미끄러짐(시뮬레이션·Chrome).
- 차량: 현재 모델은 강체(구동·제동 모델 없음) — 접지 하중·미끄러짐·점프·낙하·충돌은 Rapier가 같은 중력으로 처리. 충돌 피해 정규화
  (m·9.81·30)는 지구 기준 유지(C).
- 사람: 직립 캡슐(회전 잠금) 그대로 — 낙하·부유·반전·밀림. 전도 에너지(폭발·분출물)와 흐르는 물속 안정성은 국소 하향 중력 사용.
  생리 반응(혈압·의식·전정기관)은 Phase 34.

## 13–14. 구조 자중 · 붕괴와 재분배

- 하중은 지구 무게(질량 × 9.81, 그래프 `weight`, 표면 하중 `extra`)로 저장하고, 부재별 **중력 비율 k = g_down/g₀**(`solver.kM`)이
  `collect`에서 자기 무게와 표면 하중(적설·얼음·화산재·얹힌 잔해)에 곱해집니다. 하중·몫·검사는 실제 뉴턴. k = 1이면 Phase 25 해법과
  비트 단위로 같음(테스트).
- 균일장은 건물당 k 하나(빠른 경로), 국소 중력원 반경 안 건물은 부재 중심마다 표본(부분 지붕 파괴 가능). 비율이 1 % 넘게 바뀔 때만
  재적용(`K_QUANTUM`), **장**이 그 부재의 마지막 적용 이후 한 스텝에 0.05 g₀ 넘게 바뀌었으면 급변(동적 증폭 Ω). 붕괴 모델은 스텝당 40동까지
  새로 만들고(1000동 마을의 일회성 비용 분산), 실험 계획이 닿는 건물을 위치 순서로 미리 준비하며, 모두 준비될 때까지 어느 건물에도 비율을
  적용하지 않아 모든 건물이 같은 스텝에 반응합니다(점검 M3: 순서·ID 무관, 모델 없는 N동은 ⌈N/40⌉ − 1 스텝 늦게 함께).
- 용량은 바뀌지 않습니다(지구에서 설계됨). 중력이 2배면 자중은 2배이지만 응답은 연결부 파괴·하중 경로 전환·지지 상실로 비선형입니다
  (아파트는 4 g에서 연결부 57개가 끊기고도 다른 경로로 서 있음, 사무동·타워는 4 g에서 붕괴).
- 낙하 블록은 건물 위치의 하향 중력으로 떨어지고(정확한 등가속도식), g_down < 0.05 g₀이면 블록 대신 강체 파편으로 나갑니다(Rapier가
  실제 장으로 움직임). 잔해·파편은 같은 장을 따릅니다(별도 기본 중력 없음).
- 원인 기록: 중력 비율 변화가 시작한 파괴는 해저드 `gravity`, 원인 `gravityLoad`; 첫 파괴는 마일스톤.
- 지진 동시 발생: P-Δ 항이 단계 하향 비율을 따름, 기초 전도 저항(자중)도 같음. 설계 항복 강도는 지구 기준.

## 15. 지형·지반

지형 자체는 바뀌지 않습니다. 사면 안정(무한사면 FS, 마개 FS, Culmann 벽)은 단위중량 γ·γ_w가 단계 하향 비율을 따르고(점착력은 그대로
— 저중력에서 더 안정, 고중력에서 불안정; 마찰만 있는 건조 사면은 g와 무관: 해석해 테스트), Newmark 임계가속도 (FS − 1)·g·sinβ,
런아웃의 구동력·Coulomb 마찰은 g를 따르고 Voellmy 난류항은 지구 g(보정된 거칠기). 지반 지지력 표는 지구 기준(C).

## 16–17. 홍수와 무중력 유체

- 얕은 물 솔버(`WaterSolver`)는 균일장의 하향 성분 g_n으로 수면 경사 가속, Froude 한계, CFL(√(g h)), 경계면을 계산하고, 수평 성분은
  **기울어진 기준면**으로(지진 관성력과 같은 항: +h·g_h) 들어갑니다. 공간장에서는 셀마다 성분을 표본(면은 두 셀 평균, CFL은 최대 g_n)하고,
  깊이 적분 압력 ½·g·h²의 ∇g 항 −½·h²·∂g/∂x도 넣습니다(점검 X3: 무거운 기둥 아래의 물이 빠져나감, 평형 g·h² 일정).
- 바닥 마찰은 지구 g를 유지합니다: Manning n은 g₀에서 보정되어 √g가 숨어 있고(n ∝ √(g₀/g) — 고정 Darcy 거칠기), 그래서 g·n² = g₀·n².
  덕분에 Froude 상사가 성립: 4 g에서 t초 뒤 댐 붕괴 전선 = 1 g에서 2t초 뒤 전선(1 m 셀 이내 — 테스트).
- 부력·정수압(건물 측압, 창 수압, 벽 모멘트), 흐르는 물속 사람 안정성은 국소 하향 중력. 부력/무게 비는 g와 무관(달 중력에서도 같은 차가
  뜸 — 테스트).
- 하향 중력이 0.05 g₀ 미만이면 물을 **그 자리에 정지**시킵니다(3D 액체·구형 물방울을 만들지 않음, 정지 시간 보고). 기울기 > 0.3이면
  제한 표시. 수평 0.01 g₀에서 그 기울기로 놓인 물은 정지 상태 유지(평형 테스트).

## 18–19. 대기압과 적용 범위

공기 기둥 모델(Phase 29)은 기둥 질량 σ가 상태량입니다. 중력이 바뀌면 p_s = σ·g, 척도 높이 R·T/g, 층 몫·기준면 환산이 바뀌고 질량은
그대로(2 g에서 같은 질량의 기압 2배 — 테스트·Chrome). 균일장의 하향 성분만 사용(국소 중력원은 해석하지 않음 — 제한), 하향 중력이 없으면
마지막 유효 g로 정지(정지 시간 보고 — 정역학 기둥이 정의되지 않음). 빠른 중력 변화의 음파·압력파는 계산하지 않음(준정역학). 대기 실험이
없으면 HUD는 기둥 무게 추정 p₀·g/g₀를 **추정**으로 표시합니다. 대기권 밖 운석 진입은 지구(행성) 중력·대기 유지.

## 20–21. 열대류 · 화재와 연기

- 자연대류: Ra ∝ |g| (Nu 상관식은 무차원 — 범위 안에서 유효): 난류 h ∝ g^⅓, 무중력에서 0(수직판은 전도 한계 0.825²·k/L만). 전도·복사·
  강제대류(바람)는 그대로. 장부 경로는 같아 중복 이동 없음.
- 공기층 환기·상승기류 √(g·H·ΔT/T), 화재 구획 환기 유입(Rockett), 연기 교환(√(g h ΔT/T))은 하향 비율(반전·무중력에서 0 — 연기가 저절로
  위로 오르지 않음). Heskestad 화염 높이 ∝ g^−⅕(0.05 g₀ 아래는 그 값으로 유지·제한), Thomas 화염 기울기는 g^⅓. 연소 반응 자체(연료 소모·
  발열)는 그대로 — 미세중력 화염 화학은 없음(제한 표시).

## 22–23. 눈·얼음·강수·침강

눈·얼음 질량은 중력과 무관하고 무게만 바뀝니다. 지붕 적설 하중(§2.1), 보고 압력은 현재 g(매초), 수관 파단은 무게로 비교, 압밀
과하중 W·g/g₀(2 g에서 과하중 항 2배 — 테스트), 날림 눈 문턱 u_t·√(g/g₀)·수송 1/g(하향 중력 없으면 날림 눈 없음). 강수는 기존처럼
즉시 도달하는 표면 공급이라 낙하 시간을 계산하지 않습니다(시각 입자만 g로 떨어짐) — 하향 중력이 없어도 기후 강제로 공급됨을 제한
표시합니다. 화산재 침강: Stokes ∝ g, Newton ∝ √g(셀별 캐시에 g 포함), 무중력에서 0.

## 24–27. 화산 · 운석 · 폭발 · 도로

- 화산: 용암 빙엄 흐름 구동력 ρ·g·sinθ(임계 깊이 τ/(ρ g sinθ) — 저중력에서 더 깊어야 흐름), 고화 퇴적·지형 변화는 같은 경로, 화산탄은
  발사 시각의 균일장 벡터로 비행(비행 중 장 변화는 따라가지 않음 — 기록), 화산재 침강 위와 같음.
- 운석: 진입(세계 위)은 지구 중력·대기, 세계 안 탄도(정확한 포물선)·크레이터 중력 영역(π₂ = g·a/U², R ∝ π₂^(−μ/(2+μ)), 원심기 자료로
  g 범위에서 검증된 관계)·분출물 비행은 시작 시각의 하향 g. 충돌 에너지는 탄도 끝 속도(중복 가속 없음). 0.05 g₀ 아래에서 강도 없는
  표적은 중력 한계가 없어(R → ∞) 0.05 g₀로 계산하고 경고(제한).
- 폭발: 에너지·압력파는 바뀌지 않음. 간접 효과(사람 전도 에너지, 잔해 낙하, 구조 응답)는 g를 따름. 빠른 압력파(Phase 24)와 느린
  대기압(Phase 29) 구분 그대로.
- 도로: 중력 의존 물리 없음. 차량 접지·낙하 잔해·구조 붕괴·지반 이동은 위 경로. 원본 도로망 데이터는 바뀌지 않음(지문 테스트).

## 28–29. 에너지 · 운동량 장부 (`gravity/ledger.ts`)

스텝 k마다 장을 tₖ로 준비하고(물리 스텝 전), 물체마다(질량 m, x₀ → x₁, v₀ → v₁, 그 스텝에 작용한 g = g(x₀, tₖ)):
W_g += m·g·Δx (적분기가 실제로 간 경로의 일), ε += ½·m·dt·g·(v₁ − v₀) (반암시적 오일러가 운동에너지로 바꾸지 않은 몫, O(dt)),
J_g += m·g·dt, W_field += m·(Φ(x₀, tₖ) − Φ(x₀, tₖ₋₁)) (장 자체의 변화, 스텝 전에 기록), W_moved += m·(Φ(x′, tₖ₋₁) − Φ(x, tₖ₋₁)) (스텝
사이에 적분기 밖에서 옮겨진 물체), K = Σ½mv², U = ΣmΦ(퍼텐셜이 없으면 NaN — 만들지 않음). 점검: 기타 일 W_o = ΔK − W_g + ε(접촉·마찰·
감쇠·충격 — 자유 비행에서 0), 장 확인 R_Φ = Σ[m·(Φ(x₁) − Φ(x₀)) + m·g·Δx](균일장 0, 방사형 O(dt) — 퍼텐셜이 있는 스텝만), 에너지 확인
Δ(K + U) − W_field − W_moved − W_o = R_Φ − ε, 기타 충격량 = Δp − J_g. 척도는 총 경로 일 Σ|m·g·Δx|(순 일은 진동에서 0에 가까움). 물체가
생기거나 사라지면(다른 시스템이 장 스텝 뒤에 지운 경우 포함) 그 K·U·p를 경계 항으로. 중력은 외부장이라 Σp가 보존될 필요가 없고,
ForceLedger와 Rapier에 같은 힘을 두 번 기록하지 않습니다(장부는 힘이 아니라 표본 g로 계산). 붕괴 블록의 에너지는 구조 장부(released =
충돌 + 흡수 + 지면 + 운동)에 실제 g로. 검증: `ledger.test.ts`(독립 기준 15장면 + 이동 2 + 생성·제거 3, dt 수렴), `lifecycle.sim.test.ts`
(Rapier), 자유낙하에서 장 잔차 < 10⁻⁶·W_g(f32 위치), 감쇠 일 비율 4–10 %(c = 0.05/s, t = 1.5 s). 상세: `docs/PHASE31_AUDIT.md` §3.

## 46. 과학적 한계

- 사용자 정의 가속도장입니다. 실제 천체 전체의 중력장(구형 질량 분포·회전·조석)을 계산하지 않고, 달·화성 프리셋은 중력 크기만 바꿉니다.
- 일반상대론(시간 지연·광선 휘어짐·사건의 지평선)을 계산하지 않습니다.
- 무중력 3D 유체(표면장력 지배 흐름, 물방울)를 계산하지 않습니다 — 얕은 물·용암·흙·공기 기둥은 하향 중력이 없으면 정지합니다.
- 수평·반전 중력: 지면 기반 솔버는 기울기 0.3까지 기울어진 기준면으로, 그 너머는 제한. 구조 하중 경로는 수직 하중만(수평 정적 하중은
  모델에 없음), 상향 중력은 크기 대칭 근사(인장·들림 미모델).
- 대기 기둥 모델은 준정역학 — 빠른 중력 변화의 압력파는 없음. 국소 중력원은 공기 기둥·열·화재·화산·기후에 반영하지 않습니다(균일
  부분만 — 제한 표시). 물·구조·강체는 국소 중력원을 반영합니다.
- 화산탄·분출물 비행은 발사 시각의 장, 비행 중 변화는 따르지 않음. 강수는 낙하 시간 없는 표면 공급.
- 지구 보정 경험식(C)은 스케일링 규칙의 범위 안에서만 의미가 있습니다 — 3 g₀ 초과는 사람·차량·구조 경험식의 검증 범위 밖(제한 표시).
- 구조 모델은 인증된 FEM이 아닙니다. 지붕 패널 용량은 설계 하중 기반 축약값입니다(실제 지붕마다 다름).
- 상세 인간 생리 반응은 Phase 34에서 다룹니다. 실제 천체 환경이나 안전 예측에 사용할 수 없습니다.
