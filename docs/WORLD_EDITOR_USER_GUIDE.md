# 월드 에디터 사용 설명서

이 설명서는 화면에서 월드를 만들고 재난을 실험하는 순서를 따라갑니다. 단추와 탭 이름은 화면 그대로 적었습니다(영어 화면은 괄호 안).
화면은 셋으로 나뉩니다: **왼쪽**은 만들기(오브젝트·건물·지형·도로·설계도·장면 탭), **가운데**는 3D 월드, **오른쪽**은 선택한 것과 재난(선택·재난·분석·설정 탭)입니다.
**아래쪽**은 재생·일시정지·초기화입니다.

## 0. 기본 조작

| 하고 싶은 것 | 방법 |
|---|---|
| 카메라 돌리기 / 옮기기 / 확대 | 왼쪽 끌기 / 오른쪽 끌기 / 휠 |
| 객체 고르기 | 클릭. 겹쳐 있으면 **같은 자리를 한 번 더 클릭**하면 뒤에 있는 것이 골라집니다 |
| 여러 개 고르기 | Shift(또는 Ctrl·⌘) + 클릭, Shift + 끌기(상자), Shift + Ctrl·⌘ + 끌기(상자로 빼기) |
| 그룹 안의 하나만 | Alt + 클릭 |
| 옮기기 / 회전 / 크기 | W / E / R, 화면의 손잡이를 끌기 |
| 끌던 것을 취소 | 끄는 중에 **Esc** — 시작 전 자리로 돌아갑니다(실행 취소 기록도 남지 않음) |
| 되돌리기 / 다시 하기 | Ctrl·⌘ + Z / Ctrl·⌘ + Shift + Z(또는 Ctrl + Y) — 객체·지형·도로·재난 배치가 모두 한 기록입니다 |
| 선택한 것 보기 | F(여러 개면 모두 보이게) |
| 스냅 켜기·끄기 | G |

한글 입력 상태에서도 단축키가 동작합니다. 글자 칸에 입력하는 동안에는 단축키가 동작하지 않습니다.

## 1. 새 월드 만들기

1. 위쪽 **더보기(⋯)** → **새 프로젝트**: 빈 평지에서 시작합니다(구조 모델 v2가 켜져 있음).
2. 또는 같은 메뉴의 **프리셋으로 새 월드**:
   - 구조물 실험장(구조 형식별 건물 1동씩)
   - 도로 중심 도시
   - 산악 지형
   - 해안 지역
   - 강과 저지대
   - **샘플 도시 불러오기**는 기본 마을입니다.
3. 지금 월드에 객체가 있으면 바꾸기 전에 확인을 묻습니다. 편집 내용은 브라우저에 자동 저장됩니다(§9).

## 2. 지형 만들기

1. 왼쪽 **지형** 탭에서 도구를 고릅니다. 올리기·내리기·평탄화·다듬기·지표 칠하기 같은 브러시와, 산·언덕·계곡·강·호수·해안·숲 같은 지형 요소가 있습니다.
2. 브러시를 땅 위에 올리면 **실제로 바꾸기 전에** 미리보기가 나타납니다.
   - 영향 범위, 예상 높이 변화(따뜻한 색 = 올라감, 차가운 색 = 내려감), 패널의 예상 최대 상승·하강·면적.
   - 사각 브러시는 사각형으로 보입니다.
   - 평탄화는 맞출 높이의 고리로 보입니다.
   - 지표·토양 칠하기는 칠해질 자리가 그 색으로 보이고, 패널에는 칠할 면적만 나옵니다.
3. 누른 채 끌면 칠해집니다. **끌기 한 번이 실행 취소 한 단계**입니다. 끄는 중 Esc를 누르면 그 획은 없던 일이 됩니다.
4. 반경은 `[` / `]`, Shift와 함께 누르면 5씩 바뀝니다.
5. 땅이 바뀌면 그 위에 서 있던 건물·차·사람·나무는 새 땅에 다시 앉습니다. 공중에 띄워 둔 것은 그 높이 그대로입니다.
   - 건물의 기초 정책을 "유지"로 하면 땅이 바뀌어도 건물은 그 자리 그대로입니다.
   - 배치한 재난은 x·z 위치가 바뀌지 않습니다.

숲 브러시는 아스팔트·콘크리트·암반, 물가 1 m, 도로 0.5 m 안에는 나무를 심지 않습니다. 기준은 지형 탭의 숲 항목에서 바꿉니다. 같은 시드로 같은 자리에 칠하면 같은 숲이 됩니다.

## 3. 도로 그리기

1. 왼쪽 **도로** 탭 → **그리기**.
2. 도로 프리셋(좁은 2차로 · 2차로 도로 · 넓은 2차로 (갓길) · 4차로 대로, 골목길·자갈길·흙길)을 고릅니다.
3. 시작점을 클릭하고, 경유점을 클릭하고, 끝점에서 **더블클릭** 또는 **Enter**를 누릅니다.
   - 곡선 도로는 **곡선**으로 그립니다. 중간 클릭이 제어점이 됩니다.
4. 기존 도로에 이을 때:
   - 노드에서 3 m 안을 클릭하면 노드에 붙습니다.
   - 도로 위를 클릭하면 그 자리에서 나뉘어 T자 교차로가 됩니다.
   - 기존 도로를 가로질러 그리면 십자 교차로가 됩니다.
5. 폭이 다른 도로를 일직선으로 이으면 넓은 쪽 도로에 **폭 전환 구간**이 자동으로 생깁니다. 길이는 6 m 이상이고, 10 m → 7 m라면 15 m입니다.
   - 노면과 높이는 계단 없이 이어집니다.
   - 도로가 너무 짧아 전환 구간이 짧아지면 경고가 나옵니다.
   - **편집**에서 도로를 고르면 오른쪽에 "폭 전환 … m" 줄이 보입니다.
6. 오브젝트 탭의 도로 카드(2차로·4차로)를 클릭해 놓아도 같은 도로가 되고, 가까운 도로 끝에 이어집니다.

## 4. 건물 배치

1. 왼쪽 **오브젝트** 탭에서 건물 카드를 고르고 땅을 클릭합니다. 카드는 계속 무장되어 있어 여러 번 놓을 수 있고, Esc로 끝냅니다.
2. 놓기 전 미리보기 색: 회색 = 문제 없음, 주황 = 경고(경사·떠 있음·겹침, 이유가 화면 위쪽 안내줄에), 빨강 = 월드 밖이라 놓을 수 없음.
3. **스냅**(G로 켜고 끄기). 무엇에 붙었는지 안내줄에 "⌖ 스냅: …"으로 나오고 땅에 고리가 표시됩니다.
   - 도로 가까이(3 m): **도로 접면** — 도로를 향해, 보도 바깥 1 m 뒤에 놓입니다.
   - 옆 건물 가까이(0.8 m): **이웃 가장자리** — 맞닿거나 가장자리가 맞춰집니다. 도로 접면과 함께 붙으면 길을 따라 나란히 섭니다.
   - 옆 건물의 기둥선 가까이: **이웃 건물 구조 그리드**.
   - 그 밖: 격자.
4. 정확한 값: 건물을 고르고 오른쪽 **선택** 탭의 트랜스폼에 입력합니다.
   - 위치 (m)
   - 지면 위 높이
   - 회전(X 기울기 · Y 방향 · Z 기울기)
   - 크기
   - **지면에 놓기**, **경사 따르기**
   - 월드 밖 값은 월드 안으로 제한되고 알림이 나옵니다.
5. 건물 만들기: 왼쪽 **건물** 탭에서 프리셋을 고르고 폭·깊이·층수·층고를 정합니다.
   - **구조 형식**: 철골조·철근콘크리트조·조적조·목구조 중에서 고릅니다. 아래에 그 형식의 부재 법칙(소성·파괴 이용률, 접합, 주된 파괴)이 설명됩니다.
   - **배치**를 눌러 땅에 놓습니다.
6. 부재 편집: 건물을 고르고 **부재 편집**(Building Edit Mode)을 엽니다.
   - 아래 막대의 "+ 기둥 / + 보 / … / + 가새"로 부재를 더합니다.
   - **가새**는 기둥 끝을 한 번, 다른 기둥 끝을 한 번 클릭합니다. 화면에서 커서에 가장 가까운 접합점이 잡힙니다.
   - 부재를 고르면 오른쪽에서 역할·재료·크기·위치·방향·초기 손상을 고칩니다. 창 ↔ 문은 종류를 바꿀 수 있습니다.
   - 지지가 끊기는 부재가 늘어나는 변경은 확인을 묻습니다.

## 5. 사람과 차량 배치

- 오브젝트 탭의 사람·차 카드로 놓습니다.
- 차는 도로 가까이(2.5 m)에서 **차선 중심**에 붙고, 그 차선의 진행 방향을 봅니다.
- 미리보기 경고:
  - 바퀴가 지면에서 뜸(울퉁불퉁한 땅)
  - 너무 가파름(차 25°·사람 30° 초과)
  - 물속
  - 도로 위가 아님(차, 놓는 것은 가능)
- 여러 대: **선형 배치**(L)·**영역 채우기**(A)·**브러시**(B), 또는 도로 탭의 도시 도구(도로를 따라 차량 추가).

## 6. 오브젝트 정렬·그룹·정리

1. 여러 개를 고르면 오른쪽에 **다중 선택** 패널이 나옵니다.
2. **정렬 기준**을 **원점**(각 객체의 기준점) 또는 **바닥면**(가장자리)으로 고르고, X·Z 최소/중심/최대로 맞춥니다.
   - **간격**: 바닥면 사이 간격을 같게 합니다(처음·끝은 그대로).
   - **기준 객체에 맞추기**: 마지막으로 클릭한 객체와 같은 방향·같은 지면 위 높이·같은 크기로 맞춥니다.
   - **기준 객체 속성 복사**: 크기·방향·매개변수·물리·구조에서 골라 나머지에 적용합니다. 맞지 않는 것은 건너뛰고 건수를 알려 줍니다.
3. **그룹**: Ctrl·⌘ + G로 묶고, Ctrl·⌘ + Shift + G로 풉니다. Ctrl·⌘ + D로 복제하면 새 그룹이 됩니다.
4. 왼쪽 **장면** 탭(아웃라이너):
   - 검색과 보기 필터(종류·숨긴 것만·잠긴 것만)
   - 그룹 접기·펼치기, 연필로 이름 바꾸기
   - **눈**: 편집 화면에서 숨기기. 숨겨도 시뮬레이션에는 그대로 있고 시뮬레이션 화면에 보입니다.
   - **자물쇠**: 잠그기. 잠긴 객체는 화면에서 클릭·상자로 잡히지 않고, 옮기거나 지울 수 없습니다. 장면 탭에서는 고를 수 있습니다.

## 7. 재난 배치

1. 오른쪽 **재난** 탭 → 재난 라이브러리에서 카드를 고릅니다. 한국어·영어로 검색하거나 범주 칩, 즐겨찾기(☆), 최근을 씁니다.
2. 지도 위에 미리보기(위치·영향 범위·설명)가 따라옵니다. 클릭하면 그 자리에 놓입니다.
   - **연속 배치**를 켜면 여러 개를 계속 놓습니다.
   - 실행 방식: **클릭 즉시 실행** 또는 **배치 후 실행**.
   - **완료** 또는 Esc로 배치를 끝냅니다.
   - 재난을 고르면 편집 도구는 저절로 풀립니다.
3. 놓은 재난의 핀은 끌어서 옮깁니다. 끄는 중 Esc를 누르면 제자리로 돌아갑니다.
   - 핀을 고르고 Delete를 누르면 지웁니다. 객체를 고르면 핀 선택은 풀리므로, Delete가 엉뚱하게 재난을 지우지 않습니다.
4. 세기·범위·시각은 재난 탭의 목록에서 고칩니다(기본/고급 칸). 이 편집과 배치·이동·삭제는 모두 Ctrl·⌘ + Z로 되돌릴 수 있습니다.

## 8. 시뮬레이션 실행·결과 확인·원본 복구

1. 아래쪽 재생(▶) 또는 재난 탭의 **실험 실행**: 위쪽이 **시뮬레이션 모드**로 바뀝니다.
2. 실행 중에도 재난 탭에서 인스턴스마다 일시정지·재개·중지·취소를 할 수 있습니다(지원하는 것만 단추가 보입니다).
3. 결과:
   - **분석** 탭과 아래쪽 이벤트 로그(시뮬레이션 요약)를 봅니다.
   - 건물을 고르면 손상·층별 변위·부재 상태가 보입니다.
   - 지진 중 건물은 층마다 다르게 흔들려 보입니다. 이 흔들림은 구조 계산값이고, 연약층이면 그 층이 더 기울어 보입니다.
4. **초기화**(시뮬레이션 이전 상태로 복구) 또는 **편집 모드**로 돌아가면 원래 월드 그대로입니다. 시뮬레이션은 편집 문서를 바꾸지 않습니다.
5. 고친 뒤 다시 실행합니다. 실행 중의 변화는 실행 취소로 되돌리지 않습니다. 실행 취소는 편집에만 해당합니다.

구조 모델 v2(새 프로젝트·기본 마을·프리셋은 켜져 있음, 오른쪽 **설정** 탭)에서는 무너진 칸만큼 건물의 충돌 공간이 줄어듭니다. 그래서 부서진 모서리에 보이지 않는 벽이 남지 않습니다. 다만 잔해가 그 칸 안에 쌓여 있거나 위층 바닥판이 아직 매달려 있으면 그 칸은 막힌 것으로 봅니다.

## 9. 저장·불러오기

- **자동 저장**:
  - 편집하면 약 1초 뒤 브라우저에 저장되고, 탭을 닫거나 다른 탭으로 갈 때도 저장됩니다.
  - 지형을 칠하거나 끄는 도중에는 저장하지 않고 끝난 뒤 저장합니다.
  - 저장 공간이 부족해 저장되지 않으면 알림이 나옵니다. 그때는 파일로 내보내세요.
- **파일**: 더보기(⋯) → **파일로 내보내기 (.json)** / **파일에서 가져오기 (.json)**.
- 브라우저에 남은 자동 저장을 읽을 수 없으면 원본을 백업해 두고 알려 줍니다. 더보기(⋯) → **읽지 못한 자동 저장 내보내기**로 그 파일을 받을 수 있습니다. 전처럼 조용히 덮어쓰지 않습니다.
- 잠금·숨김·그룹 이름은 파일에 저장됩니다. 이전 버전 프로그램으로 열면 이 세 가지는 빠집니다.

## 10. 명령으로 편집하기

화면 아래쪽에 **명령창**이 한 줄 있습니다. 한국어나 영어 문장, 또는 정규 명령을 치면 마우스로 한 것과 같은 편집이 됩니다 — 같은 스냅, 같은 배치 검사, 같은 실행 취소입니다.

### 기본 흐름

1. **/** 키(또는 Ctrl·⌘ + K)를 누르면 명령창에 커서가 갑니다. 시뮬레이션 중에도 됩니다.
2. 문장을 칩니다. 치는 동안 명령창 위 한 줄에 **이렇게 이해했습니다**(정규 명령)와 생기는 것(+)·바뀌는 것(~)·지워지는 것(−)의 개수가 나오고, 3D 화면에 흐린 유령이 보입니다(**초안**).
3. **Enter** — **계획**이 열립니다. 아직 아무것도 바뀌지 않았습니다. 유령·지형 열 지도·도로 선·재난 핀으로 무엇이 될지 보여 주고, 결과 영역에 항목별 경고와 거부 사유가 나옵니다.
4. **Enter 한 번 더** — 확정. 명령 하나가 **실행 취소 한 단계**입니다(Ctrl·⌘ + Z 한 번에 전부 돌아옵니다). 200개가 넘는 큰 편집은 Enter를 한 번 더 받습니다.
5. **Esc** — 계획 취소. 한 번 더 누르면 명령창에서 나갑니다. 글을 고치고 Enter를 누르면 새 계획입니다.

- 질문("건물 몇 채야?"), 카메라("… 보여 줘"), 선택, 실행·일시정지·리셋·배속은 미리보기 없이 **Enter 한 번**에 됩니다.
- 한글을 조합하는 중의 Enter는 글자를 확정할 뿐, 명령을 보내지 않습니다.
- **↑ / ↓** 는 전에 친 명령(50개까지, 이 브라우저에 보관), **Tab** 은 낱말 자동 완성(종류·프리셋·그룹 이름·id·재난 칸 이름)입니다.
- 명령창에 글을 치는 동안에는 W·E·R·G 같은 편집 단축키가 동작하지 않습니다.
- 상태는 색이 아니라 기호와 글자로 표시합니다: ○ 대기 · ◇ 초안 · ◆ 계획 · ◈ 확인 · ? 질문 · ✕ 오류 · ✓ 완료.

### 이해하지 못했을 때

- **모르는 문장은 실행하지 않습니다.** 가까운 명령 두세 개를 단추로 보여 줍니다(누르면 명령창에 들어갑니다). **?** 단추를 누르면 부류별 **예문**, 정규 **명령** 표, **키** 목록이 나옵니다.
- **한 조각이 빠졌으면 그것만 묻습니다.** "선택한 것 동쪽으로 옮겨" → 얼마나? 글을 채우고 Enter를 누르세요.
- **여럿 중 어느 것인지 모르면 고르게 합니다.** 교차로가 둘인데 "교차로에 폭발"이라고 하면 후보가 단추로 나옵니다. 단추에 마우스를 올리면 3D 화면에서 그 자리가 강조되고, 누르거나 숫자 키(1–9)로 고릅니다.
- "…하지 마", "…말고", "만약 …면"이 들어간 문장은 읽지 않습니다.

### 낱말

| 낱말 | 뜻 |
|---|---|
| 여기 / here | 마우스가 마지막으로 가리킨 땅(마우스가 명령창으로 가도 기억합니다) |
| 저기 / there | 화면 한가운데가 땅과 만나는 곳 |
| 이것·선택한 것 / these | 지금 선택 |
| 방금 만든 것 / the ones I just made | 바로 앞 명령이 만들거나 바꾼 객체 |
| 그것 / it | 선택이 있으면 선택, 없으면 방금 만든 것(어느 쪽인지 표시합니다) |
| 큰길 / the main road | 가장 넓고 긴 길. 같은 급의 길이 둘이면 어느 길인지 묻습니다 |
| 교차로 / the junction | 길이 셋 이상 만나는 곳. 둘 이상이면 묻습니다 |
| 북·남·동·서 | 화면의 나침반 그대로(북 = −z). 길 옆은 "큰길 북쪽에", 남북으로 난 길의 "북쪽"은 옆이 아니라 끝이라 되묻습니다 |
| #building_ab12 | 객체 id(앞부분만 쳐도 하나로 정해지면 됩니다. Tab으로 완성) |
| n4 · s2 · p3 | 도로 노드 · 도로 구간 · 놓인 재난의 번호 |

잠긴 객체는 편집에서 빠지고 몇 개가 빠졌는지 알려 줍니다. 숨긴 객체는 "모든 나무"처럼 쓸어 담을 때는 빠지고, "숨긴 나무"·선택·id로 직접 가리키면 포함됩니다.

### 부류별 예문

| 하고 싶은 것 | 한국어 | English |
|---|---|---|
| 길 옆에 건물 | 큰길 북쪽에 2층 주택 세 채 간격 2미터 | put three 2-storey houses north of the main road, 2 m apart |
| 차·사람 | 큰길에 트럭 두 대 | two trucks on the main road |
| 숲 | (30, 30) 반경 25 m에 숲, 밀도 5, 시드 7 | a forest within 25 m of (30, 30), density 5, seed 7 |
| 선택 | 경사 20도 넘는 곳의 나무 다 선택 · n4에서 30 m 이내 건물들 선택해 | select every tree on slopes over 20° · select buildings within 30 m of n4 |
| 옮기기·값 | 선택한 것 x를 10으로 | set x to 10 for the selection |
| 묶기·이름 | 방금 만든 것 묶어서 "북쪽 블록"이라고 해 | group the ones I just made, named "North block" |
| 숨김·잠금·삭제 | 숨긴 나무 다시 보여 줘 | show the hidden trees again |
| 지형 | 여기 반경 10 m 평평하게 · (40, 60) 반경 6 m 지면을 1 m 높여 | flatten a 10 m circle here · raise the ground within 6 m of (40, 60) by 1 m |
| 도로 | n4에서 (40, 60)까지 2차로 도로 | a two-lane road from n4 to (40, 60) |
| 재난 | 교차로에 폭발 1.8×10⁹ J, 5초 뒤 · 여기에 규모 7 지진 | a 1.8e9 J explosion at the junction in 5 s · a magnitude 7 earthquake here |
| 실행 | 실행 · 일시정지 · 리셋 · 2배속 · 비 멈춰 | run · pause · reset · 2x · stop the rain |
| 보기 | 가장 높은 건물 보여 줘 | show me the tallest building |
| 질문 | 건물 몇 채야? · 3층 이상 건물 목록 | how many buildings? · list buildings with at least 3 floors |
| 되돌리기 | 방금 거 취소 | undo that |

- 수는 "세 채", "3", "1.8×10⁹", "18억"처럼 쓸 수 있고, 단위(m·도·초·분·J·MJ·km/h …)는 알아서 바꿉니다. 단위가 필요한데 없으면 묻습니다.
- **"실행"** 은 편집 모드에서 놓아 둔 재난과 함께 시작합니다(재난 탭의 **실험 실행**과 같음). 시뮬레이션 중에는 편집 명령을 받지 않고 이유를 알려 줍니다. 질문·카메라·실행 제어·재난 명령은 됩니다.
- 재난마다 되는 제어가 다릅니다. 폭발은 시작한 뒤 멈출 수 없어서 "폭발 일시정지"는 하지 않고 이유를 말합니다.
- 지형을 올리는 명령("… 3 m 올려")은 원 안 전체를 그 높이만큼 올리고 가장자리 2–3 m에서 급하게 떨어집니다. 완만한 언덕은 지형 탭의 브러시나 지형 요소가 낫습니다.

### 정규 명령

문장은 모두 아래 모양의 **정규 명령**으로 바뀌어 보입니다. 정규 명령을 그대로 쳐도 됩니다(동사는 `배치`·`선택`·`삭제`처럼 한국어로도). 수치는 m, °, 초, J 같은 기본 단위입니다.

```
place <종류>[:<프리셋>] [count=N] [at=<위치>] [along=<도로>] [side=north|south|east|west|left|right] [gap=<m>] [floors=N] [heading=<°>]
select | add | remove <대상>      select none
move <대상> by=<dx,dy,dz> | to=<위치>      rotate <대상> by=<°>      scale <대상> x<k>
set <대상> [x=] [y=] [z=] [heading=] [scale=] [lift=]
align <대상> axis=x|z mode=min|center|max      distribute <대상> axis=x|z|auto [gaps]
match <대상> heading|height|scale [to=<대상>]      copy <속성,…> from=<대상> to=<대상>
group <대상> [name="…"]   ungroup   rename <대상> "…"   hide | show | lock | unlock | delete <대상>   duplicate <대상> [offset=<dx,dz>]
terrain raise|lower|flatten|smooth <영역> [by=<m>] [to=<m>]      paint <영역> ground=<이름>
road <위치> -> <위치> [preset=<이름>]      forest <영역> [density=<값>] [seed=N]
disaster <종류> [at=<위치>] [<칸>=<값> …] [start=<초>] [now]      disaster <p번호|종류|all> stop|pause|resume|delete|move to=<위치>
run   pause   reset   speed=<k>   focus <대상>   focus at=<위치>   undo   redo
count | list | info | measure <대상>      count | list disasters | groups | roads      measure <위치> <위치>

대상 = selection | last | it | all | #<id> | group:"이름" | name:"이름" | type:<종류>[:<프리셋>]  [where 조건 and 조건] [largest|tallest|nearest <위치>] [first N]
조건 = floors>=3 · slope>20 · height<10 · near <위치> r=<m> · on road · hidden · locked · warning
위치 = 12,-4 · node:n4 · seg:s2@0.5 · junction · cursor · view · center · selection · last · #<id> · feature:hill · north(<위치>,10) · next(<위치>)
영역 = rect x0,z0,x1,z1 · circle <위치> r=<m> · around <대상> r=<m> · feature:hill
```

`heading=`은 오른쪽 **선택** 탭의 "Y 방향"과 같은 수입니다. 재난 칸의 값은 저장 단위입니다(폭발 에너지 J, 기간 초).

### 스크립트

명령창의 **스크립트** 단추를 누르면 여러 줄을 한 번에 넣을 수 있습니다. 한 줄에 명령 하나, `# `(#과 한 칸)로 시작하는 줄은 주석입니다.

- **실행**(Ctrl·⌘ + Enter) → 전체 미리보기 → 명령창에서 Enter로 확정. 스크립트 전체가 실행 취소 한 단계입니다(**줄마다 실행 취소 한 단계**를 켜면 줄마다).
- 한 줄이라도 실패하면 전체가 취소되고 월드는 그대로입니다.
- 뒷줄은 앞줄의 결과를 가리킬 수 있습니다("방금 만든 것", `last`).
- **기록에서**: 지금까지 확정한 명령을 스크립트로 만듭니다. **불러오기 … / 저장**: `.dscmd.txt` 파일(일반 글). 스크립트는 월드 파일에 저장되지 않습니다.
- **작은 편집은 바로 적용**: 켜면 객체 20개 이하를 건드리는 한 줄 명령이 미리보기 없이 적용됩니다. 삭제·지형·도로·큰 편집은 켜도 항상 미리보기합니다. 기본은 꺼짐입니다.

### 오른쪽 클릭 메뉴

3D 화면의 땅을 **오른쪽 클릭**(끌지 않고)하면 **여기에 놓기 …**·**여기에 재난 …** 메뉴가 나옵니다. 고르면 그 좌표가 채워진 명령이 명령창에 들어가고(예: `place building:house at=40,60`), 거기서 Enter를 누르면 계획합니다. 오른쪽으로 **끌면** 전처럼 카메라가 움직입니다.

### 함께 바뀐 것

- **여러 개의 값을 한 번에**: 여러 개를 고르면 오른쪽 **다중 선택** 패널에 **모두 같은 값으로** 칸(X·Y·Z·Y 방향·크기·지면 위 높이)이 있습니다. 명령 "선택한 것 x를 10으로"와 같은 결과입니다. X·Z를 바꾸면 땅에 서 있던 객체는 새 자리의 땅에 앉고, 떠 있던 객체는 높이를 유지합니다.
- **장면 탭(아웃라이너)**: Shift + 클릭 = 마지막으로 누른 줄부터 그 줄까지 **범위** 선택, Ctrl·⌘ + 클릭 = 하나씩 추가/제외, ↑ / ↓ = 이동(Shift = 범위 늘리기). 3D 화면의 Shift + 클릭(하나 추가)과 뜻이 다릅니다.
- **차의 설정이 복사본을 따라갑니다**: 차를 복제(Ctrl·⌘ + D)·붙여넣기·설계도로 놓으면 그 차의 주행 설정이 같은 실행 취소 단계에서 복사됩니다. 탑승자는 함께 복사한 사람만 새 차에 탑니다. 자율 주행 경로는 옮겨지지 않습니다(같은 좌표).
