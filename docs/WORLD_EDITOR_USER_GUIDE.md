# 월드 에디터 사용 설명서

이 설명서는 화면에서 월드를 만들고 재난을 실험하는 순서를 따라갑니다. 단추와 탭 이름은 화면 그대로 적었습니다(영어 화면은 괄호 안).
화면은 셋으로 나뉩니다: **왼쪽**은 만들기(오브젝트·건물·지형·도로·설계도·장면 탭), **가운데**는 3D 월드, **오른쪽**은 선택한 것과 재난(선택·재난·분석·설정 탭)입니다.
**아래쪽**은 재생·일시정지·초기화입니다.

## 0. 기본 조작

| 하고 싶은 것 | 방법 |
|---|---|
| 카메라 돌리기 / 옮기기 / 확대 | 왼쪽 끌기 / 오른쪽 끌기 / 휠 |
| 객체 고르기 | 클릭. 겹쳐 있으면 **같은 자리를 한 번 더 클릭**하면 뒤에 있는 것이 골라집니다 |
| 여러 개 고르기 | Shift(또는 Ctrl·⌘) + 클릭, Shift + 끌기(상자), Shift + Ctrl·⌘ + 끌기(상자로 빼기) |
| 그룹 안의 하나만 | Alt + 클릭 |
| 옮기기 / 회전 / 크기 | W / E / R, 화면의 손잡이를 끌기 |
| 끌던 것을 취소 | 끄는 중에 **Esc** — 시작 전 자리로 돌아갑니다(실행 취소 기록도 남지 않음) |
| 되돌리기 / 다시 하기 | Ctrl·⌘ + Z / Ctrl·⌘ + Shift + Z(또는 Ctrl + Y) — 객체·지형·도로·재난 배치가 모두 한 기록입니다 |
| 선택한 것 보기 | F(여러 개면 모두 보이게) |
| 스냅 켜기·끄기 | G |

한글 입력 상태에서도 단축키가 동작합니다. 글자 칸에 입력하는 동안에는 단축키가 동작하지 않습니다.

## 1. 새 월드 만들기

1. 위쪽 **더보기(⋯)** → **새 프로젝트**: 빈 평지에서 시작합니다(구조 모델 v2가 켜져 있음).
2. 또는 같은 메뉴의 **프리셋으로 새 월드**:
   - 구조물 실험장(구조 형식별 건물 1동씩)
   - 도로 중심 도시
   - 산악 지형
   - 해안 지역
   - 강과 저지대
   - **샘플 도시 불러오기**는 기본 마을입니다.
3. 지금 월드에 객체가 있으면 바꾸기 전에 확인을 묻습니다. 편집 내용은 브라우저에 자동 저장됩니다(§9).

## 2. 지형 만들기

1. 왼쪽 **지형** 탭에서 도구를 고릅니다. 올리기·내리기·평탄화·다듬기·지표 칠하기 같은 브러시와, 산·언덕·계곡·강·호수·해안·숲 같은 지형 요소가 있습니다.
2. 브러시를 땅 위에 올리면 **실제로 바꾸기 전에** 미리보기가 나타납니다.
   - 영향 범위, 예상 높이 변화(따뜻한 색 = 올라감, 차가운 색 = 내려감), 패널의 예상 최대 상승·하강·면적.
   - 사각 브러시는 사각형으로 보입니다.
   - 평탄화는 맞출 높이의 고리로 보입니다.
   - 지표·토양 칠하기는 칠해질 자리가 그 색으로 보이고, 패널에는 칠할 면적만 나옵니다.
3. 누른 채 끌면 칠해집니다. **끌기 한 번이 실행 취소 한 단계**입니다. 끄는 중 Esc를 누르면 그 획은 없던 일이 됩니다.
4. 반경은 `[` / `]`, Shift와 함께 누르면 5씩 바뀝니다.
5. 땅이 바뀌면 그 위에 서 있던 건물·차·사람·나무는 새 땅에 다시 앉습니다. 공중에 띄워 둔 것은 그 높이 그대로입니다.
   - 건물의 기초 정책을 "유지"로 하면 땅이 바뀌어도 건물은 그 자리 그대로입니다.
   - 배치한 재난은 x·z 위치가 바뀌지 않습니다.

숲 브러시는 아스팔트·콘크리트·암반, 물가 1 m, 도로 0.5 m 안에는 나무를 심지 않습니다. 기준은 지형 탭의 숲 항목에서 바꿉니다. 같은 시드로 같은 자리에 칠하면 같은 숲이 됩니다.

## 3. 도로 그리기

1. 왼쪽 **도로** 탭 → **그리기**.
2. 도로 프리셋(좁은 2차로 · 2차로 도로 · 넓은 2차로 (갓길) · 4차로 대로, 골목길·자갈길·흙길)을 고릅니다.
3. 시작점을 클릭하고, 경유점을 클릭하고, 끝점에서 **더블클릭** 또는 **Enter**를 누릅니다.
   - 곡선 도로는 **곡선**으로 그립니다. 중간 클릭이 제어점이 됩니다.
4. 기존 도로에 이을 때:
   - 노드에서 3 m 안을 클릭하면 노드에 붙습니다.
   - 도로 위를 클릭하면 그 자리에서 나뉘어 T자 교차로가 됩니다.
   - 기존 도로를 가로질러 그리면 십자 교차로가 됩니다.
5. 폭이 다른 도로를 일직선으로 이으면 넓은 쪽 도로에 **폭 전환 구간**이 자동으로 생깁니다. 길이는 6 m 이상이고, 10 m → 7 m라면 15 m입니다.
   - 노면과 높이는 계단 없이 이어집니다.
   - 도로가 너무 짧아 전환 구간이 짧아지면 경고가 나옵니다.
   - **편집**에서 도로를 고르면 오른쪽에 "폭 전환 … m" 줄이 보입니다.
6. 오브젝트 탭의 도로 카드(2차로·4차로)를 클릭해 놓아도 같은 도로가 되고, 가까운 도로 끝에 이어집니다.

## 4. 건물 배치

1. 왼쪽 **오브젝트** 탭에서 건물 카드를 고르고 땅을 클릭합니다. 카드는 계속 무장되어 있어 여러 번 놓을 수 있고, Esc로 끝냅니다.
2. 놓기 전 미리보기 색: 회색 = 문제 없음, 주황 = 경고(경사·떠 있음·겹침, 이유가 화면 위쪽 안내줄에), 빨강 = 월드 밖이라 놓을 수 없음.
3. **스냅**(G로 켜고 끄기). 무엇에 붙었는지 안내줄에 "⌖ 스냅: …"으로 나오고 땅에 고리가 표시됩니다.
   - 도로 가까이(3 m): **도로 접면** — 도로를 향해, 보도 바깥 1 m 뒤에 놓입니다.
   - 옆 건물 가까이(0.8 m): **이웃 가장자리** — 맞닿거나 가장자리가 맞춰집니다. 도로 접면과 함께 붙으면 길을 따라 나란히 섭니다.
   - 옆 건물의 기둥선 가까이: **이웃 건물 구조 그리드**.
   - 그 밖: 격자.
4. 정확한 값: 건물을 고르고 오른쪽 **선택** 탭의 트랜스폼에 입력합니다.
   - 위치 (m)
   - 지면 위 높이
   - 회전(X 기울기 · Y 방향 · Z 기울기)
   - 크기
   - **지면에 놓기**, **경사 따르기**
   - 월드 밖 값은 월드 안으로 제한되고 알림이 나옵니다.
5. 건물 만들기: 왼쪽 **건물** 탭에서 프리셋을 고르고 폭·깊이·층수·층고를 정합니다.
   - **구조 형식**: 철골조·철근콘크리트조·조적조·목구조 중에서 고릅니다. 아래에 그 형식의 부재 법칙(소성·파괴 이용률, 접합, 주된 파괴)이 설명됩니다.
   - **배치**를 눌러 땅에 놓습니다.
6. 부재 편집: 건물을 고르고 **부재 편집**(Building Edit Mode)을 엽니다.
   - 아래 막대의 "+ 기둥 / + 보 / … / + 가새"로 부재를 더합니다.
   - **가새**는 기둥 끝을 한 번, 다른 기둥 끝을 한 번 클릭합니다. 화면에서 커서에 가장 가까운 접합점이 잡힙니다.
   - 부재를 고르면 오른쪽에서 역할·재료·크기·위치·방향·초기 손상을 고칩니다. 창 ↔ 문은 종류를 바꿀 수 있습니다.
   - 지지가 끊기는 부재가 늘어나는 변경은 확인을 묻습니다.

## 5. 사람과 차량 배치

- 오브젝트 탭의 사람·차 카드로 놓습니다.
- 차는 도로 가까이(2.5 m)에서 **차선 중심**에 붙고, 그 차선의 진행 방향을 봅니다.
- 미리보기 경고:
  - 바퀴가 지면에서 뜸(울퉁불퉁한 땅)
  - 너무 가파름(차 25°·사람 30° 초과)
  - 물속
  - 도로 위가 아님(차, 놓는 것은 가능)
- 여러 대: **선형 배치**(L)·**영역 채우기**(A)·**브러시**(B), 또는 도로 탭의 도시 도구(도로를 따라 차량 추가).

## 6. 오브젝트 정렬·그룹·정리

1. 여러 개를 고르면 오른쪽에 **다중 선택** 패널이 나옵니다.
2. **정렬 기준**을 **원점**(각 객체의 기준점) 또는 **바닥면**(가장자리)으로 고르고, X·Z 최소/중심/최대로 맞춥니다.
   - **간격**: 바닥면 사이 간격을 같게 합니다(처음·끝은 그대로).
   - **기준 객체에 맞추기**: 마지막으로 클릭한 객체와 같은 방향·같은 지면 위 높이·같은 크기로 맞춥니다.
   - **기준 객체 속성 복사**: 크기·방향·매개변수·물리·구조에서 골라 나머지에 적용합니다. 맞지 않는 것은 건너뛰고 건수를 알려 줍니다.
3. **그룹**: Ctrl·⌘ + G로 묶고, Ctrl·⌘ + Shift + G로 풉니다. Ctrl·⌘ + D로 복제하면 새 그룹이 됩니다.
4. 왼쪽 **장면** 탭(아웃라이너):
   - 검색과 보기 필터(종류·숨긴 것만·잠긴 것만)
   - 그룹 접기·펼치기, 연필로 이름 바꾸기
   - **눈**: 편집 화면에서 숨기기. 숨겨도 시뮬레이션에는 그대로 있고 시뮬레이션 화면에 보입니다.
   - **자물쇠**: 잠그기. 잠긴 객체는 화면에서 클릭·상자로 잡히지 않고, 옮기거나 지울 수 없습니다. 장면 탭에서는 고를 수 있습니다.

## 7. 재난 배치

1. 오른쪽 **재난** 탭 → 재난 라이브러리에서 카드를 고릅니다. 한국어·영어로 검색하거나 범주 칩, 즐겨찾기(☆), 최근을 씁니다.
2. 지도 위에 미리보기(위치·영향 범위·설명)가 따라옵니다. 클릭하면 그 자리에 놓입니다.
   - **연속 배치**를 켜면 여러 개를 계속 놓습니다.
   - 실행 방식: **클릭 즉시 실행** 또는 **배치 후 실행**.
   - **완료** 또는 Esc로 배치를 끝냅니다.
   - 재난을 고르면 편집 도구는 저절로 풀립니다.
3. 놓은 재난의 핀은 끌어서 옮깁니다. 끄는 중 Esc를 누르면 제자리로 돌아갑니다.
   - 핀을 고르고 Delete를 누르면 지웁니다. 객체를 고르면 핀 선택은 풀리므로, Delete가 엉뚱하게 재난을 지우지 않습니다.
4. 세기·범위·시각은 재난 탭의 목록에서 고칩니다(기본/고급 칸). 이 편집과 배치·이동·삭제는 모두 Ctrl·⌘ + Z로 되돌릴 수 있습니다.

## 8. 시뮬레이션 실행·결과 확인·원본 복구

1. 아래쪽 재생(▶) 또는 재난 탭의 **실험 실행**: 위쪽이 **시뮬레이션 모드**로 바뀝니다.
2. 실행 중에도 재난 탭에서 인스턴스마다 일시정지·재개·중지·취소를 할 수 있습니다(지원하는 것만 단추가 보입니다).
3. 결과:
   - **분석** 탭과 아래쪽 이벤트 로그(시뮬레이션 요약)를 봅니다.
   - 건물을 고르면 손상·층별 변위·부재 상태가 보입니다.
   - 지진 중 건물은 층마다 다르게 흔들려 보입니다. 이 흔들림은 구조 계산값이고, 연약층이면 그 층이 더 기울어 보입니다.
4. **초기화**(시뮬레이션 이전 상태로 복구) 또는 **편집 모드**로 돌아가면 원래 월드 그대로입니다. 시뮬레이션은 편집 문서를 바꾸지 않습니다.
5. 고친 뒤 다시 실행합니다. 실행 중의 변화는 실행 취소로 되돌리지 않습니다. 실행 취소는 편집에만 해당합니다.

구조 모델 v2(새 프로젝트·기본 마을·프리셋은 켜져 있음, 오른쪽 **설정** 탭)에서는 무너진 칸만큼 건물의 충돌 공간이 줄어듭니다. 그래서 부서진 모서리에 보이지 않는 벽이 남지 않습니다. 다만 잔해가 그 칸 안에 쌓여 있거나 위층 바닥판이 아직 매달려 있으면 그 칸은 막힌 것으로 봅니다.

## 9. 저장·불러오기

- **자동 저장**:
  - 편집하면 약 1초 뒤 브라우저에 저장되고, 탭을 닫거나 다른 탭으로 갈 때도 저장됩니다.
  - 지형을 칠하거나 끄는 도중에는 저장하지 않고 끝난 뒤 저장합니다.
  - 저장 공간이 부족해 저장되지 않으면 알림이 나옵니다. 그때는 파일로 내보내세요.
- **파일**: 더보기(⋯) → **파일로 내보내기 (.json)** / **파일에서 가져오기 (.json)**.
- 브라우저에 남은 자동 저장을 읽을 수 없으면 원본을 백업해 두고 알려 줍니다. 더보기(⋯) → **읽지 못한 자동 저장 내보내기**로 그 파일을 받을 수 있습니다. 전처럼 조용히 덮어쓰지 않습니다.
- 잠금·숨김·그룹 이름은 파일에 저장됩니다. 이전 버전 프로그램으로 열면 이 세 가지는 빠집니다.
