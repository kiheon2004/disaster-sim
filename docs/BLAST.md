# Phase 24 — Explosion, Blast Wave & Shock Physics

공기 중으로 방출된 에너지가 **압력파**로 퍼져 나가고, 그 압력과 충격량이 **물리 하중**(힘·충격량)으로 바뀌어 건물·차량·사람·시설물·나무·파편·물에 전달되는 단계입니다. 운석 충돌(Phase 23)의 공중 폭발과 지표 충돌의 대기 결합 몫도 같은 경로를 쓰며, 지반 충격과 에너지를 나눠 갖지 않습니다.

이 프로젝트는 물리 현상을 **관찰하는 샌드박스**입니다. 폭발원은 **가상의 에너지 방출**(공기에 결합된 에너지 J)로만 정의되며, 폭발물의 종류·조성·질량·TNT 환산·배치 최적화·특정 대상에 대한 효과 극대화 기능은 **설계상 존재하지 않습니다**. 압력파 모델에도 고폭약 경험식(폭풍파 곡선)은 쓰지 않았습니다(§5). 실제 폭발물 성능 예측이나 피해 위험도 평가에 사용할 수 없습니다(§30).

## 2. Phase 23 잔여 성능 문제

### 2.1 충돌 순간 긴 프레임

`src/bench/impactFrame.bench.test.ts`가 Phase 23 첫 프레임 측정 장면(주택 121동 + 0.3 s 뒤 착지하는 직접 충돌)을 고정 스텝 하나씩 돌리며 스텝마다 시스템·물리 시간을 분리합니다.

측정에서 드러난 사실:
1. **이벤트 시작 스텝**에 `ImpactEvent.onStart`가 계획 전체(진입 + 궤적 + 크레이터 + 384 묶음 비행 + 지반 충격)를 계산 — 17–59 ms(부하에 따라).
2. **충돌 스텝**: 첫 지반 충격에서 구조 모델을 지연 생성(121동, 3–9 ms), 첫 지진 피해 패스에서 부품 용량 계산(1.5–3.7 ms), 지형·충돌체 갱신(2–15 ms).

원자적 물리 이벤트는 쪼개지 않고 **준비 작업만 시계 밖으로** 옮겼습니다.
- 이벤트에 선택적 `prepare(terrain)` — 예약할 때(시계 밖) 계획을 계산하고, `onStart`는 런타임 지형이 **처음 그대로**(변형 엔진 리비전 0)일 때만 재사용, 아니면 다시 계산. 같은 함수·같은 입력 → 결과 비트 동일.
- 지진·충돌·압력파가 있는 실행은 예약 시 구조 모델과 외장 부품 용량을 미리 생성. 지연 생성 시점에 하던 **잔여 강도 축소는 첫 활성화 때 그대로** 적용(`SeismicRuntime.activated`) → 결과 불변(골든·다중 재해·지진·충돌 테스트 통과).
- 크레이터 굴착·충돌체 교체·지형 메시 갱신은 한 스텝의 원자적 사건으로 유지(다른 현상이 중간 상태를 읽지 않음).

측정(부하가 높게 흔들린 상태 — 부하 16–34, 절대값보다 분해가 의미 있음): 준비 전 첫 스텝 20–66 ms의 대부분이던 계획 비용이 사라져 첫 스텝 10–16 ms; 충돌 스텝은 지형·충돌체 갱신(원자적) + 지면 상태장 갱신이 남음.

**같은 조건 A/B**(부하 ≈ 5, 같은 기계, 같은 프로파일러 — Phase 23 코드는 커밋 `5352309` 작업 트리에서 실행; `docs/bench-phase24-impact-frame.json`, `…-impact-frame-p23.json`):

| | 이벤트 시작 스텝 | 충돌 스텝 | 충돌 스텝의 구조 모델 생성(groundMotion) |
|---|---|---|---|
| Phase 23 (지반 예열 없음 / 있음) | 18–44 / 11–22 ms | 11–40 / 8–11 ms | 4–11 ms |
| Phase 24 (지반 예열 없음 / 있음) | — (시계 밖으로) | 8–30 / 6–11 ms | ≈ 1 ms |

**브라우저**(프로덕션 빌드, `scripts/probe-first-frame.mjs impact`, 두 빌드 번갈아 각 2회, 부하 3.9–6.7; `docs/bench-phase24-impact-firstframe.json`): 충돌 프레임 **58–60 ms → 46–49 ms**, 그 프레임의 시뮬레이션 틱 **≈ 25 → ≈ 17.5 ms**, 충돌 순간 50 ms 넘는 프레임은 Phase 23에서 매번, Phase 24에서 0회. 남은 비용은 원자적 지형·충돌체 갱신(≈ 10 ms)과 렌더링. 실행 시작 프레임(95–118 ms)은 두 빌드 모두 그 안에 28 ms GC가 있는 첫 실행의 시작 프레임입니다.

추가로 찾아 고친 Phase 23 문제: 한 스텝에 분출물 묶음 여러 개가 같은 물체에 떨어지면 `impact` 힘이 여러 번 적용되어 ForceLedger가 첫 번째 외에는 **거부**(운동량 손실, 벤치마크 장면에서 중복 2회). 스텝마다 물체별로 합산해 한 번 적용(중복 0).

| 장면 | 빌드 | 부하 | A(충돌 없음) FPS / 최악 | B(충돌) FPS / 최악 / 틱 | 힙 B |

| 건물 500 | Phase 23 | 4.1 | 60.1 / 22 ms | 59.3 / 55 ms / 4.55 ms | 61.2 MB |

### 2.3 GPU 자원 누수 회귀

압력파 시각 효과(압력장 격자, 파면 껍질, 섬광, 압력 벡터, 영향 링)의 모든 GPU 자원은 `useDisposable`(또는 같은 생성/해제 쌍)로 소유합니다. `scripts/stress-runs.mjs`에 압력파 장면 두 개(마을 위 압력파 2개 + 모든 오버레이, 충돌 + 대기 압력파)를 추가했습니다. 결과는 §26.3: 12주기 24회 실행에서 지오메트리·텍스처·리스너·DOM 일정, 프로그램 포화, 힙 추세 없음, Rapier 월드 모두 해제.

## 4. 에너지 분배와 보존

**가상 방출**은 입력 자체가 "공기에 결합된 에너지"이므로 분배는 대기 결합 100 %(지반 결합·열·분출물 0 — 지면 방출이 지반을 흔드는 효과는 계산하지 않음; 필요하면 지진/충돌을 함께 실행).

**운석**: Phase 23 분배를 재사용합니다.

| 항목 | 지표 충돌 | 공중 폭발 |
|---|---|---|
| Ground coupling (지진) | k_s·E (Phase 23) | 0 |
| Atmospheric coupling | `blast` = min(airCoupling·E_impact, 미해결) | `airburstBlast` = 공중 폭발 에너지(대기 몫의 일부) |
| Thermal / radiative | 미해결에 포함(모델링 안 함) | 압력파 모델의 근거리 소산에 포함 |
| Ejecta / mechanical | 분출물 운동(Phase 23) | 0 |
| Unresolved | 나머지(가열·용융·분쇄) | 진입 중 항력 손실 등 |

`airCoupling` 기본 0.02(2 %)는 **차수 수준 가정**입니다(편집 가능, 0.1–50 %): 수 km/s 충돌은 거의 기화하지 않아 공기 충격은 팽창하는 크레이터·분출물에서 생기고, Collins et al. (2005)은 충돌 에너지 전체를 폭풍 수율로 쓰는데(상한) 이를 따르지 않았습니다. 합 = 충돌 에너지(테스트, 상대 1e-12). 지반 충격 에너지는 `airBlast`를 켜도 **바뀌지 않습니다**(테스트).

**압력파 에너지 장부**(`ledger.ts`, HUD 막대): 입력 = 근거리 소산 + 충격 소산(월드 안) + 전파 중 + 월드 밖. 위쪽 반구 256 방향 광선으로 추적, 잔차 ~1e-7 J(입력 1e9 J). 물체에 전달된 일은 파에서 빼지 않습니다(선형 중첩 가정 — 몇 자릿수 작음). 정압 파형만 쓰면 부압 단계 에너지를 "적용 안 됨"으로 표시.

## 5. 대기 압력파 모델 (`source.ts`)

점에 E가 방출된 이상 기체(γ = 1.4)의 일반 모델입니다. **어떤 폭발물에도 맞추지 않았습니다.**

1. **Sachs 스케일링**: R₀ = (E/p₀)^(1/3), t₀ = R₀/c₀ — 기압·밀도(고도·날씨)가 일관되게 들어감.
2. **근거리 — 강충격 점 폭발**(Taylor 1950, Sedov 1959): R = ξ₀(Et²/ρ₀)^(1/5), ξ₀ = 1.033 → 강충격 도약 Δp = 2ρ₀U²/(γ+1) = **K·E/r³**, K = 8ξ₀⁵/(25(γ+1)) ≈ 0.157. Δp ≫ p₀에서 정확한 상사해(배압 무시).
3. **전이 반경** r_t: 그 과압이 p₀가 되는 곳, r_t = K^(1/3)·R₀ ≈ 0.54 R₀. 여기서 약충격으로 넘어가며, 정압 지속 시간은 그 지점의 자기 상사 시간 척도(도달 시각)로 둡니다(차수 1 닫힘, 표시). 그러면 펄스 에너지가 **따라 나옵니다**(선택하지 않음): E_p = (8π/3)r_t²Δp_t²T_t/(ρ₀c₀) ≈ **0.33·E**, 나머지는 강충격이 근거리에 남긴 열(근거리 소산).
4. **원거리 — 구면 약충격 N파**(Whitham 1974 §9.5; Landau & Lifshitz §102): 선형 진폭 P(r) = Δp_t(r_t/r)√(ρ(r)/ρ_s)(광선관 에너지 흐름 보존 — 고도 방출의 임피던스 보정), 나이 σ(r) = (1/T_t)∫βP/(ρc³)dr', β = (γ+1)/2. 등면적 충격 맞춤으로 **Δp = P/√(1+σ), T₊ = T_t√(1+σ), I₊ = ½ΔpT₊ ∝ 1/r 정확히**, 펄스에 남은 에너지 E_p/√(1+σ)(나머지는 충격에서 소산). `acoustic`은 σ = 0(모양 유지, 1/r, 손실 없음 — 상한).
5. **도달 시각**: 모든 구역에서 정확한 Rankine–Hugoniot 충격 속도 U = c√(1 + (γ+1)Δp/(2γp))로 t_a = ∫dr/U → 근거리·원거리가 끊김 없이 이어지고, 1차로 U = c(1 + (γ+1)Δp/(4γp))(약충격 속도, 테스트). `acoustic`은 r_t 밖에서 U = c.

**유효 구역**(국부 Δp/p): 약충격 ≤ 0.3(1차 이론, 충격 마하 ≤ 1.12) — **유효**; 0.3–3 전이 — 두 점근해 모두 부정확(근사, 경고); ≥ 3 강충격 상사(배압 무시, 근사); r < 0.02 r_t는 값 고정. 계획이 유효 반경·전이 반경을 계산해 편집기·미리보기·인스펙터·경고에 표시합니다. 대기 흡수·바람/기온 굴절·난류·실기체·복사는 없습니다.

## 6. 전파 시간

도달 시각은 방출점–수신점 거리의 표에서 읽습니다(로그 간격 480 마디, 도달 시각은 r에 선형 보간). 차폐되면 우회 경로 차 δ/c만큼 늦어짐(§9). 검증: 근거리·중거리·원거리·월드 경계(표 범위 밖은 1/r·음속으로 연장, 시뮬레이션은 질의하지 않음)·복수 원천(각자의 표). 같은 입력 → 같은 도달 시각(결정론 테스트, 브라우저 22). 원천 높이와 지면 반사: 영상파는 영상점에서의 거리.

## 7. 압력·충격량

| 양 | 단위 | 어디서 |
|---|---|---|
| 과압 Δp(t) | Pa | `pulse.ts` `pressure` |
| 압력 충격량 ∫p dt | Pa·s | `impulse` (닫힌식) |
| 힘 | N | 면 충격량 × 면적 / Δt, 항력 |
| 기계적 충격량 | N·s | 면 압력의 시간 적분 × 면적 |

- **파형**: 정압 단계 Δp(1 − τ/T), N파는 이어서 부압 단계와 후방 충격. 약충격 구역에서 대칭 N파(Δp₋ = Δp). 근거리에서 대칭 N파는 비물리적(밀어낸 만큼 끌어당김)이라 **부압 진폭을 0.3 p로 제한하고 같은 충격량**(T₋ = ΔpT/Δp₋)을 유지 — 원거리 성질 ∫p dt = 0 보존(가정, 표시).
- **정확한 스텝 적분**: 모든 하중은 스텝 구간의 닫힌식 적분 → 충격파가 스텝 중간에 와도 그 스텝의 충격량이 정확, **시간 간격과 무관하게 총 충격량 동일**(테스트: 1/30, 1/60, 1/240, 0.0071 s).
- **적분 커서**: 객체마다 "여기까지 적분" 시각을 가져 첫 평가 스텝 이전에 도달한 충격량도 한 번에 정확히 전달(실행 중 발견: 0.5 s 시작 이벤트가 고정 스텝 누적 오차로 한 스텝 늦게 시작해 정압 단계를 잃던 문제).
- **압력을 힘으로 쓰지 않음**: 압력은 항상 면적 × 시간 적분을 거쳐 N·s → 힘 = 충격량 / Δt.

## 8. 전파 기하

3차원 거리(원천 높이·지형 높이차 포함). **지면 반사**(강체 지면, 원천 아래 평면): 지면 방출 = 반구로 퍼지는 자유 공간 2E 파(완전 반사; 실제 지면 흡수는 없음), 높은 방출 = 직접파 + 지면 영상파(선형 중첩, 지면 근처에서 2배 — 정상 반사), 그 사이(h < 2r_t)는 w = h/(2r_t)로 연속 혼합(테스트: 높이에 따라 과압 연속). 고도 방출(공중 폭발 수 km)은 등온 지수 대기에서 원천 고도의 대기로 R₀를 정하고, 월드 중심을 향한 광선을 따라 임피던스 보정과 나이를 적분. 월드 경계는 열려 있음(반사 없음, 장부의 "월드 밖"). 건물 사이 반사·회절·마하 줄기는 계산하지 않습니다 — **고정밀 도시 폭풍파 해석이 아닙니다**.

## 9. 지형·장애물 상호작용

- **지형 차폐**: 원천–수신점 직선을 지형 높이와 비교해 직선 위로 솟은 지형 중 경로 차 δ가 가장 큰 모서리(능선)를 찾음. 수신점 바로 아래 지면은 반사 평면이므로 제외(양의 δ만).
- **건물 차폐**: 건물 상자(바람 장애물과 같은 상자)를 평면에서 직선이 지나면 지붕 위 경로와 양 옆 모서리 우회 중 짧은 쪽의 δ.
- **삽입 손실**: 프레넬 수 N = 2δ/λ, λ = 2cT₊(펄스 길이), Maekawa 방음벽 도표의 Kurze–Anderson 식 IL = 5 + 20 log₁₀(√(2πN)/tanh√(2πN)) dB, **최대 20 dB** — 능선 뒤라도 완전히 막히지 않음(테스트: 5–80 %). 진폭(과 충격량)에 적용, 도달은 δ/c 늦음.
- **노출 분류**: 직접 / 지형 차폐 / 건물 차폐(손실 dB) + 지면 반사파 포함 여부, 유효 구역 — 인스펙터·객체 상태.
- **노출 방향**: 객체의 면마다 법선과 전파 방향으로 정면(반사)·측면·후면을 구분(§11–12).
- 근사로 표시: 단일 지배 모서리, 다중 모서리·건물 반사·거리 채널링·펄스 모양의 회절 변화 없음. 붕괴한 건물은 더 이상 가리지 않음(활성화 시점의 상태).

## 10. 복수 압력파

원천마다 독립된 파(각자 표·장부·출처). **중첩 정책**: 과압은 선형 합(음향 중첩 — 약충격 구역에서 타당, 강충격끼리의 비선형 상호작용 없음), 반사 계수는 각 파의 진폭으로. **구조 손상 합성 정책**: 손상은 하중을 합한 하나의 구조 응답에서만 생김(파별로 손상을 더하지 않음 — 같은 구조 모델·같은 부재 SDOF가 모든 파의 하중을 함께 받음). 부재 SDOF는 나중 파가 와도 상태를 이어감. 피해 기록 출처는 그 객체에서 가장 강한 파의 현상. 결정론적 순서: 스케줄러 순서와 고정된 반복 순서(테스트: 같은 실행 두 번 비트 동일).

## 11. ForceLedger 연동

새 원천 `blast`(비트 64, 색인 6). 자유 물체·파편의 압력파 힘은 **이 경로로만**, 스텝당 물체당 한 번(면 하중 + 항력 + 모든 파의 합). 구조물은 강체 힘이 아니라 구조 모델 외부 하중(§12). 중복 0(모든 테스트·벤치마크·브라우저). 힘 = 스텝 충격량 / Δt, 작용점 = 순충격량과 모멘트로 정한 압력 중심(모멘트 보존, 비틀림 성분 제외). 정확성: 시간 간격 독립(§7), 도달 전 힘 0(테스트·브라우저 7: 첫 힘 스텝 시작 ≥ 계산 도달 − Δt).

**물체 하중 모델**(`loads.ts`, 근사로 표시):
- 객체 = 방향 있는 바운딩 박스, 면마다 **그 면 중심에서의 도달**(앞면이 먼저 → 회절 단계의 밀기가 횡단 시간에서 나옴).
- 정면: 반사 C = 1 + (C_r − 1)cos θ, C_r = Rankine–Hugoniot 정상 반사 2(약)…8(강), 해소 시간 3S/c 동안 측면 압력으로 감소(간이 해소 공식).
- 측면: 측면 압력. 후면: (1 − |cos θ|)p에서 4S/c 동안 p로 증가(파가 돌아 들어옴; 간이 후면 이상화) — 이것이 없으면 짧은 펄스가 물체를 원천 쪽으로 끌어당기는 비물리적 결과(발견·수정).
- 바닥면: 자유 물체는 포함(차량 하부 간극, 수 ms 안에 압력이 들어감) — 없으면 지붕 압력이 차를 땅에 박아 튀어 오르게 했음(발견·수정). 지면에 고정된 구조물은 제외.
- 항력: ½ρ₂C_dA|u − v|(u − v), Rankine–Hugoniot 입자 속도와 충격 후 밀도 → ½ρ₂u² = 5Δp²/(2(Δp + 7p₀))(γ = 1.4의 정확한 동압).
- 다공·가는 물체는 기존 정면 면적비(areaFactor).

- **Phase 25 고급 연쇄 붕괴를 완성한 것이 아닙니다**: 낙하 바닥의 동적 충격, 접합부, 잔여 강도 진화는 Phase 17 수준.

## 13. 시설물 반응

가로등·표지판·담(벽)은 구조 모델 단위(SDOF, Phase 13 성질)에 면 충격량 + 항력을 횡하중으로 → 손상 지수 ≥ 1에서 전도/붕괴(지진 경로 기록, blast 귀속). 부착물(램프 헤드·표지판 판)은 SDOF 부재로 탈락. 유효 면적은 박스 면 × 정면 면적비, 방향은 면 법선. 가드레일·도로 시설은 이 프로젝트에서 별도 객체가 아니라 도로 표면의 일부이므로 개별 반응이 없습니다(가로등·표지판·담이 도로변 시설물). **도로 자체는 공기 압력으로 들리지 않습니다** — 지형 불변(테스트).

## 14. 차량 반응

차량 박스(바닥 포함) 면 하중 + 항력 → ForceLedger `blast` 힘을 압력 중심에 → 이동·회전·전복은 Rapier 접촉·마찰 해. 도달 전 힘 0(브라우저 7: 첫 힘 스텝 1.0167 s ≥ 도달 1.0182 − Δt). 원천에서 멀어지는 방향으로 밀림(테스트·브라우저). 귀속: 최근 지배 힘이 blast면 `MOVED`/`OVERTURNED` blast.

## 15. 사람 반응

- **밀림**: 계산값(ForceLedger, 박스 면 하중 + 항력).
- **균형 상실·넘어짐**: 파 방향의 누적 속도 변화의 최대값이 강체 전도 한계 √(2g(√(h²+b²) − h))(Housner 1963)를 넘으면 — **역학적 근사 기준**, 생리 아님.
- **넘어지는 동작**: 기존 쓰러짐 연출(토크·밀기 — 시각 근사).
- **충돌**: Rapier 접촉(기존 충돌 피해).
- 장기 손상·생리학적 폭발 피해 예측은 **하지 않습니다**. 인스펙터에 이 구분을 표시합니다.

## 16. 지반 충격과의 분리

같은 운석에서 지반 충격(지반 운동장, `impact` 해저드)과 대기 압력파(압력 채널, `blast` 해저드, 출처 `impact:p1`)가 함께 생기지만 에너지는 분배표에서 따로(지진 = k_sE, 대기 = 미해결 몫에서) — 지반 충격 에너지는 `airBlast`와 무관하게 같음(테스트). 건물은 두 하중을 **각각** 받습니다(지반 가속도 → 구조 모델 `agx`, 압력파 → `fbx`; 같은 모델에서 합쳐진 응답 하나). 피해는 지배 하중으로 원인별 기록(테스트: 지진 몫 PGA와 압력파 aEq 모두 > 0, 기록이 blast/impact로 분리, 바람 0).

## 17. 물 상호작용

얕은물 모델의 범위 안에서만: 상호작용이 켜져 있으면 BlastSystem이 물이 있는 셀마다 그 스텝의 ∫p dt를 정확히 적분해 `WaterForcing.airImpulse`에 쌓고, 다음 솔버 호출이 면 유량에 −h·∂(∫p dt)/∂x/ρ_w를 호출 비율대로 더한 뒤 지움. **운동량만** 바뀌므로 질량 정확(테스트 1e-9, 브라우저 18). 지나가는 펄스의 운동량은 Δp/(ρ_w c) 수준(cm/s) — 결과도 그렇습니다(테스트 < 1 m/s). 수중 충격파·물 공동·실제 쓰나미는 **계산하지 않습니다**.

## 18. 지형 상호작용

대기 압력파만으로는 크레이터를 만들지 않습니다(테스트: 지형 불변). 크레이터는 Phase 23 충돌 모델만 만듭니다. 이 압력 수준(≤ MPa, ms)에서 흙을 파내는 공기 충격의 물리 모델은 범위 밖이며, 지형 변형이 필요하면 Phase 21–23 공통 경로를 쓰는 현상을 함께 실행합니다.

## 24. 저장·불러오기

스키마 **v7 유지**: 압력파는 실험 인스턴스로 저장(에너지·모델·파형·대기 조건·시작). v1–v7 불러오기 회귀 통과. 범위 밖 에너지의 인스턴스는 버려짐(고치지 않음). Phase 23 이전 저장의 충돌 스펙은 `airBlast`가 없어 **대기 압력파 끔**으로 불러옴(저장한 대로 재현). 새 충돌은 기본 켬. 실행 중간 상태(파·부재 진동)는 저장하지 않으며 저장 시 기존 안내(런타임 상태 목록에 `blastWaves`(파생)·`blastObjects`(상태) 추가).

## 27. 과학적 검증

| 항목 | 방법 | 결과 |
|---|---|---|
| 근거리 | Δp = KE/r³(Sedov), r_t/R₀ = K^(1/3), Δp(r_t) = p₀ | 상대 1e-3 |
| 원거리 | 약충격 닫힌식 Δp, T₊, 남은 에너지 | 상대 1e-3 |
| 충격량 | I₊·r 일정(약충격) | 1e-3 |
| 도달 = 거리/속도 | 음향: Δt = Δr/c 정확; 약충격: 조금 빠름(0.98–1.0); R–H 1차식 | 일치 |
| Sachs 스케일링 | r/R₀ 고정 시 Δp/p₀가 E와 무관, 저기압에서 R₀ 증가 | 확인 |
| 반사·입자 속도 | R–H 2…8, 약충격 Δp/(ρc) | 일치 |
| 단위 | 압력 Pa → 면적·시간 적분 → N·s → 힘 = 충격량/Δt | 구조적으로 보장, 테스트 |
| 시간 간격 독립 | 스텝 4종에서 총 충격량 | 1e-10 |
| 도달 전 힘 없음 | 첫 힘 스텝 ≥ 도달 − Δt | 통과(테스트·브라우저) |
| 중첩 결정론 | 두 파, 두 번 실행 | 비트 동일 |
| 지반 충격 / 압력파 중복 | 분배 합 = 충돌 에너지, 지반 충격 에너지 불변 | 1e-12 |
| 하중–반응 연결 | 구조 모델 횡하중/질량 = 객체 aEq; SDOF = 삼각 펄스 해석해(충격·준정적 구간) | 정확 / 10 % 이내 |
| 상자 하중 | 닫힌 상자 균일 압력 → 0, 측면 압력만의 통과 → 순충격량 0, 반사가 밀기를 만듦 | 일치 |
| 차폐 | 능선 뒤 감소·지연, 0 아님, 그늘 | 확인 |
| 물 | 질량 | 1e-9 |
| 원본 복원·재실행 | 지문, 위치, 기록 | 비트 동일 |

해석적 비교는 위의 닫힌식(Sedov 상사해, 약충격 이론, 선형 음향, Rankine–Hugoniot, SDOF 해석해)입니다. **실제 고폭약 충격파나 복잡한 도시 반사파의 정확성은 주장하지 않습니다.** 과학적 일관성(위 표)과 시각적 완성도(§21)는 따로 평가했습니다.
