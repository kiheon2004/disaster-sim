# 사용성·물리적 설득력 수정 (Phase 35.5)

Phase 35(차량)와 Phase 36 사이의 수정 단계입니다. 실제로 프로그램을 쓰면서 나온 여섯 가지 불편을 고쳤습니다:
재난 위치를 마우스로 지정, 같은 재난의 여러 독립 인스턴스, 간결한 중앙 하단·오른쪽 UI, 스크롤 없는 재난 선택,
도로 단면 통일, 구조 형식에 따른 건물 변형·부분 붕괴·연쇄 붕괴. 기능은 지우지 않았고, 이전 파일·이전 결과는 그대로입니다(§10, §23).
사전 감사는 `docs/PHASE35_5_PREIMPLEMENTATION_AUDIT.md`, 작업 기록은 `~/projects/disaster-sim-work/phase355/`.

## 1. 개발 목적

목표는 기능을 늘리는 것이 아니라 **이미 있는 기능을 쓰기 쉽게, 이미 있는 물리를 더 그럴듯하게** 만드는 것입니다.
UI·명령어·실험 목록은 모두 같은 내부 실행 경로(`SimulationController.addEvent`)와 같은 인스턴스 모델(`PhenomenonInstance`)을 씁니다.
새 구조 거동(v2)은 설정 하나(`settings.simulation.structure`)로 켜지며, 새 프로젝트와 기본 월드에서만 기본으로 켜집니다.

## 3. 기존 구조

- 실행: UI(`runSimulation`)·명령어(`commandTarget.runEvents`)·실험(`runExperiment`) → `simulationController.addEvent(spec)` → `EventScheduler`.
  스케줄러는 같은 `channel`의 진행 중 이벤트를 대체합니다. 리셋하면 `scenario[]`를 다시 예약합니다.
- 인스턴스 모델은 Phase 15부터 있었습니다(`PhenomenonInstance`, 저장 스키마 v5). 새로 만들지 않고 이것을 단일 출처로 썼습니다.
- 사전 감사의 9개 질문 답: `docs/PHASE35_5_PREIMPLEMENTATION_AUDIT.md` §1.

## 4. 재난 위치 지정 (배치 모드)

흐름: **라이브러리 카드 → (설정) → 지도 위로 포인터 → 클릭 → 그곳에서 발생**. 좌표 숫자 입력은 인스턴스 편집기의 "고급 설정"에 남아 있습니다.

- 상태(UI 전용, `src/ui/placement/placementStore.ts`): 비활성 → 미리보기(카드 선택, 포인터가 지도 위) → 배치(클릭) → (연속 배치면 다시 미리보기)
  → 완료/취소(Esc, 완료 버튼, 다른 카드). 배치한 재난 자체는 문서의 실험 인스턴스입니다.
- 3D 층(`src/rendering/placement/PlacementLayer.tsx`)은 편집·시뮬레이션 장면 모두에 붙습니다. 클릭은 편집 도구·카메라보다 먼저 잡고(창 캡처),
  배치 중이 아닐 때는 핀 근처(화면 14 px) 클릭만 잡으므로 객체 선택·카메라 조작은 그대로입니다.
- 실행 방식: **배치 후 실행**(기본 — 여러 곳을 놓고 한 번에 실행) / **클릭 즉시 실행**. 같은 `runSimulation` 경로입니다.

## 5. 마우스 피킹

화면 좌표 → 카메라 광선 → `samplerFor(현재 지형).raycast` (변형된 지면 포함, 원근 투영, 월드 경계 밖은 무시). 재난별 위치 규칙
(`src/phenomena/catalog.ts` `placement`):

| 규칙 | 재난 | 클릭이 정하는 것 |
|---|---|---|
| ground | 폭발, 운석, 싱크홀, 화재, 열원, 화산, 물 유입, 지형 변형, 소용돌이 | 지표면의 한 점 |
| space | 가변 중력(국소 원천), 블랙홀·천체 | 클릭한 지면 위 공간(높이는 설정값 유지) |
| area | 비(원형 강우 영역), 기후 영역, 산사태 원천, 국소 대기 제거 | 범위의 중심 |
| edge | 수위 상승 | 가장 가까운 지도 가장자리 |
| epicentre | 지진 | 진앙(지도 좌표, 깊이는 설정값) |
| global | 전역 바람(태풍), 전역 중력, 지도 전체 기후 | 위치 없음 — 카드가 곧바로 추가 |

## 6. 배치 미리보기

포인터 위치에 핀 + 영향 범위 원 + 이름·좌표·범위·강도 문구(3D 라벨과 배치 막대에 같은 문구). 범위가 실제 물리 경계가 아닌 안내값이면
**점선 + "참고 범위"**: 폭발은 유리 파손 과압 7 kPa의 환산 거리(Kingery–Bulmash Z ≈ 18 m/kg^⅓ × TNT 환산 질량^⅓ — 압력파 자체는 월드 끝까지
계산됨), 싱크홀은 공동 반경 + 덮개 두께, 운석은 지름 × 12, 열원·화산·중력원은 고정 안내값. 실선은 모델 입력 그대로(소용돌이 영향 반경, 강우 원,
점화 반경, 유입 반경). 3D 라벨은 화면 크기 고정 스프라이트(React 루트를 따로 만들지 않음 — drei `<Html>`은 장면 전환 때 경고를 냈음).

## 7. 연속 배치와 조작

연속 배치가 켜져 있으면 클릭마다 새 인스턴스가 생기고 도구가 유지됩니다. 키(배치 키가 다른 단축키보다 먼저, 편집·시뮬레이션 모두):

| 키 | 동작 |
|---|---|
| 클릭 / 포인터 이동 | 배치 / 미리보기 |
| Esc | 배치 끝내기, 아니면 선택한 핀 해제 |
| Delete / Backspace | 선택한 재난 삭제(실행 중이면 시작 전 취소 또는 중지) |
| Ctrl/⌘+Z, Ctrl/⌘+Shift+Z | **배치** 되돌리기·다시 — 배치 중이거나 재난 탭에서 배치 기록이 있을 때. 그 밖에는 월드 편집 되돌리기(두 기록은 분리) |
| 핀 드래그 | 위치 이동(카메라 잠금) — 실행에 들어간 재난은 옮길 수 없음(복제해서 새로) |
| 숫자 입력 | 인스턴스 편집기 "고급 설정"의 X/Z |

## 8. 다중 재난 인스턴스

- 종류(정의 = `ImplementedPhenomenon`)와 인스턴스(`PhenomenonInstance {id 'p3', type, spec, enabled, start, seed?, visualize}`)는 이미 분리돼
  있었습니다. 실행 측에는 **인스턴스 키**를 더했습니다: 실험 인스턴스는 그 id(`p3`), 직접 시작한 이벤트는 `<종류>#<n>`. 이름이 있는 재난이
  이름 없이 오면 키가 원천 이름이 됩니다 → 같은 종류 두 개가 장부·결과에서 섞이지 않습니다(이전에는 무작위 이벤트 id).
- 채널: 폭발·화재·열원·운석·싱크홀·산사태·지형 변형·화산·중력·천체·대기·기후·물 유입은 이미 인스턴스별 채널. **지진은 이제 인스턴스별**
  (지반 운동장이 여러 지진을 선형 중첩, §9), **원형 강우는 인스턴스별**, 지도 전체 비와 전역 바람은 하나의 날씨 상태라 새것이 대체(문서화).
- **소용돌이 바람**(계획 상태이던 `tornado`를 구현): Holland(1980) 접선 풍속 형상, 유입각, 회전 방향, 이동 경로, 유한 영향 반경, 발달·소멸.
  여러 개가 서로·전역 바람과 벡터로 더해집니다. 태풍의 최대풍 반경은 수십 km라 200 m 지도에서는 균일한 전역 바람이고, 지도 위에 놓는
  소용돌이는 토네이도·회오리 규모입니다(편집기 가정 문구). 명세 시나리오 4의 "태풍 두 개"는 소용돌이 두 개로 검증했습니다(§24).
- 인스턴스별 제어(`SimulationController.controlEvent(key, op)`): 시작 전 **취소**, 지속형 원천의 **중지·일시정지·재개**(지진·비·수위·물 유입·
  소용돌이; 중지만: 바람·열원), 한 번에 방출된 것(압력파·운석)은 멈출 수 없음(이유 표시). 실행 중 값 변경은 다음 실행부터.
  제어는 시각과 함께 시나리오에 기록되어 리셋하면 **비트 단위로 재현**(시험).
- 실행 중 "실험 적용"은 이미 실행에 들어간 인스턴스를 다시 넣지 않습니다(이전에는 모두 다시 넣어 중복).

## 10. 저장 호환성

- 인스턴스는 기존 `doc.scenario.experiment`(스키마 v5) 그대로 — 저장 형식 변경 없음. 실행 키·제어 기록은 실행 상태(저장 안 함).
- 새 설정 `settings.simulation.structure = { model: 'v2' }`(없으면 v1). 새 도로 단면 칸 `shoulderWidth`, `medianWidth`(선택; 없으면 0 =
  이전 도로 기하와 같음). 옛 파일은 아무것도 바뀌지 않고 같은 결과(§23 동일성).
- 이전 단일 지진·홍수 폼 설정(`scenario.earthquake`, `scenario.flood`)은 "상세 설정 폼"으로 그대로 남아 같은 경로로 실행됩니다.

## 11. UI 재구성

- **중앙 하단**: 재생/일시정지·리셋·시간·이벤트 트랙·배속(타임라인) + 지진 중 지진계 + 접히는 명령어 서랍. 재난 폼·명령 콘솔이 상시 차지하던
  262 px가 사라졌습니다.
- **오른쪽**: 탭 4개 컨텍스트 패널(선택 / 재난 / 분석 / 설정), 닫기 가능(뷰포트 오른쪽 위 "패널 열기"). 선택 = 고른 것의 속성(지형·건물·도로 도구,
  여러 객체, 객체 하나 + 시뮬레이션 실시간 섹션) 또는 월드 개요. 재난 = 배치 막대 + 라이브러리 + 배치한 재난 목록(상태·제어) + 접힌 상세 폼.
  분석 = 시뮬레이션 요약·로그·탐침·도로. 설정 = 시뮬레이션 설정·상호작용·구조 v2·단축키. 문맥 따라가기: 객체를 고르면 선택 탭, 카드·핀을 고르면 재난 탭.
- **Progressive disclosure**: 인스턴스 편집기와 배치 막대 모두 기본 칸(재난별 목록, `catalog.ts basic`)만 보이고 나머지는 "고급 설정"(기억됨).
- **뷰포트**: 오른쪽 위 정보 패널(HUD) 묶음 접기, 오른쪽 아래 표시 설정 접기(새 사용자는 접힘).
- **상태 분리**: 월드 문서 / 재난 설정(문서) / 선택(편집기) / 패널·탭·즐겨찾기·접힘(UI, 브라우저 저장) / 배치 임시 상태(UI) / 런타임(컨트롤러).
  UI 상태는 결과를 바꾸지 않습니다.
- 이전 사용자 호환: 예전 `ds.hazardTab` 기록이 있으면 재난 탭·상세 폼·고급 칸이 펼쳐진 채 시작합니다.

## 19. 하중 전달

자중·적재·잔해는 부재 그래프로 아래로(Phase 25 솔버: 지지 단계, 대체 경로, 갑작스런 상실의 동적 계수). 지진은 층 모델(≤ 5 자유도)의 층간 변위 →
각 부재의 변위 용량, v2는 **비틀림 증폭** δ = 1 + 0.6·d/L(강성 중심에서 흔들림 방향에 수직인 거리 d, 평면 치수 L — EC8 우발 비틀림 형식)로
모서리·외곽 부재가 먼저 한계에 닿습니다. 바람은 외장 부품별(국소 풍속·Cp) + 전체 피로, 폭발은 벽면별 압력·충격량(SDOF), 홍수·운석 분출물은
v2에서 하중을 마주한 면의 부재로(§20), 지반 침하는 기초 부재별 지지, 열은 부재별 강도 저하.

v2 **부재 거동 단계**: 이용률 u(요구/용량) — u ≤ 1 탄성, 1 < u ≤ u_p 항복·소성(손상 증가, 내력 유지), u_p < u ≤ u_f 연화(내력 → 잔존), u > u_f 파괴.
법칙은 자기 연화를 뺀 이용률 위의 고정점이라 반복 증폭이 없고, 법칙이 낮춘 내력은 점진 변화로 다뤄 동적 증폭을 받지 않습니다.
같은 점진 과재하(u = 1.2): v1은 RC 기둥 그대로, v2 RC는 연화(손상 > 0.3)하며 섬, v2 조적은 u = 1.12에서 파괴(v1은 섬) — 시험.

## 21. 연쇄 붕괴와 전도

- 재분배·대체 경로·충돌 압괴(팬케이크)는 Phase 25 엔진. v2 **전도**: 지지를 잃은 블록이 한쪽에서 아직 서 있는 지지 부재에 매달려 있으면 그
  연결점들의 주축이 힌지선이 되고, 질량중심이 힌지선 밖 0.3 m 이상이면 블록이 힌지선을 축으로 **회전**합니다(1 자유도, 중력 모멘트
  M·g·(수평 팔), 부재 상자 관성). 회전은 마찰 없는 힌지의 에너지 적분 ½·I·ω² = M·g·Δh로 ω를 정해 에너지가 정확히 보존됩니다. 연결 형식의 해제
  회전(조적 0.06 … 철골 0.6 rad)에 닿거나 땅에 닿으면 질량중심 속도로 자유 낙하하고 기울어진 채 떨어집니다. 부재는 실제 방향으로 그려집니다.
- 장부: 회전 중 위치에너지 → 회전 운동에너지, 찢어질 때 자전 에너지는 손실로, 회전에서 얻은 수평 운동에너지는 착지 때 손실로 기록 —
  질량 잔차 < 1e-9, (충돌 + 흡수 + 지면) / 방출 = 1(1e-6) — 시험.
- 지진으로 옆으로 움직이는 블록(구조 속도 > 0.5 m/s)은 힌지 없이 떨어집니다(그 운동이 우세).

## 26. 과학적 한계

- 모두 교육용 축약 모델입니다. 실제 건물의 붕괴·도로의 성능을 예측하지 않습니다.
