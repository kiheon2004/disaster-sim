# Phase 32 — Black Holes & Extreme Celestial Gravity

사용자가 세계 안에 **블랙홀(연화 점질량 + 포획 반경)** 이나 **압축 천체**를 놓으면, 그 중력이 Phase 31의 중력장 g(x, t)에 더해지고
같은 장을 모든 시스템이 읽습니다. 물체는 궤도를 돌거나 탈출하거나 포획되고(KDK 궤도 적분기), 구조물은 층별 수평 하중과 들림으로
변형·파괴되며, 포획된 질량·운동량·에너지는 장부에 남습니다.

> **뉴턴 역학 계산과 교육용 축약을 구분합니다.** 실제 G·실제 질량으로 계산하지만, 연화(ε)·포획 반경·원반·렌즈는 교육용 모델과 시각
> 효과입니다. 일반상대론(사건의 지평선, 시간 지연, 광선 휘어짐 …)은 계산하지 않습니다. 실제 천체 현상의 예측이나 안전 판단에 쓸 수
> 없습니다. 구조 모델은 인증된 FEM이 아닙니다.

## 4. 뉴턴 중력

- G_N = 6.67430·10⁻¹¹ m³/(kg·s²), c = 299 792 458 m/s — 바꾸지 않습니다(교육용 모드도 G가 아니라 질량을 고름).
- 원형 궤도 v_c = √(μ/r), 탈출 v_e = √(2μ/r), r_s = 2GM/c²(태양 2953 m — 시험).
- 중력원 사양: 위치, 질량 M(kg; μ = G·M 일관 변환), 종류(블랙홀/압축 천체), ε, 포획 반경, 영향 반경, 시작·종료, 질량 램프, 질량 정책,
  이동 방식(고정·일정 속도·경유점 경로), 시각 효과. 편집기는 log₁₀ M, μ, 교육용 "기준 거리의 |g|" 세 방식으로 같은 질량을 정합니다.

## 5. 연화 모델

g_ε = −μ r⃗/(r² + ε²)^{3/2}, Φ_ε = −μ/√(r² + ε²) (Plummer). 최대 |g| = 2μ/(3√3 ε²)를 r = ε/√2에서 가집니다(시험). **ε 안쪽은 실제
블랙홀 부근 장이 아닙니다** — GUI가 ε 구(청록)를 그리고 "연화 핵" 영역을 표시합니다. ε이 작으면 필요한 하위 스텝이 늘어 교육용 모드는
한계를 넘는 조합을 거부합니다(§11).

## 6. 퍼텐셜

무제한 장은 Φ → 0(무한원). 영향 반경 R을 주면 바깥 20 %에서 smootherstep으로 장을 0까지 줄이고(교육용 차단), 퍼텐셜은 그 장의
적분으로 일관되게 둡니다: 안쪽은 닫힌 식 + 테이퍼 구간 Simpson 128칸(이음매 불연속 < 10⁻⁹·|Φ|, 시험). 퍼텐셜이 있으면 Phase 31 장부의
U·W_field가 그대로 동작합니다(점질량원은 보존장).

## 7. 중력 구배

T_ij = μ·w·(3 r_i r_j/q^{5/2} − δ_ij/q^{3/2}) + g_i w′(r) r_j/r, q = r² + ε² — 해석식. 독립 검증: 중심 차분과 비교(10⁻⁶), **Poisson
대각합** = −3με²/q^{5/2}(ε = 0이면 0), 점질량 고유값 2μ/r³, −μ/r³, −μ/r³. `GravityField.gradient`는 Phase 31 국소원 부분만 수치
미분하고 점질량원은 해석식을 더합니다(국소원이 없으면 Phase 31과 같은 값).

## 8. 조석력

Δg = g(x + d) − g(x) ≈ T·d. 균일장은 T = 0 → 조석 없음(시험). 주 늘림 λ₁(최대 고유값)과 축(고유벡터)을 오버레이·인스펙터에 표시하고,
균일 막대의 중앙 인장 N = m·λ·L/8을 참고값으로 보여 줍니다(차량·사람의 내부 파괴 모델은 없음 — Phase 33/35). 긴 강체에는 **중력 구배
토크** τ_i = ε_ijk S_jl T_kl(S = 상자 2차 모멘트)을 각충격량으로 적용합니다 — 45°로 놓인 물체가 반경 방향으로 돌아섬(시험, 정렬 시 0).

## 9. 궤도

원·타원·포물선 경계·쌍곡선·근접 통과·산란·포획을 같은 장에서 계산합니다. 시험체(probe)는 실험 시작 시 생성되는 구(질량·반경 지정,
감쇠 0 — 진공 가정)이며 초기 속도는 원형/탈출 속도 × 배수(반경에 수직으로 투영) 또는 직접 지정입니다. 편집기와 미리보기는 단일·비연화
중력원의 원뿔곡선(해석해)을 보여 주고, 연화·균일장·복수 중력원·이동이 있으면 "근사"라고 표시합니다.

## 10. 적분기 — KDK

v½ = v + ½h g(x); x′ = x + h v½; v′ = v½ + ½h g(x′). 2차·심플렉틱·시간 대칭(고정 h) — 결합 궤도의 에너지 오차가 누적되지 않고 진동.
경로 일 W = Σ ½(g + g′)·Δx(사다리꼴). 독립 검증(`celestial.test.ts`): 케플러 방정식 위상(5바퀴 후 1 %), 비스비바 근·원점, 러더퍼드 편향
2·asin(1/e), 자유낙하(사이클로이드) 포획 시각, **오차 ∝ h²**(dt 절반 → 1/4), 원 궤도 20바퀴 반경 3·10⁻⁴·에너지 2·10⁻⁴, 각운동량 10⁻¹⁰.
단순 전진 Euler는 쓰지 않습니다.

## 11. 적응형 하위 스텝

h ≤ η·τ, η = 0.02, τ = 스텝 직선 경로의 최근접점에서 min(q^{3/4}/√μ, √q/|v|). n = 2^⌈log₂(dt/ητ)⌉ — 상태와 장만의 함수라 같은 상태는 늘
같은 분할(결정론, 객체 순서 무관). 상한 256(1/60 s당). 넘으면 **조용히 포기하지 않습니다**: 상한으로 진행하고 `capped`를 세며 한계
이벤트를 기록하거나(경고 정책) 실행을 멈춥니다(정지 정책, §19). 교육용 모드는 포획 반경(압축 천체는 중심)까지 상한 안이 아니면 사양을
거부합니다(`celestial.invalid.core`).

## 12. Rapier 연동

Rapier는 접촉·충돌·강체를, KDK는 극한 장의 자유 비행 정확도를 맡습니다. 같은 상태를 두 번 갱신하지 않도록 **Rapier의 중력 증분만**
교체합니다(측정: Rapier 0.21, 해석 반복 n = 4에서 상수 가속도 응답 x₁ = x₀ + v₀dt + κ a dt², κ = (n+1)/(2n) = 0.625, v₁ = (v₀ + a dt)/(1 + d dt)):

  x₁ ← x₁ + (x* − x₀ − v₀dt) − κ g dt²,   v₁ ← v₁ + ((v* − v₀) − g dt)/(1 + d dt)

x*, v*는 같은 장의 KDK 결과입니다. 다른 힘(바람·물·폭발)과 감쇠가 그 스텝에 한 일은 남습니다. 대상: 깨어 있고 그 스텝에 **해석
접촉이 없는** 동적 물체(`PhysicsEngine.touching` — contactPairsWith/numSolverContacts). 상태 전환: 자유 궤도(KDK) → 접촉(Rapier 1차) →
충돌·파괴·파편(기존) → 포획(제거) → 세계 이탈(±800 m). 장부는 KDK 물체를 `bodyPath`로 기록합니다(W = 경로 일, ε = W − ΔK_kdk, J = mΔv) —
에너지가 임의로 변하지 않습니다(원 궤도 ΔE/E 6·10⁻⁶, Rapier f32 위치 반올림 포함).

## 14. 포획

r ≤ r_capture(하위 스텝 끝마다 검사)이면 포획 이벤트를 기록하고 물체를 제거합니다 — 엔티티는 런타임에 남고(숨김, `flags.captured`),
몸체·바람/물 장애물 제거, 파편은 목록에서 빼고 건물 장부 'bodies' → **'captured'** 계정, 시험체는 상태 captured. 포획 반경은 교육용 파라미터이며
r_s(참고값)와 다릅니다. 이벤트·로그·마일스톤(첫 포획, 중력원별).

## 15. 질량 보존

정책: 고정(별도 저장소), 누적(기록, M 고정), 성장(M ← M + m, μ = G·M 즉시 반영). 장부: 포획 질량 = 성장분 + 저장분(잔차 0, 시험). 시험
입자: 배치 = 비행 + 포획 + 착지 + 이탈(잔차 0). 파편 질량은 건물 장부에서 이동만(새 질량 없음).

## 16. 운동량 보존

중력원은 지정 경로에 고정(외부 구속). 포획 시 구속 충격량 J = m(V_s − v)를 기록합니다(고정원: J = −mv, 시험). 자유 중력원이었다면
받았을 ΔV = m(v − V_s)/(M + m)(완전 비탄성 병합)은 진단값으로만 기록 — 적용하지 않습니다(N-body 아님).

## 17. 에너지 장부

포획 장부: K = ½mv², K_rel = ½m|v − V_s|², U = mΦ(x), 구속 일 J·V_s, 항등식 ½mV_s² − ½mv² = J·V_s − K_rel(이동 중력원 시험). K_rel과 결합
에너지는 **미해결 에너지**로 보고합니다(복사·가열·강착 효율 모델 없음 — 빛이나 열로 표시하지 않음). Phase 31 중력 장부는 포획 물체를 경계
이탈(K, U, p)로, KDK 물체를 경로 일로 기록합니다(§12). 착지한 시험 입자의 운동 에너지는 지면 소산으로 따로 기록.

## 18. 중력원 이동

고정 · 일정 속도 · 경유점 경로(선형, 끝에서 정지). 장은 스텝 안에서 고정(표본 시각 하나, Phase 31과 같음) — 중력원은 스텝마다
이동하고, 그 시간 변화의 일은 Phase 31 장부의 W_field로 기록됩니다(Chrome 25). 물체의 역학적 에너지는 보존되지 않습니다(외부 장의 일).

## 19. 복수 중력원

않습니다(`celestial.lim.external`). 단일 중심 궤도 요소는 정확하지 않으므로 인스펙터는 에너지·각운동량만 보여 줍니다.

| 몸 방향·각속도 | `getPose`, `getAngularVelocity`; 중력 구배 토크 `gradientTorque(S, T)`, `boxSecondMoment` |
| 구조 접촉 | 기존 파편·잔해 경로, 들림 분리 파편(`detachMember`) |
| 포획 상태 | `RuntimeEntity.flags.captured`, `CaptureRecord`(시각·질량·운동량·에너지) |
| 손상 원인 | `DamageCause` `tidalLoad`, `captured`; FailCause `uplift`; 해저드 'gravity' 귀속(`gravityGovernsStructure`) |
