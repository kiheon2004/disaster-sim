### 높음

**A1 영하 시작 월드: 토양수가 첫 5초에 얼어 지면 전체가 0 °C로** — `ClimateWorld.applyInitialState`. 기후 시작 기온이 열 기준 온도가 되므로 영하 시작이면 지면 4층이 모두 영하인데, 선행 토양수는 액체로 시작했습니다(영하에서 평형이 없는 상태). 첫 표면 스텝의 투영 엔탈피 결빙이 잠열로 0.8 m 지면 전체를 0 °C로 올렸습니다. 재현: −20 °C, 토양 수분 0.3 → 수정 전 5 s 안에 4층 모두 0 °C, 토양수 75 % 즉시 결빙(40 × 40 m에 9.7·10¹⁰ J) / 수정 후 지면 −20 °C 유지, 시작 때 0 °C 아래 층의 토양수는 얼음으로 시작(초기 저장량으로 장부). 테스트 audit30 "soil water … starts frozen".

**A2 영하 시작 호수: 과냉각수로 시작해 6초에 16 cm 결빙, 바닥도 −20 °C** — 같은 함수. 물도 기준 온도(−20 °C 액체)로 시작해 c_w·ΔT/L_f(25 %)가 첫 스텝에 얼었고, 호수 바닥 지면이 −20 °C라 바닥에서 ≈ 2 kW/m²를 빼앗겼습니다. 재현: 0.5 m 호수 −20 / −10 / −3 °C → 얼음 16.3 / 7.7 / 2.1 cm(6 s). 수정: 수체와 그 아래 지면을 0 °C로 시작(열 장부 계정 `climate` — 강제의 시작 상태, `startWarming` 진단) → 6 s 얼음이 표면 열손실 상한 600 W/m²·6 s/(ρ_i L_f) = 11.8 µm 미만. 테스트 "a lake starts as liquid at 0 °C".

**A3 건물이 자기 지붕에 그림자** — `computeShade`. 광선이 건물 칸에서도 지면 + 5 cm에서 출발해 첫 걸음에 자기 지붕에 막혔습니다. 재현: 10 × 10 × 10 m 블록, 태양 1–80° → 지붕 100칸 중 90칸 그늘(해석해 0). 집·창고 정오: 직달 ≈ 625 kW 누락, 지붕 눈에 산란광만(94.6 vs 1012 W/m²). 수정: 장애물 위에서 출발 → 0칸. 테스트 "a building does not shade its own roof".

**A4 일정 일사 + 해가 지평선 아래: 평지에 설정값의 7배** — `ClimateForcing.sun`. 고도를 0.05 rad로 잘라 직달을 G·share/sin 0.05로 만든 뒤 방향은 천정으로 두어 평지가 직달을 그대로 받았습니다. 재현: 800 W/m², 0시 → 5867 W/m². 수정: 3° 이하이면 전량 산란 → 800. 테스트 "a prescribed irradiance at night is diffuse".

**A5 시나리오·프리셋이 폭염 기본값의 습도 목표 25 %를 물려받음** — `presets.ts climate()`, `climateDefinitions` 시나리오 선택. '강설·어는 비·다습' 시나리오가 화면 습도 0.9–0.95인데 t = 0부터 25 %로 실행(constant 경로의 모양 함수 = 1), 프리셋 7개가 25 %로 흘러감, 근거 없는 '건조한 강설' 경고. 수정: 습도 목표를 상속하지 않음, 경고는 강수 구간의 실제 습도 경로로 판정. 테스트 "scenario … humidity it shows", "presets change humidity only where they say so"(수정 전 실패).

**A6 뜬 얼음 하중을 수심으로 자름 → 얼음 아래 가짜 흐름** — `ClimateWorld.syncIce` + `WaterSolver.computeFluxesIce`. 얼음이 수심의 절반을 넘는 얕은 곳이 '바닥에 닿은 얼음'으로 취급되어 수면 기울기가 생겼습니다. 재현: 그릇 모양 호수 + 초기 얼음 0.1 m → 최대 0.56 m/s, 15.9 m³ 이동(정지해야 함). 수정: 액체가 막 이상 있으면 덮개 전체 질량을 흘수로(눈만 있는 덮개·막 위 덮개는 하중 0) → 단위 유량 < 10⁻⁴ m²/s. 0.1 mm 막 위 9 cm 하중에서도 부단계 1회(0b0cfdf의 400 부단계 문제 재발 없음). 테스트 "floating ice on a bowl lake leaves the water at rest".

**A7 지붕·차량·수관 눈과 그 아래 물체가 일사를 이중으로** — `bodySolar` + `updateStoresStep`. 지붕은 1 kg/m² 미만일 때, 차량·수관은 항상 저장소와 물체 윗면이 같은 일사를 받았습니다. 수정: 눈 덮임 비율(1 kg/m²에서 1)로 한 번만 나눔(`ClimateWorld.storeCover`). 테스트 "a thin store cover takes only its share".

## 4. P0 점검 항목별 결론

### 4.1 물 질량 소유권과 이동 (§3)

모든 이동을 `출발 → 도착`으로 추적했고 각 경로에서 출발 차감 = 도착 가산(정확히 1회), 장부 기록 = 실제 이동량을 확인했습니다. 외부(강수·경계·대기 제거·수관 물)와 내부 이동은 장부에서 구분됩니다.

| 경로 | 확인 | 비고 |
|---|---|---|
| 눈 → 눈 속 액체 → 홍수 | `settleCover` 보유 5 % 초과분 → `toFlood(melt)` | 장면 10·11 시계열(§4.3) |
| 눈 → 지면 침투 | 1 g 미만 조각만 토양수로(홍수 미기동), 나머지는 홍수 → Phase 14 침투 | 정상 |
| 홍수 물 → 얼음 / 얼음 → 홍수 | `freezeWater`(투영 엔탈피, budget.frozen) / `settleCover`·`clearCover`(budget.melt) | A6·A13 수정 |
| 토양수 ↔ 토양 얼음 | `soilPhase`(층 0 °C 유지) | 강화 테스트(0 °C 유지·해빙) |
| 표면수 → 수증기 | `reconcileEvaporation`(물·막·토양) | A18 |

"장부는 맞지만 잘못된 저장소에 물이 있는" 경우를 따로 찾았습니다. A20(비가 융설수로)과 A18(막이 토양수 취급)이 그 예이고 둘 다 수정했습니다. 변이 시험에서 "융설수를 셀 0에 넣기"는 장부만 보는 원래 테스트를 통과했으나, 새 위치 테스트에 잡힙니다(§7).

### 4.2 엔탈피·잠열 (§4)

기준: 기준 온도의 액체 물 = 0, 융해 L_f, 기화 L_v, 승화 L_s. 모든 이동은 (질량, 질량 × 출발지 비엔탈피)로 장부에 적고 공기 노드가 나머지를 받습니다. 극단 사례 스트레스 13장면(1 g 미만 물·얼음, 거의 마른 토양, 포화 근처, 2 kPa·500 Pa, 고온 지표, 강한 복사 손실, 큰·작은 시간 간격)에서:

- 열 세계·기후 저장소 상대 잔차 ≤ 3.4·10⁻¹¹, NaN 0, 음수 질량 0.
- 덮개 온도는 언제나 가장 찬 대상 이상(최저 −3.9 °C at −40 °C 공기 위 0.5 g/m² 얼음 — 0 °C 지면에 붙어 있음).
- **잠열 = 실제 이동 질량**: 물이 바닥나 요청량이 잘리는 경우(질량 없는 잠열)를 계측 — 모든 장면에서 0 J. 증발 상한(`evapMax`)이 지면 스텝 안에서 공급 가능량을 지키기 때문입니다. 남는 경로(`vaporExchange(dm = 0)`)는 진단만 남겼습니다.
- 찾은 문제: A9(포화 조정), A12(끓음), A16(얇은 노드의 증기 부호), A32(녹는점 응결의 상).
