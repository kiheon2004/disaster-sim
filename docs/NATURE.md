# Phase 19 — Natural Environment & Landscape Creator

> 상태: 분석·계획 (구현이 진행되면 보고서로 교체)

## 1. 기존 시스템 분석

| 부분 | Phase 18 현재 |
|---|---|
| 높이장 | `TerrainData` 201×201 정점, `heights`(float32, 1 cm 양자화) · `ground` · `soil`. **단일 배열**이 충돌체(Rapier heightfield, 시뮬레이션 로드 시 1회)·물 바닥(셀 = 두 삼각형 평균)·렌더러·배치·마찰의 원천 |
| 브러시 | `applyDab` raise/lower/flatten/smooth/paint/paintSoil — 최종 `heights`를 제자리에서 수정, 획 끝에 사각형 패치 1개 = 실행 취소 1단계 |
| 프리셋 | `generateTerrain`(flat / gentleHills / valley / coastal / lowland) — 전체 교체 |
| 도로 굽기 | 도로가 덮은 정점의 원래 값을 `roads.underlay`에 보관하고 최종 높이를 덮어씀. 브러시 획이 도로 아래를 바꾸면 그 **변화량을 underlay에 더하고** 도로를 다시 굽고(`sync.ts`), 프리셋은 전부 다시 굽기 |
| 물 | `WaterField.buildLayers`가 최종 높이·지표에서 바닥·투수·Manning·배수를 만듦(물 이벤트 시작 시 1회). 정적 기준 수위 `settings.waterLevel`, 경계(auto/closed/open/fixedLevel), 물 공급원·수위 상승·강우 이벤트, 초기 물 상태 스냅샷 |
| 배치 | 지면 오브젝트는 지형 편집 후 `followTerrain`으로 재안착, 건물 기초 정책(다시 맞춤/위치 유지), 도로 링크 정책 |
| 식생 | `tree` 오브젝트: 바람 손상(줄기 파단·전도), 지진 흔들림, 홍수는 **노출만**(전도 없음). 바람장 장애물은 건물만(나무는 바람을 막지 않음) |
| 저장 | 스키마 v6: 최종 지형 + 도로망(underlay) + 설계 테이블 |
| 스냅샷 | 시뮬레이션은 문서 복사본에서 실행, 원본 편집 잠금 |

### 소유권 문제
최종 높이 배열 하나를 브러시·프리셋·도로가 모두 고칩니다. Phase 18의 underlay가 “도로 아래 원래 값”을 지키지만, **원래 값이 무엇으로 만들어졌는지**(기본 지형인지, 사용자가 깎은 것인지, 산 생성기인지)는 사라집니다. 강·호수·산 같은 **편집 가능한 자연 지형**을 넣으면, 그 중 하나를 고치거나 지울 때 무엇을 남기고 무엇을 되돌릴지 정할 근거가 없습니다.

## 2. 설계: 비파괴 지형 레이어

```
Base Terrain (프리셋 / 불러온 지형)            heights, ground
  + User Sculpt Layer (브러시 높이 변화량)       Δh  (정점별)
  + Landform Features (산·언덕·능선·계곡·협곡)    Σ Δh (가산, 순서 무관)
  → Landform L
  ⊓ Water/Coast Features (강·호수·해안)          min(L, 각 수로/분지/해안 단면)  (최소값, 순서 무관)
  + User Paint Layer (지표 재질 덧칠)            ground 덮어쓰기
  → Natural Terrain N   (도로 없는 지형 — 캐시)
  ⊕ Road Grading (Phase 18 bake, N 위에서)
  → Final Terrain       (충돌체·물 바닥·렌더러·배치·마찰)
```

* 가산 지형(합)과 깎기 지형(최소값)은 각각 **교환 법칙**이 성립하므로 기능의 생성 순서와 무관하게 결정론적이고, 사각형 단위로 다시 합성할 수 있습니다. 수로·분지·해안 단면은 **L(깎기 전 지형)** 을 기준으로 계산합니다.
* 도로는 항상 N 위에서 굽습니다 → `underlay`는 N에서 파생(호환용으로만 유지). 도로를 지우면 그 자리에 **현재의 N**(그 사이 사용자가 고친 산·강 포함)이 나옵니다.
* 브러시는 최종 지형을 실시간으로 보여주고, 획 끝에 변화량을 Sculpt 레이어에 더한 뒤 사각형을 다시 합성 + 도로를 다시 굽습니다.
* 실행 취소: 최종 지형 패치 + 레이어 패치(Sculpt/Paint 사각형) + 기능 목록(불변 참조) + 도로망.

## 3. 계획 (커밋 단위)

1. 레이어 코어: 데이터 모델, 기능 평가(가산/깎기), 합성, 도로 굽기를 N 기준으로, 스토어 통합, v7 저장·마이그레이션, 순서 시나리오 테스트
2. 브러시 확장: Plateau / Ridge / Valley / Slope / Noise / Erosion-inspired, falloff·shape·seed·height limit, 획 전후 높이 차
3. 자연 지형 UI: 산·언덕·능선·계곡·협곡, 강(그리기·제어점·폭·깊이·둑 경사·재질·사행), 호수, 해안선, 기능 목록/편집/삭제, 재질(rock / mud / riverbed)
4. 수문 연동: 수로와 물 상태 분리, 초기 수위·상류 유입·하류 경계·강우, 충돌 검사, 정적 수면 렌더링
5. 숲·식생 도구, 식생 홍수/캐노피 차폐(선택 설정, 골든 불변), 건물 기초 경고, 강–도로 교차 정책
6. 지형 인스펙터, 자연환경 프리셋 6종
7. 성능·벤치·브라우저 검증·문서
