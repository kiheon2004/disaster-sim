# Phase 29 — Atmosphere, Pressure, Air Density & Atmospheric Removal

월드 위 공기 기둥의 **질량**에서 지면 기압(p_s = σ·g)을 얻고, 이상기체 상태방정식으로 밀도를, Phase 26 공기층에서 온도를 읽어
하나의 대기 상태를 만듭니다. 대기 질량을 실제로 빼거나(제거) 외부 저장소에서 넣어(복원) 기압·밀도가 바뀌면, 같은 상태가
바람 하중·공기저항·대류 열전달·연소 산소·연기·화산재·화산 가스·운석 진입·폭발 기준 상태에 전달됩니다.

> §1은 구현 전에 쓴 분석과 설계, §2부터는 구현·측정·검증 결과입니다.
> **국소 축약 대기 모델입니다. 기후 모델·완전 압축성 CFD·기상 예측이 아니며 항공·건축·화산·기상 안전 판단에 쓸 수 없습니다.**
> 고속 충격파는 계속 **Phase 24**가 담당합니다(§21).

### 1.4 모델 범위 선택

| 선택지 | 장점 | 단점 | 결정 |
|---|---|---|---|
| 2D 수평 격자 + 진단적 수직 분포 | 기존 5 m 공기층과 1:1, 1600칸(200 m), 질량 = 기압 관계가 정확 | 수직 순환은 진단으로만 | **채택** |
| 2.5D 다층 | 열적 저기압·역전층 표현 | 층간 질량 교환 폐합 필요, 비용 n배 | 범위 밖(Phase 30 이후) |
| 제한된 3D | 플룸 구조 | 200 × 200 × 수 km는 거칠게라도 수만 칸, 음향 CFL | 범위 밖 |

채택한 모델의 구성:

1. **기둥 질량(바로트로픽)**: σ_a = 칸 a 위 공기 전체 질량/면적. p_s = σ·g(정수압, 정확). 지형 보정 기압 p* = p_s·exp((z_a − z_0)/H_ref)의 차이로 면 질량 플럭스 U(kg/(m·s))를 구동. 운동량 dU/dt = −H_s·∂p*/∂x − U/τ, 연속 dσ/dt = −∇·U + 원천.
   이 방정식의 파속은 √(RT) ≈ 290 m/s(램 파, 등온 음속) — 0.1 s 단계에서 **후진 오일러(반암시적)**로 풀어 음향 과도는 감쇠·여과되고, 질량은 면 플럭스 형태로 정확히 보존됩니다. 행렬은 대칭 양정치(s = red·σ로 변수 변환) → 켤레 기울기법, 결정론적 순서.
2. **근지면층 수렴 흐름**: 층(높이 H, Phase 26과 같음)에서 질량이 빠져나가는 곳(따뜻한 칸의 부력 상승 w = √(gHΔT/T), 국소 흡입)과 들어오는 곳(국소 복원)을 연속 방정식 ∇·u_L = −(w + s)/H 의 퍼텐셜 흐름으로 표현(경계 열림 = 가장자리 φ = 0, 닫힘 = 상층 침강 보상). 크기는 연속에서 정해집니다(예: 반경 30 m에서 4.9 t/s 흡입 → 약 2 m/s 유입).
3. **수직 분포(진단)**: 층 위 등온 T_col, ρ(z) = ρ_s·exp(−(z − z_s)/H_s). 기준 고도의 p·T는 ISA 대류권 식(0–8 km). 월드 높이(≤ 2 km)에서 등온과 ISA의 기압 차 < 1 %.

표현하지 않는 것: 음파·충격파(Phase 24), 열적 저기압의 상층 발산, 난류 구조, 역전층, 구름·습도(Phase 30 자리만), 코리올리, 실내 구획의 과압(구획은 누기로 즉시 평형 — §23).

### 1.5 상태방정식·단열 과정

p = ρRT(R = 287.05 J/(kg·K), c_p = 1005, γ = 1.4). 밀도는 항상 p와 T에서 계산되므로 "온도만 바뀌고 p·ρ가 함께 고정"되는 상태는 만들 수 없습니다.

- **열린 기둥 가열**: 기둥 질량 불변 → p_s 불변, ρ = p/(RT) 감소(층이 위로 팽창). 정수압 기둥의 올바른 반응.
- **질량 제거**: 정수압 기둥의 에너지는 ∫c_pT dm(내부 + 위치 에너지). 제거되는 공기는 엔탈피 + 위치 에너지 (c_p + R)·T·dm를 가지고 나가므로 남은 공기는 c_p(M − dm)T' = c_pMT − (c_p + R)T·dm → 근사적으로 dT/T = (R/c_p)·dp/p **단열 팽창 냉각**. 복원은 반대(외부 공기는 저장소 온도로 들어옴). 이 식을 그대로 써서 에너지 장부가 정확히 닫힙니다. 비교용 옵션 `isothermal`: 냉각분을 외부 열 공급으로 장부에 기록.
- **실내 구획**: 정적 체적·누기 → 실외와 압력 평형, 기체 질량 = ρ_out·V(Phase 27과 같은 Boussinesq), 나가는 기체는 O₂·그을음·열을 비율대로 실외 칸으로.

### 1.8 결정론·원본 보존·호환

- 대기 상태는 런타임에만(`env.atmosphere.rt`); 원본 문서·지형·건물은 읽기만.
- **대기 인스턴스가 없으면 모든 결합 배열이 `null`** → 기존 코드 경로 그대로(분기), Phase 28과 비트 동일(식별 벤치 IDENTITY_ATMOS로 확인).
- 기존 저장 문서에는 대기 인스턴스가 없으므로 자동 활성화되지 않음.
- 스키마 v7 유지: 대기 스펙은 실험 인스턴스로 저장(인스턴스별 zod 검증), 런타임 상태는 저장하지 않음.
