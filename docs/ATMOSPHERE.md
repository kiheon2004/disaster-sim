# Phase 29 — Atmosphere, Pressure, Air Density & Atmospheric Removal

월드 위 공기 기둥의 **질량**에서 지면 기압(p_s = σ·g)을 얻고, 이상기체 상태방정식으로 밀도를, Phase 26 공기층에서 온도를 읽어
하나의 대기 상태를 만듭니다. 대기 질량을 실제로 빼거나(제거) 외부 저장소에서 넣어(복원) 기압·밀도가 바뀌면, 같은 상태가
바람 하중·공기저항·대류 열전달·연소 산소·연기·화산재·화산 가스·운석 진입·폭발 기준 상태에 전달됩니다.

> §1은 구현 전에 쓴 분석과 설계, §2부터는 구현·측정·검증 결과입니다.
> **국소 축약 대기 모델입니다. 기후 모델·완전 압축성 CFD·기상 예측이 아니며 항공·건축·화산·기상 안전 판단에 쓸 수 없습니다.**
> 고속 충격파는 계속 **Phase 24**가 담당합니다(§21).

### 1.4 모델 범위 선택

| 선택지 | 장점 | 단점 | 결정 |
|---|---|---|---|
| 2D 수평 격자 + 진단적 수직 분포 | 기존 5 m 공기층과 1:1, 1600칸(200 m), 질량 = 기압 관계가 정확 | 수직 순환은 진단으로만 | **채택** |
| 2.5D 다층 | 열적 저기압·역전층 표현 | 층간 질량 교환 폐합 필요, 비용 n배 | 범위 밖(Phase 30 이후) |
| 제한된 3D | 플룸 구조 | 200 × 200 × 수 km는 거칠게라도 수만 칸, 음향 CFL | 범위 밖 |

채택한 모델의 구성:

1. **기둥 질량(바로트로픽)**: σ_a = 칸 a 위 공기 전체 질량/면적. p_s = σ·g(정수압, 정확). 지형 보정 기압 p* = p_s·exp((z_a − z_0)/H_ref)의 차이로 면 질량 플럭스 U(kg/(m·s))를 구동. 운동량 dU/dt = −H_s·∂p*/∂x − U/τ, 연속 dσ/dt = −∇·U + 원천.
   이 방정식의 파속은 √(RT) ≈ 290 m/s(램 파, 등온 음속) — 0.1 s 단계에서 **후진 오일러(반암시적)**로 풀어 음향 과도는 감쇠·여과되고, 질량은 면 플럭스 형태로 정확히 보존됩니다. 행렬은 대칭 양정치(s = red·σ로 변수 변환) → 켤레 기울기법, 결정론적 순서.
2. **근지면층 수렴 흐름**: 층(높이 H, Phase 26과 같음)에서 질량이 빠져나가는 곳(따뜻한 칸의 부력 상승 w = √(gHΔT/T), 국소 흡입)과 들어오는 곳(국소 복원)을 연속 방정식 ∇·u_L = −(w + s)/H 의 퍼텐셜 흐름으로 표현(경계 열림 = 가장자리 φ = 0, 닫힘 = 상층 침강 보상). 크기는 연속에서 정해집니다(예: 반경 30 m에서 4.9 t/s 흡입 → 약 2 m/s 유입).
3. **수직 분포(진단)**: 층 위 등온 T_col, ρ(z) = ρ_s·exp(−(z − z_s)/H_s). 기준 고도의 p·T는 ISA 대류권 식(0–8 km). 월드 높이(≤ 2 km)에서 등온과 ISA의 기압 차 < 1 %.

표현하지 않는 것: 음파·충격파(Phase 24), 열적 저기압의 상층 발산, 난류 구조, 역전층, 구름·습도(Phase 30 자리만), 코리올리, 실내 구획의 과압(구획은 누기로 즉시 평형 — §23).

### 1.5 상태방정식·단열 과정

p = ρRT(R = 287.05 J/(kg·K), c_p = 1005, γ = 1.4). 밀도는 항상 p와 T에서 계산되므로 "온도만 바뀌고 p·ρ가 함께 고정"되는 상태는 만들 수 없습니다.

- **열린 기둥 가열**: 기둥 질량 불변 → p_s 불변, ρ = p/(RT) 감소(층이 위로 팽창). 정수압 기둥의 올바른 반응.
- **질량 제거**: 정수압 기둥의 에너지는 ∫c_pT dm(내부 + 위치 에너지). 제거되는 공기는 엔탈피 + 위치 에너지 (c_p + R)·T·dm를 가지고 나가므로 남은 공기는 c_p(M − dm)T' = c_pMT − (c_p + R)T·dm → 근사적으로 dT/T = (R/c_p)·dp/p **단열 팽창 냉각**. 복원은 반대(외부 공기는 저장소 온도로 들어옴). 이 식을 그대로 써서 에너지 장부가 정확히 닫힙니다. 비교용 옵션 `isothermal`: 냉각분을 외부 열 공급으로 장부에 기록.
- **실내 구획**: 정적 체적·누기 → 실외와 압력 평형, 기체 질량 = ρ_out·V(Phase 27과 같은 Boussinesq), 나가는 기체는 O₂·그을음·열을 비율대로 실외 칸으로.

- Phase 29는 표준 기압에서 대류 계수를 바꾸지 않습니다(기압비 1 → 같은 산술; 식별 A/B 용암 장면 비트 동일). 대기 실험을 켜고 기압을 낮추면 대류가 약해져 오히려 더 뜨거워집니다(50 kPa: 670 °C). 용암 위 플룸이 만드는 강제 대류를 크러스트에 넣는 것은 Phase 28 기본 결과를 바꾸므로 이번에 **하지 않았고**, 필요하면 대기 실험의 옵트인 결합으로 별도 검증해야 합니다.

### 2.3 화산재·가스·열기둥 연결부 (중복 생성 없음)

- **가스**: 대기는 화산 장부의 `gasEmitted` **증가분 자체**를 받습니다(`VolcanoWorld.ledger().mass.gas`의 스텝 간 차이, 분출구별 현재 배출률 비율로 칸에 배분). 배출률을 다시 적분하지 않으므로 두 장부가 정확히 같습니다(테스트: 상대 차 < 10⁻¹², 대기 질량에 원천으로 들어가고 O₂ 오프셋으로 조성 보정).
- **화산재**: Phase 28 화산재 덩어리(라그랑지안) 그대로 — 대기는 새 화산재를 만들지 않고, 덩어리의 **이류에 계산된 기류를 더하고 침강에 국소 ρ·μ·미끄럼 보정**을 줍니다. 화산재 질량은 화산 장부만.
- **열기둥 열**: Phase 28에서 층 위로 방출된 것으로 기록된 열(`plumeHeat`)은 대기 에너지 장부에 **정보 항목**(`aboveLayerInfo`)으로만 — 다시 더하지 않음. 용암의 대류열은 Phase 26 공기층(`volcano:air`)에 들어가고, 그 열이 만든 상승기류가 층 수렴 흐름을 만듭니다(같은 열을 한 번만).

## 6. Equation of State

p = ρRT. 밀도는 항상 p와 T에서 계산되고 독립 입력이 없습니다(편집기에 밀도 필드 없음, 요약에 파생값 표시). 경우 구분:

| 조건 | 거동 |
|---|---|
| 열린 기둥 가열 | 기둥 질량 불변 → p_s 불변, ρ 감소(층 팽창) |
| 질량 제거(열린·닫힌 경계 공통) | p ∝ σ, 남는 공기 단열 팽창(§9) |
| 경계 교환 | 유입 공기는 배경 상태(기준 온도 또는 균일 제거 시 배경의 단열 온도) |
| 실내 구획(고정 체적, 누기) | 실외 압력과 평형, 질량 = ρ_out·V, 남는 공기 단열 |

이상기체 범위: 응결·해리가 없는 건조 공기(대략 1 Pa – 10 MPa, 150 – 2500 K) — 이 실험의 범위(100 Pa – 120 kPa, −60 … +60 °C)는 그 안.

## 7. Hydrostatic Pressure

dp/dz = −ρg ⇒ 기둥의 지면 기압 = 기둥 무게(σ·g, 온도 분포와 무관하게 정확). 층(10 m) 안은 층 온도, 위는 자유 대기 온도의 등온 분포 p(z) = p_s·exp(−Δz/H_s). 지형: 정지 상태에서 지형 보정 기압 p* = p_s·exp(z_g/H_ref)가 모든 칸에서 같도록 초기화 → 지형 위에서도 흐름 없음(테스트: 38 m 경사에서 높은 칸의 압력비 = exp(−38/H_s), 솔버 휴지). 월드 높이(≤ 2 km)에서 등온과 ISA의 기압 차 < 1 %.

## 8. Atmospheric Mass Ledger

final = initial + boundaryIn − boundaryOut + source − removed + restored (+ 잔차). `shortfall` = 바닥(초기의 10⁻⁶)에 막혀 제거되지 못한 요청량(제거하지 않음). 제거는 **실제 σ 감소**이며 기압 숫자만 바꾸는 경로는 없습니다. 열·운동량 전달은 질량을 만들지 않습니다(면 플럭스 형태: 한 칸에서 빼고 이웃에 더함). 테스트: 닫힌 경계 상대 잔차 < 10⁻¹², 열린 경계 유입 장부, 제거량 = 계획량(스텝 무관), 복원량.

## 9. Pressure Evolution

한 스텝(0.1 s, 열 시스템 주기):
1. 질량 변화를 **같은 온도에서**: 제거된 공기는 엔탈피 c_p·T·dm를 가지고 나가고, 복원 공기(저장소, 기준 온도)·화산 가스는 섞임.
2. 반암시적 기둥 재분배: U' = β(U − Δt·H_s·∂p*/∂x), σ' = σ − Δt·∇·U' (β = 1/(1 + Δt/τ), τ = 30 s 감쇠 — 지면 마찰·영역 밖으로 빠지는 조정을 묶은 폐합, 보정되지 않음). s = σ·red로 바꾸면 대칭 양정치 → 야코비 전처리 켤레기울기(결정론적 순서, 웜 스타트). 질량은 해의 오차와 무관하게 면 플럭스로 정확. 칸 바닥을 넘는 유출은 제한(제한된 플럭스가 이웃이 받는 양).
3. **압력 일**: 모든 칸의 공기가 스텝 동안의 실제 압력비로 단열 변화 T' = T·(p'/p)^(R/c_p); 기둥 흐름으로 들어오고 나간 공기는 기준 온도로 섞임(그 열 교란은 열 세계의 이류가 운반 — 두 번 세지 않음). 균일 제거: 남는 공기가 냉각되고 그 일 = 제거된 공기가 가져간 유동일 −∫R·T dm(테스트, 0.5 %); 열린 경계가 채우는 국소 흡입: 압력이 거의 안 변하므로 냉각 < 0.01 K(테스트).

**표현 가능한 시간 척도**: 램 파(√(RT) ≈ 290 m/s)의 영역 횡단 시간 L/c ≈ 0.7 s보다 느린 변화. 후진 오일러가 음향 과도를 감쇠·여과 — 음파를 직접 전파하지 않습니다. 10초보다 빠른 제거·복원은 경고(`atmos.warn.fastRemoval`).

## 10. Atmospheric Transport

층(10 m)의 면 속도 = 처방 배경 바람(Phase 15/26의 층 중간 높이 평균풍) + 기둥 흐름 + 층 수렴 흐름. 같은 면 속도로 공기층 열(Phase 26), 연기·O₂ 결손(Phase 27), 화산 가스(신규)를 보존형 상류 차분(CFL ≤ 0.9 하위 스텝)으로 운반. 경계 유입은 배경 공기(추적자 0, 열 교란 = 배경 온도). 수치 확산 = 상류 차분의 것(난류 확산 모델 없음). 부력 환기(따뜻한 칸 → 층 위)는 열·연기·가스에 같은 비율 1 − e^(−wΔt/H).

## 11. Wind Integration

Phase 15 바람은 **처방 배경 흐름(Prescribed Background Flow)**: 대기 모델이 풀지 않는 외부 강제. 계산된 기류(기둥·층)는 배경 위의 **섭동**이며 정지 대기에서 정확히 0 → 바람 없는 기본 장면에 힘이 생기지 않고(테스트: 휴지 상태), 바람을 두 번 더하지 않습니다. 열린 경계에서 배경 바람이 들여오는 공기는 배경 상태.

## 12. Pressure Gradient & Airflow

기둥 흐름은 지형 보정 기압 차가 구동, 차이가 사라지면 τ로 감쇠해 정지(테스트: 흡입 중단 후 300 s에 < 10⁻⁴ m/s, 칸 간 기압 차 < 10⁻³ Pa). 국소 흡입은 근지면층 연속 방정식으로 유입 속도를 만듦(반경 12 m, 6.9 t/s → 가장자리 7.6 m/s; 테스트: 양쪽에서 흡입구를 향함). 안정 조건: 반암시적이라 Δt 무제한(10 s 스텝 테스트 — 양수·유한), 운반은 CFL 하위 스텝.

## 13. Buoyancy & Thermal Plumes

Phase 26 환기 속도 w = √(gHΔT/T)(층 온도 − 자유 대기 온도)를 상승기류로. 근지면 수렴 ∇·u_L = −(w − w̄)/H — **영역 평균 상승은 제자리 대류**(지면이 모든 곳을 데우면 수평 흐름 없음), 국소 초과분만 주변 공기를 끌어들임(동반 유입 근사). 닫힌 월드는 상층 침강으로 보상. 3 MW 체적 열원: 상승 > 1 m/s, 양쪽에서 유입(테스트), `plumeDevelopment` 마일스톤. w는 차원 추정(계수 1)으로 관측 플룸 속도의 크기 정도이며 보정되지 않음; 플룸 높이·연행 계수 모델 없음.

주고받는 계정이 일치: 표면→공기 열은 열 세계 내부 이동, 대기 장부의 `heatIn`은 열 세계의 층 에너지 변화에서 환기·경계 유출을 뺀 값(대기 장부는 질량·압력 일·경계 항을 독립적으로 검증; 열 세계 장부는 자체 잔차로 독립 검증). 제거된 공기의 열 교란은 `airMass` 계정으로 함께 이동.

## 16. Near-Vacuum Conditions

칸 질량 바닥 = 초기의 10⁻⁶(≈ 0.1 Pa) — 음수 질량·압력·밀도 불가(테스트). 거의 진공(목표 0): 밀도 < 10⁻⁴ kg/m³, 풍하중·항력 → 0(테스트), 대류 계수 → 0(Ra ∝ p²), 산소 질량 → 0. 1 Pa 미만이면 로그 경고(평균 자유 행로 6.5 mm — 1 m 물체 Kn 0.007은 아직 연속체, 화산재 입자는 커닝햄 보정). 실제 진공의 탈기체·끓음·생리 반응 등은 계산하지 않음.

## 19. Air Density & Aerodynamic Forces

`WindForceSystem` 하나(ForceLedger 출처 `wind`)에서: 압력 중심의 ρ(높이별 p/RT), 속도 = 배경 바람(공간 바람장·수관 차폐 그대로) + 계산된 기류, 하중비 × ρ/ρ_design, 바람이 없어도 움직이는 물체의 상대 속도 항력. 차량·사람·나무·간판·가로등·잔해가 모두 이 경로. 화산탄·분출물 비행은 `fly(rhoAir)`. 이중 적용 없음(물체당 힘 하나 — `duplicateForces` 0, 벤치 기록). 테스트: 하중비·차량 풍하중 비 = 밀도비(±0.05).

## 20. Building Wind Loads

동압 q = ½ρv² (비압축, 마하 < 0.3). 설계 용량(설계 풍속)은 해면 ρ = 1.225에서 정의된 보정 상수로 유지하고 **하중 쪽만** 국소 ρ: 하중비 = (v/v_design)²·ρ/ρ_design. 구조 손상은 기존 구조 엔진(Phase 17/25)이 그 하중비로 처리. 마하 0.3 초과 기류는 로그 경고.

## 21. Blast Wave Compatibility

| 상태 | 담당 |
|---|---|
| Background Atmospheric Pressure | Phase 29 (기준 + 기둥 질량) |
| Slowly Varying Pressure Field | Phase 29 (≥ 1 s) |
| Blast Overpressure / Impulse | Phase 24 (해석해, 펄스) — Phase 29 격자로 재계산하지 않음 |

인터페이스(옵트인 `coupleBlast`): 폭발 시작 시각·위치의 배경 상태(월드 기준면의 보정 기압 p와 ρ = p/RT)를 Phase 24의 `ambient`로 — Sachs 축척·음속이 그 값으로. 범위(30 kPa, 0.4–1.5 kg/m³) 밖이면 기본 대기 유지 + 계획 경고. 스펙이 직접 기압·밀도를 정했으면 그쪽 우선. 폭발 하중의 ρ도 옵트인일 때만 국소값. 옵트인이 아니면 결과 불변(식별 A/B 18장면 + 테스트: 비옵트인 101 325 Pa).

## 22. Meteor Atmospheric Entry

옵트인 `coupleMeteor`: Phase 23 진입 대기(ρ₀·e^(−z/8 km), 100 km → 1.5 km)의 ρ₀를 **현재 기둥 질량 / 표준 기둥**(기준 기압 × 남은 비율을 해면으로 환산 / 101 325)으로 축척 — 실험이 월드 위 기둥 전체를 얇게 한다는 가정. 진입은 이벤트 시작 시 한 번 적분(그 시점 상태). 분출물 비행은 국소 ρ. 대기가 얇으면 항력·가열(애블레이션)·파쇄 동압 ρv²가 모두 작아져 더 빠르게·덜 부서져 도달(테스트·Chrome §23). 진입 모델의 유효 범위(ρ₀ 축척된 지수 대기)는 그대로.

## 23. Fire & Oxygen

| 상태 | 위치 |
|---|---|
| Oxygen Mass | 층 칸: Y_air·m_layer − 결손(kg), 실내: `FireRoom.o2`(kg) |
| Oxygen Fraction | 실외 Y = Y_air − 결손/m_layer, 실내 o2/gas |
| Total Air Mass | 층 m_layer = ℓ·σ·A, 실내 gas = ρ_out·V |
| Compartment Ventilation | Rockett 개구부 유입 ∝ ρ∞(국소), 누기 |

제거된 공기는 결손을 비율대로 가져가 분율이 유지되지만 산소 **질량**은 줄어듦(테스트: 5 %에서 층 O₂ < 기준의 10 %). 실내 기체는 누기로 실외 압력과 평형: 나가는 기체는 O₂·그을음·열을 실외 칸으로, 들어오는 기체는 실외 조성. 실외 연소는 칸이 한계 분율 위로 가진 O₂ 질량을 넘지 못함(항목 순서 결정론적).

## 24. Fire & Low Pressure

- 산소 공급 한도(위) — 압력이 낮다는 이유만으로 끄지 않고, O₂ 공급으로 제한된 연소율이 연료 지배 연소율의 1 % 미만으로 2초 지속될 때만 산소 고갈 소화(축약 기준).
- 대류 열전달: 연소체 표면 대류도 기압비(§14).
- 환기: Rockett ∝ ρ∞.
- 60 kPa 미만: 화재 관계식(EN 설계 화재, 착화 열유속–시간, Heskestad 화염 높이)의 자료 범위 밖 → 편집기 가정·로그 경고. **저압 화염의 화학적 소화 한계(다뮈쾰러 수)는 모델에 없음** — 부력 공급이 충분하면 실제로는 꺼질 낮은 기압에서도 탈 수 있음(§47).

측정(테스트): 5 %까지 희박화 후 점화 — 15 s 동안 연소 연료가 기준의 0.8 미만, O₂ 제한 스텝 기록.

## 25. Smoke Transport

Phase 27 그을음 배열을 같은 면 속도(배경 + 계산 기류)로 운반, 따뜻한 칸에서 환기, 경계 유출 `smokeAdvected`, 실내 ↔ 실외 교환(누기·개구부·압력 평형). 장부 smokeProduced = 실내 + 실외 + 환기 + 유출(테스트 < 10⁻⁹). 공기가 빠져도 그을음 질량은 남고(에어로졸), 농도(mg/m³)는 체적당 — 질량과 농도를 혼동하지 않음.

## 26. Volcanic Ash Transport

Phase 28 덩어리 그대로: Airborne Mass(화산 장부), Advection(배경 바람 프로파일 + 계산 기류), Settling(Schiller–Naumann + 국소 ρ·μ(T)·커닝햄 미끄럼, 방출 후 자유 낙하 속도 상한), Deposition·Boundary Outflow(Phase 28). 화산재 질량은 공기 질량과 별도 장부. 테스트: 20 % 기압에서 1 mm 입자 침강 > 표준의 1.8배.

## 27. Volcanic Gas & Thermal Plume

| 항목 | 처리 |
|---|---|
| Gas Source Mass | 화산 장부 증가분(§2.3), 기둥 질량의 원천 |
| Temperature | 가스는 층 온도로 섞임(분출 가스 자체의 열은 Phase 28도 장부에 없음) |
| Buoyancy | 따뜻한 칸 환기 비율로 층 위로(`aloft`) |
| Transport / Dilution | 층 면 속도 운반, 상류 차분 확산 |
| Boundary Loss | `out` |

장부 emitted = airborne + aloft + out + removed(테스트). 화학·독성·생리 피해 없음. 화산재·연기·가스는 별도 양.

## 28. Water & Atmospheric Pressure

- 균일 기압 변화: 기압 경사가 없어 물은 움직이지도 사라지지도 않음(테스트: 체적 변화 < 10⁻⁶).
- 기압 경사: 보정 기압 차를 Phase 24의 공기 충격량 경로(−h·∇∫p dt/ρ_w)로 — 역기압계 응답. 국소 흡입의 Pa 수준 차이는 mm 이하 변화.
- 바람 응력: 평균 층 밀도.
- 공기–물 열교환: 기압비 대류.
- 끓음·증발: 미지원 — 국소 기압의 끓는점(클라우지우스–클라페롱)과 그것을 넘는 물 칸 수를 보고만(HUD, 결과).

## 29. Terrain & Altitude

변형 revision이 바뀌면 최대 1초에 한 번 칸의 지면 높이를 다시 읽음(네 점 평균) — 기둥 질량은 유지되고 정수압 조정은 계산된 흐름이 담당(테스트: 4 m 침하 → 갱신 > 0, 흐름 < 1 m/s, 60 s 뒤 정지). 전체 격자를 재구성하지 않음(높이 배열과 보정 계수만).

## 30. Atmospheric Energy Ledger

final = initial + heatIn − ventedAloft − advectedOut + boundaryIn − boundaryOut − removed + restored + source + pressureWork + isothermalHeat. 정보 항목(장부 밖): aboveLayerInfo(층 위로 바로 나간 열원·플룸 열), kinetic(기둥 흐름 운동 에너지), dissipated(감쇠가 없앤 운동 에너지 — 열로 되돌리지 않음, 미해결). 공기와 함께 나간 에너지 = `removed`(엔탈피), 남은 공기의 단열 일 = `pressureWork`. 테스트·Chrome: 상대 잔차 < 10⁻¹⁰.

## 31. Momentum Ledger

공기 운동량(기둥 흐름 Σ U·A), 압력 경사 충격량(경계 기압·지형 형상력 포함), 감쇠 충격량 — 갱신식의 정확한 분해. 물체 항력 반작용은 되먹이지 않음(단방향 결합, 정보). 배경 바람의 운동량 공급은 모델 밖(처방) — ForceLedger의 `wind` 출처가 물체에 준 힘을 기록. 비선형 운동량 이류는 없음(선형 기둥 모델).

## 42. Performance Architecture

| 기법 | 적용 |
|---|---|
| Sparse / idle updates | 정지 대기(흐름 0, 보정 기압 균일)에서 기둥 솔버 휴지; 균일 제거도 비율이 같아 휴지 |
| Active regions | 층 수렴 흐름은 원천(상승 초과분 > 2 cm/s·흡입)이 있을 때만; 지면 타일은 공기가 기준에서 벗어난 칸 아래만 활성 |
| Multi-rate solver | 기둥·층 결합 0.1 s(열 주기), 부력 층 흐름 1 s마다 재풀이(흡입은 매 스텝), 통계·마일스톤 1 s, 지형 재평가 ≤ 1 s, 이력 1 s(가득 차면 절반·간격 2배) |
| Typed arrays | 모든 칸·면 상태 Float64Array, 작업 배열 재사용(스텝당 할당 없음) |
| Dirty / changed cells | 질량·온도가 바뀐 칸만 열 세계에 반영(`changed`) |
| Cached values | 같은 압력비의 단열 계수 1회, 화산재 침강 속도 (등급, ρ, T) 캐시 |
| Lazy statistics | 칸별 통계는 읽을 때(HUD·결과·1초 마일스톤)만 |
| Spatial index / batched forces | 물체 힘은 기존 WindForceSystem 루프 안에서(물체별 칸 조회 O(1)), 대기가 물체를 탐색하지 않음 |
| GPU pooling | 칸 격자 1 메시, 화살표 InstancedMesh(≤ 900), 유선 LineSegments 하나, 모두 소유·해제 |

## 47. Scientific Limitations

- 국소 축약 대기 모델(2D 기둥 질량 + 진단 수직 분포). 전 지구·기후 모델, 기상 예보, 대기질 모델이 아님.
- 완전 압축성 CFD가 아님: 음파·충격파를 풀지 않음(≥ 1 s 변화만, 후진 오일러가 과도를 여과); 고속 충격파는 Phase 24.
- 수직 구조는 10 m 층 + 등온 자유 대기(스칼라 하나); 역전층·대류권 구조·열적 저기압의 상층 발산 없음.
- 난류·대류권 기상(구름·강수·습도)·코리올리 없음; 층 수렴 흐름은 연속 방정식의 퍼텐셜 흐름(소용돌이 없음), 상승 속도는 차원 추정.
- 기둥 흐름 감쇠 τ = 30 s는 보정되지 않은 폐합.
- 희박 기체: 연속체 관계식(대류 상관식, 항력)은 Kn ≲ 0.01까지; 1 Pa 미만은 경고. 실제 진공의 탈기체·물의 끓음·생리 반응은 계산하지 않음.
- 화재·연소의 저압 반응은 축약: 산소 질량 공급과 대류 변화만, 저압 화염의 화학적 소화 한계·연소 속도의 압력 지수 없음; 60 kPa 미만은 화재 관계식 자료 범위 밖(경고).
- 균일 제거에서 경계로 들어오는 배경 공기는 단열 냉각된 자유 대기 온도(주변 지면이 데운 효과 없음); 자유 대기 온도는 영역 스칼라 하나.
- 에어로졸(연기·화산재)은 공기 제거로 빠지지 않음(기체만 제거).
- 화산재·연기의 미세물리(응집, 응결)·화학 반응, 화산 가스의 화학·독성 없음.
- 인체의 저압·저산소 생리 반응은 Phase 34 범위(산소 분율 변경 `atmosphereLoss`는 계획 현상).
- 물: 역기압계 응답만, 끓음·증발·용존 기체 없음.
- 설계 용량은 해면 보정값 그대로(구조 설계 코드의 고도 보정 없음).
- 실제 항공·건축·화산·기상 안전 판단에 사용할 수 없음.
