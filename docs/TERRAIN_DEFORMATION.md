# Phase 21 — Dynamic Terrain Deformation Engine

> 작업 전 설계(데이터 흐름·갱신 순서). 구현 후 아래 각 절을 실제 결과로 채웁니다.

## 설계: 데이터 흐름과 갱신 순서

```
월드 문서 (원본, 불변)             ── 시뮬레이션 시작 ──▶  스냅샷(불변, 초기화 대상)
                                                           │ 복사
                                                           ▼
                                         원본 합성 지형 H₀ (Float32 사본, 불변)
TerrainDeformationEvent ──▶ env.deformation (활성 변형 목록, 시간 프로파일)
                                                           │ DeformationSystem (prePhysics, 첫 번째)
                                                           ▼
                                 변위장 W(t) = Σ wᵢ(x, z, t)   (선형 중첩)
                                 유효 지형 H(t) = H₀ + W(t)    (런타임 TerrainData 하나)
                                                           │ 같은 스텝 안에서 원자적으로
   ┌─────────────────┬─────────────────┬──────────────────┼──────────────────┬─────────────────┐
 TerrainSampler.sync  Rapier 높이장 교체  물 바닥(bed) 갱신     고정 오브젝트·건물 기초   도로 상태        렌더 dirty
 (모든 시스템 공통)    (setShape 전체)    수심 보존 = 질량 정확   (지면 추종·기울기·부등침하)  (경사·단차·통행)  (지형·도로 청크)
```

1. 변형 이벤트는 채널(`env.deformation`)만 씁니다(Phase 15 원칙). 오브젝트를 직접 건드리지 않습니다.
2. DeformationSystem은 prePhysics 맨 앞에서 실행: 연속 변형은 10 Hz(물 솔버와 같은 스텝, 그보다 먼저), 즉시 변형은 발생 스텝에 바로 적용.
3. 적용은 원자적: 높이 → 샘플러 → 충돌체 → 물 바닥 → 오브젝트·건물·도로 → 렌더 표시. 그 스텝의 물리·물 솔버·피해 시스템은 모두 새 지형을 봅니다.
4. 스냅샷과 원본 사본은 절대 쓰지 않습니다 → 초기화 = 스냅샷에서 다시 빌드 = 원본 정확 복원.
