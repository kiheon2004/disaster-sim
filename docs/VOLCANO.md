# Phase 28 — Volcano, Lava Flow, Cooling & Volcanic Deposition

화산 분출원에서 공급된 용암이 지형 경사·항복강도·점성(온도·결정 함량)에 따라 흐르고, **Phase 26 열 상태로 열을 내보내며** 식고 결정화되어
멈추고, 고화된 용암·화산탄·화산재가 **Phase 21 지형 변형 경로로 지형이 되는** 단계입니다. 새 온도 엔진·구조 파괴 엔진·화재 엔진은 없습니다.

> §1은 구현 전에 쓴 분석과 설계, §1.8부터는 구현·측정·검증 결과입니다.
> **축약된 국소 분출 모델입니다. 화산 분화 예측·재난 대응·구조물 안전 판단에 쓸 수 없습니다.**

- 용암 열이 열 노드에 들어가는 경로는 `SourceStep` 하나뿐 → 화재의 입사 열유속 계산(`incident()`)이 그대로 한 번 읽음(중복 없음).
- 교환량은 단계 시작의 온도로 계산(명시적, 0.1 s): 안정 조건 = 열 노드 쪽 G·Δt/C ≪ 1(지면 표면층 C ≈ 4·10⁴ J/K, 용암–지면 G ≈ 수 W/K) — 측정해 문서화.

### 1.4 용암 유동 모델 (Phase 14·22를 복사하지 않음)

- 물(얕은 물 local-inertial)·토사(Voellmy)와 달리 용암은 **점성 지배·항복강도 유체**: 관성 무시, 정상 Bingham 판 흐름의 단위 폭 유량
  q = (τ_y·h_cr²/(3η))·(a³ − 1.5a² + 0.5), a = h/h_cr > 1, h_cr = τ_y/(ρ g sin θ) (Dragoni 1986; MAGFLOW 계열 셀 오토마타의 천이 규칙). τ_y → 0이면 뉴턴 판 흐름 ρ g sin θ h³/(3η).
- 공유 기법(재사용): 면 플럭스를 한 셀에서 빼 이웃에 더함, 유출을 보유량으로 제한(양수성), 공여 셀 값 운반(엔탈피·나이), 활성 영역, 정지 판정은 자기 면으로.
- 용암 전용: η(T, φ) = η_melt(T)·(1 − φ/φ_m)^−2.5 (Einstein–Roscoe), η_melt = GRD 모델(Giordano et al. 2008, 조성 → VFT B·C), τ_y(φ) (FLOWGO/Pinkerton & Stevenson), φ(T) 액상선–고상선 선형, 결정 φ ≥ φ_lock이면 이동 불가 → 고화 퇴적층.
- 안정: 확산형 명시 한계 Δt ≤ 0.2·Δx²/D, D = ρ g h³/(3η)(최대값); 하위 스텝 상한과 그때의 면 제한(자유 수면 역전 금지)으로 무조건 단조. 얇은 막은 h < h_cr에서 유량 0(항복) → 정착 후 갱신 멈춤.

### 1.5 장부

- **질량**: 공급 = 이동 + 고화 + 경계 유출 + (분출물: 비행 중 + 퇴적 + 유출) + (화산재: 공중 + 퇴적 + 지붕 + 유출) + 잔차.
- **에너지**(기준 = 대기 기준 온도 Tref의 현열, Phase 26과 같음): 공급 열에너지 = 용암·퇴적층 내부 에너지 + 지면·물체·물·공기로 간 열 + 하늘 복사 + 경계 유출(용암이 가져감) + 미해결(플룸·화산재·가스 열) + 잔차. 잠열은 엔탈피 표에 포함(고화 에너지 항 = 방출 잠열, 정보용).
- 열 세계 쪽: `ThermalLedger.volcanic` = 화산 장부의 "열 세계로 간 열" 합 — 두 장부가 각각 닫히고 서로 같음(테스트).

### 1.6 LOD

용암이 닿거나 강한 복사(≥ 1 kW/m²)를 받는 건물만 부재 노드로 세분(Phase 26/27 규칙). 1000동 장면에서 용암 경로 밖 건물은 세분되지 않아야 함(측정).

### 1.7 원본 월드 복원

모든 화산 상태는 런타임(`env.volcano`, 실행 지형 사본, 열 상태)에만 — 초기화 시 버림. 원본 지형·건물·도로·식생·Blueprint는 쓰지 않음. 같은 조건이면 같은 결과(시드 무관한 결정론적 계산, 반복 순서 = 정점 번호·삽입 순서).

### 1.8 설계에서 바뀐 점 (구현 중 측정으로)

- 퇴적층 게시: 1 mm 허용치만 두면 고화 전면이 매 0.1 s 충돌체 재생성을 일으킴 → **1 mm 초과 + 1초 주기(5 cm 넘는 변화는 즉시)**. 용암 자신의 바닥은 `지형 − 이미 반영한 퇴적 + 현재 퇴적`이라 게시 지연과 무관하게 정확.
- 용암 ↔ 고온 퇴적층 전도와 얇은 막의 열교환은 **양방향**으로 제한(아래 §6) — 시뮬레이션에서 나노그램 잔여 막이 수천 도로 계산되는 문제를 찾아 고침.
- 움직이지 않는(잠든) 용암과 고온 퇴적층은 1초마다 그동안의 시간으로 식힘(셀별 마지막 냉각 시각, 정확한 적분) — 1시간 분출의 비용을 측정해 도입.

## 2. Phase 27 잔여 검증

### 2.1 화재·열 원인 귀속

- `volcano`는 `HAZARDS` 끝(색인 8)에 추가 — 이전 해저드 색인 불변(테스트). Phase 27에서 고친 "미등록 해저드 색인 −1 = '원인 없음' 표지" 버그는 **회귀 테스트로 추가**: 먼 곳의 무관한 열원이 있는 지진 붕괴에서 `thermalFailures = 0`, `thermal`/`fire`/`volcano` 피해 기록 없음.
- 원인 구분: 용암 접촉·측압 = `volcano`/`lava`, 매몰 = `volcano`/`burial`, 화산탄 = `volcano`/`ejecta`(IMPACT), 지붕 화산재 = 붕괴 엔진의 `causeHazard = volcano`(정적 하중), 열 약화 = 열 결합 경로의 해저드 훅(용암이 가열한 건물 → `volcano`, 그 건물이 타면 `fire`), **2차 화재 = 해저드 `fire` + `source: 'volcano'`**(착화 원인 `lava`).
- 화산이 없으면 모든 집계가 Phase 27과 같음: 12개 장면 A/B 해시 비트 동일(§35.3).

### 2.2 외부 입사 열유속 — 정확히 한 번

용암 열은 `SourceStep(volcanic)`의 물체 수열체(면적 `a` 포함)로만 들어가고, 화재 모델의 `incident()`가 그 단계 목록을 한 번 읽습니다. `incidentProviders`는 **파일럿 표시만**(빛나는 용암에 닿은 연료) 하고 열유속을 더하지 않음. 테스트: 나무 연료 항목의 `qInc` = Σ(복사 + 접촉 피부 몫)/(dt·ε·a), 비율 1 ± 5·10⁻⁷(Float32 정밀도; 두 번 들어갔다면 2). 나무 줄기 접촉열은 코어 노드로(`Deposit.core`, 면적 없음) — 수관 연료의 입사 열유속에 섞이지 않음.

### 2.3 대규모 화재·열 LOD

복사 묶음의 수신체는 도달 거리(조사도 ≥ 200 W/m²가 될 수 있는 거리, 최대 40 m) 안의 물체만 활성화하고, 8 m 안의 건물만 부재로 세분(Phase 26 규칙과 같은 강한 가열 구역). 측정: 1000동 마을 구석의 분출 — 세분 7동, 100동 마을 테스트 ≤ 6동(테스트). Phase 27의 1000동·400그루 장면은 화산 없이 Phase 27과 비트 동일.

## 3. Volcano Runtime Architecture

| 상태 | 위치 |
|---|---|
| Volcano Source / Eruption State | `VolcanoWorld.eruptions` (스펙, 분출구 정점·가중치, 적분한 지역 시간, 발사·방출 횟수, 단계) |
| Lava Reservoir / Supplied Mass | 공급은 지정(저장소 없음); 장부 `suppliedMass`·분출구별 화산탄·화산재 대기분 |
| Lava Flow Field / Temperature / Enthalpy | `LavaField` `M`·`E`·`age`(정점 SoA), 캐시 `T`·`Ts`·`speed` |
| Solidified Lava | `LavaField` 퇴적층 `depM`·`depB`·`depA`·`depE`·`depAge`, 두께 `dep` |
| Volcanic Ejecta | `VolcanoWorld.bombs`(집계 묶음, 비행 경로) |
| Ash Field | `VolcanoWorld.puffs`(라그랑주 덩어리) + 퇴적 `depA` |
| Source Energy / Deposition Ledger | `LavaField.ledger` + `VolcanoWorld.ledger()` |
| Affected Terrain Region | 퇴적 변경 상자 `dirty` → `VolcanoSource.changedRect` |

문서(월드)와 런타임은 분리: 스펙만 실험 계획에 저장, 런타임은 `env.volcano`(채널·`VolcanoRuntime`)에만. 화산이 없으면 채널은 휴면(배열 없음, 시스템 비활성 판정에 `false`만 더함) → Phase 27과 비트 동일.

## 4. 월드 규모와 과학적 범위

200 m × 200 m, 1 m 정점 격자. 지원: 국소 분출구, 작은 균열 분출(2–120 m), 국소 용암류, 분출구 주변 화산탄 원뿔 성장, 제한된 화산재 퇴적, 단순 탄도 화산탄. 공급량 0.01–20 m³/s(체적, 기공 포함), 분출 10 s – 6 h. 실제 화산의 분출률(하와이 균열 수십–수백 m³/s)은 축소하지 않고 이 월드에 맞는 국소 사건만 다룸. 월드 밖으로 나간 용암·화산탄·화산재는 경계 유출 계정.

## 5. 분출원 (`src/volcano/types.ts`, `VolcanoWorld.ventVertices`)

중앙 분출구(원판, 반지름 0.5–10 m), 균열(선분 + 반폭), 여러 분출구(최대 6, 비중 가중), 시간 변화(아래 §6). 분출구 정점 = 원판/띠 안의 정점(없으면 가장 가까운 하나), 균등 가중. 위치는 월드 좌표; 분출구 지면 높이는 런타임 지형에서(화산탄 발사점). 월드 밖 분출구는 이유와 함께 거부(`volcano.reject.outside`).

## 6. 분출 타이밍 (`src/volcano/eruption.ts`)

Q(t) = Q₀·s(t). 일정·증가·맥동은 Phase 26 열원 프로파일의 **정확한 구간 적분**을 재사용, 단계(같은 길이 단계 수준) · 예정 종료(일정 후 선형 감소)는 해석 적분. 불규칙한 단계로 나눠 더해도 총량과 같음(테스트, 1e-9). 단계: dormant → starting(증가 구간·첫 낮은 단계) → active → declining(감소 구간·최고 뒤 낮은 단계) → stopped. 화산탄은 1초, 화산재는 1초마다 그 사이 분출분을 발사/방출(단계 길이와 무관).

## 8. 용암 질량 공급

분출 체적 × 체적 밀도 = 분출 질량. 화산탄·화산재 몫을 뺀 용암만 분출구 정점에 공급(`supply`: 질량·분출 온도의 엔탈피·나이 0). 장부: 공급 = 이동 + 고화 + (화산탄: 대기·비행·퇴적·물체·유출) + (화산재: 대기·공중·지면·지붕·유출) + 용암 유출 + 잔차. 시각 효과(스패터·증기)는 질량이 없음. 가스는 분출 질량의 0.5 %(장부 전용, 질량 보존식 밖).

## 9. 용암 유동 솔버 (`src/volcano/LavaField.ts`, `rheology.ts`)

물(Phase 14 local inertial)·토사(Phase 22 Voellmy)와 다른 **점성 지배 Bingham 판 흐름**:

  h_cr = τ_y / (ρ g sin θ),  q = (τ_y h_cr² / 3η)·(a³ − 3a²/2 + 1/2),  a = h_f/h_cr > 1   (τ_y → 0: ρ g sin θ h³/3η)

각 면에서 용암 표면(바닥 + 깊이)이 높은 쪽(공여 셀)의 흐름 깊이 h_f와 물성(T → η, τ_y)으로 유량, 면 폭 1 m. 공여 셀 운반(질량·에너지·나이; 하위 단계 시작 시점의 비에너지·나이 스냅샷으로 순서 무관). 공유 기법만 재사용(면 플럭스 ±, 양수성 제한, 활성 집합, 자기 면 정지 판정). 경계: 열린 가장자리는 지형 경사를 연장한 바깥으로 흘러나가 유출 계정; 닫힌 모드는 벽. 장애물(멀쩡한 건물·담장)은 그 높이를 넘을 때만 진입. 3차원 비뉴턴 유동·관성·용암 동굴·팽창은 해석하지 않음.

## 10. 수치 안정성

- **하위 단계**: 면 플럭스는 표면의 비선형 확산; 각 면이 한 하위 단계에 ΔS·dx²/5 이상 옮기지 않는 h를 고름(이웃 4개의 명시 확산 한계에 여유). 0.1 s 단계당 최대 48 하위 단계 — 넘으면 면 체적을 그 몫으로 제한(`limited` 계수, 측정된 장면 모두 0).
- **음수 깊이·역전 없음**: 공여 셀 총유출 ≤ 하위 단계 시작 질량(양수성), 면 체적 ≤ 높이차의 1/5(표면 역전 없음). 비우는 셀은 질량·에너지를 함께 정확히 옮김(반올림 잔여 없음).
- **얇은 막**: h ≤ 5 mm는 흐르지 않음, h ≤ h_cr이면 유량 0(항복) → 정착 후 면 계산 0(테스트: 평지 분출 정지 후 `faces = 0`, 하위 단계 0).
- **잠든 셀**: 4 하위 단계 동안 흐름이 없으면 유입이 올 때까지 평가 생략.
- **열 폭주 방지**: 한 단계 손실은 주변 최저 온도까지 가진 에너지의 90 % 이하, 이득은 주변 최고 온도까지의 90 % 이하(항을 함께 축소·축소한 대로 장부 기록), 용암 ↔ 퇴적층 전도는 공통 온도까지의 절반 이하. 1 g 미만의 그램 단위 질량 온도는 표시용 캐시만 [기준 − 50 K, 액상선 + 300 K]로 묶음(에너지 불변).
- 수렴: dx 1 m vs 0.5 m 전면 위치 20 % 이내, dt 0.1 vs 0.05 s 10 % 이내(테스트).

## 11. 온도 의존 점성

T ↓ → 결정 φ ↑ → η(GRD·Einstein–Roscoe) ↑, τ_y ↑ → 유량 ↓, 정지 깊이 h_cr ↑ → 얇은 앞부분부터 멈춤. 결정률 55 %에서 정지(퇴적). 크러스트(§14)는 흐름 깊이를 줄임. 상수 점성이 아님(테스트: 1110 °C 전면 < 1170 °C 전면, 안산암 ≪ 현무암).

## 12. 용암 열 상태 (Phase 26 재사용)

용암과 퇴적층의 에너지 = Phase 26 엔탈피 표(새 재료 `basaltLava`·`andesiteLava`, 잠열 포함)로 E ↔ T. 열교환(명시, 0.1 s):

| 경로 | 식 | 열이 가는 곳 |
|---|---|---|
| 용암–지면 | (T_i − T_g)/(δ/k + R_g), δ = 바닥 경계층, R_g = 지면 표층 반층 저항 | 정점이 덮은 열 셀(¼씩) 표층 — `volcano:ground` |
| 용암–구조물 | A·k·(T − T_b)/δ, 피부 열용량 차의 절반 이하 | 건물 1층 외곽 부재·차체·담장·기둥 — `volcano:contact`(면적 포함) |
| 용암–나무 | 같음, 줄기(코어) | 나무 코어 노드(`Deposit.core`) |
| 용암–공기 대류 | h_c(T_s − T_a), h_c = Phase 26 `hGround`(바람) | 위쪽 공기층 칸 — `volcano:air` |
| 용암 복사 | εσ(T_s⁴ − T_sky⁴)·(윗면 + 노출된 가장자리 면) | 4 × 4 m 묶음 → 물체 A_p·cos θ/(πr²)·ε(가림 포함), 나머지 하늘 — `volcano:rad` |
| 용암–물 | h_w(T_s − T_w), h_w = 500 W/(m²·K) | 물 열 — `volcano:water` |
| 용암–용암 | 이류 혼합 + 이동 용암 ↔ 아래 퇴적층 전도 | 내부 |

용암 밑 지면은 `covered`(공기와 교환하지 않음). 용암이 잃은 열은 위 단계들로만 열 세계에 들어가며, 열 장부 `volcanic` = 화산 장부의 전달 열(테스트, 1e-9). 열을 잃은 용암은 다음 유동 하위 단계의 T·η·τ_y에 바로 반영.

## 13. 냉각과 고화

완전 용융(φ = 0) → 부분 고화(0 < φ < 0.55, 흐름) → 정지(φ ≥ 0.55: 같은 정점의 퇴적층으로, 질량·에너지 그대로) → 퇴적층이 계속 식으며 결정화(φ → 1 고상선). 잠열은 엔탈피 표에 포함(장부와 일치), 정보용 `latentReleased`. 고화한 용암은 다시 흐르지 않음(재가열해도 — 한계).

## 14. 용암 크러스트 (축약 모델, `src/volcano/crust.ts`)

열적 경계층 δ = 2√(κ(t + 1 s)) (반무한 전도체, Turcotte & Schubert 4장), δ ≤ h/2. 표면 온도는 경계층 에너지 수지 k(T_i − T_s)/δ = εσ(T_s⁴ − T_sky⁴) + h_c(T_s − T_a)(물속: = h_w(T_s − T_w))의 해(뉴턴, 위에서 단조 수렴). 경계층 중 정지 온도보다 차가운 부분은 굳은 크러스트 → 흐름 깊이에서 뺌. 나이는 질량 가중으로 운반(신선한 용암이 섞이면 젊어짐). **검은 표면 = 차가운 크러스트이며 고화가 아님**(고화는 내부 엔탈피로만 판정) — 시각 색은 계산된 T_s(525 °C Draper 점 이상 발광). 이 모델의 표면은 관측(하와이 파호이호이 표면이 수 분 안에 500–600 °C)보다 다소 뜨겁게 나옴(3분 ≈ 690 °C) — 기공·유리질 피막·균열을 다루지 않는 단순 경계층의 한계.

## 15. 고화 퇴적

퇴적 두께 = (용암 + 화산탄 질량)/(ρ_bulk·dx²) + 화산재 질량/(1000 kg/m³·dx²) — 질량과 체적 일관(고화 시 같은 기공 체적 밀도; 열수축 없음). 지형 기여 = 퇴적 두께 하나의 `DeformationSource`(`src:volcano`, 비분리형, `changedRect`). 토사(Phase 22 `GeoField`)·운석 분출물 장부와 공유하지 않고 별도 재료로 식별. `overburdenAt` = 전부(기초는 따라 오르지 않음 — 매몰·하중).

## 16. 지형 성장과 유로 차단

퇴적이 지형이 되면 이후 용암(바닥 = 지형 − 반영분 + 퇴적)과 물(Phase 21 경로로 물 바닥 갱신, 수심 보존)이 그 위로 흐름(테스트: 3 m 고화 둑이 뒤의 흐름을 끝 쪽으로 돌림; 용암 댐 프리셋). 지형 갱신은 변경된 상자만(정점 기록·충돌체·물 바닥·대상물 반응이 그 영역만). 렌더 지형·충돌체·도로·물 바닥이 같은 높이(테스트: 런타임 높이 − 원본 = 반영 퇴적, 충돌체 높이 일치).

## 17. 화산체 성장

분출구 주변에 화산탄(아래)과 정지 용암이 퇴적되어 국소 원뿔이 자람 — 실제 분출·퇴적 질량에서만(별도 애니메이션 없음). 테스트: 화산탄 퇴적의 반 이상이 분출구 20 m 안. 높이맵 한계(오버행·동굴·수직 절벽 없음).

## 18. 화산탄 (`src/volcano/bombs.ts`)

분출구마다 1초마다 그 사이 화산탄 몫을 6개 집계 묶음으로(분출구·발사 번호 시드). 발사각 55–85°, 8–25 m/s, 크기 0.06–0.4 m, 밀도 2000 kg/m³ — 가정 범위(스트롬볼리식 폭발의 거의 수직 화산탄, Patrick et al. 2007 류의 관측을 200 m 월드에 맞게 자름). 비행 = Phase 23 `fly()` 그대로(중력 + 크기 항력, 지면 착지 또는 월드 밖 유출). 착지: 물체에 맞으면 그 물체가 받음(열 → 물체 노드, 질량 → 지붕, IMPACT 기록·운동에너지), 아니면 착지 정점의 퇴적층(고온). 비행 중 냉각 없음(수 초). 시각 스패터는 장식.

## 19. 화산재 (`src/volcano/ash.ts`)

연기(Phase 27 그을음 추적자)와 **다른 물질·다른 상태·다른 장부**. 라그랑주 덩어리: 1초마다 분출구별·크기 3등급(0.063 / 0.25 / 1 mm, 1/3씩 — 가정)으로 지정 높이(기본 60 m, 10–300 m — 플룸 상승은 계산 안 함)에 방출, σ₀ = 0.15 H. 이류: 덩어리 높이의 평균 바람 U₁₀(y/10)^0.14(Phase 26 공기층 프로파일). 침강: 구의 종단 속도(Schiller–Naumann, Re < 1000; 입자 밀도 2000 kg/m³ 가정) — 0.063 mm 0.24 m/s, 1 mm 약 4 m/s. 확산 σ² += 2K dt, K = 1 m²/s(가정). 비: Λ = 10⁻⁴·I^0.8 1/s(가정한 아래구름 세정 형식). 월드 밖·2000 m 위 = 유출.

## 20. 화산재 퇴적

착지한 덩어리 질량을 2.5σ 가우스 발자국에 정규화해 분배(월드 밖 몫은 유출). 건물 발자국 정점에 떨어지면 지붕이 받음(`ashCaught`): 모듈형 건물은 지붕 부재의 평면적 비례 정적 하중(Phase 25 `addLoad`, 해저드 volcano), 다른 건물은 하중(kPa)만 보고. 지면은 퇴적 두께(1000 kg/m³). 도로는 두께 보고, 10 cm 이상이면 통행 불가(가정한 지표). 보이는 낙하(덩어리)와 장부가 같은 묶음.

## 21. 화산 가스

장부 수량(분출 질량의 0.5 %)만 — 농도·이류·화학·독성·인체 영향 **계산하지 않음**(미지원 표시). Phase 29 인터페이스 `atmosphericSources(t)`: 가스·화산재·플룸 열의 위치·율. 가스·연기·화산재의 데이터 소유권 분리.

## 22. 용암–물

접촉 판정 = 정점의 물 깊이 > 1 mm(Phase 14 물, 열 셀 ¼ 평균). 물속 표면은 h_w = 500 W/(m²·K)(막·천이 비등 영역 100–1000의 대표값, 약한 근거)로 물에 열을 줌 → 물 열(Phase 26 추적자)만 오름, 용암은 급랭. **끓음·증기·폭발적 상호작용은 계산하지 않음** — 100 °C 넘는 물 셀 수를 HUD에 그대로 보고(숨기지 않음). 물 질량은 바뀌지 않음(테스트: 호수 체적 2 % 이내, 퇴적이 물을 밀어낸 몫 포함). 고화 용암은 물 바닥이 되어 흐름을 막음(이동 용암은 물 바닥이 아님 — 한계).

## 23. 용암–화재

화산이 있으면 화재 모델이 실행됨(용암 열이 연료를 데울 수 있으므로). 용암 열은 열 노드로 들어가고(§12), 착화는 Phase 27 규칙(열유속-시간 적분, 함수율, 파일럿)으로만 — 빛나는 용암 표면(≥ 525 °C)에 닿은 연료는 파일럿(`incidentProviders`). `contact()`(즉시 점화)는 쓰지 않음. 연소열은 화학 에너지 장부(`combustion` 계정), 용암열은 화산 장부(`volcanic` 계정) — 서로 다른 계정이라 중복 없음. 착화 원인 `lava`(`FireRuntime.ignitionSource`).

## 24. 식생

열 노출(복사 묶음 → 수관, 접촉 → 줄기 코어), 착화·연소(Phase 27), 측압으로 넘어짐(바닥 모멘트 ½ρgh²w·h/3 + ρu²hw·h/2 vs 바람 설계 모멘트), 매몰(높이의 0.8), 화산재 퇴적(지면). 매몰·넘어짐(`volcano`)과 화재 피해(`fire`, source volcano)를 구분해 기록.

## 25. 건물·구조

기초 매몰(퇴적 + 용암 ≥ 건물 높이 → BURIED), 용암 접촉(외곽 1층 부재로 열), 열팽창·온도 의존 강도(Phase 26 결합 그대로, 해저드 volcano), 지붕 화산재(정적 하중), 측압(정수압 ½ρgh²B, Phase 22 횡내력 규칙, 모듈형 1층 부재 손상) → 붕괴·잔해는 Phase 25. 화산이라는 이유로 삭제하지 않음. 무너진 건물은 장애물에서 빠짐.

## 26. 도로

표본점(5 m)의 용암 깊이·고화 두께·화산재·표면 온도. 용암 ≥ 2 cm 또는 고화 ≥ 0.3 m(잔해 기준과 같음) → 차단, 화산재 ≥ 0.1 m → 통행 불가. 도로망은 수정하지 않음(실행 상태만), 종료 시 원래대로.

## 27. 차량·사람

차량: 접촉 기록(LAVA_CONTACT), 0.3 m 이상에서 고정(움직임 제한), 매몰(높이 0.6), 화산탄 충돌 기록, 차체 열(접촉·바닥). 사람: 접촉 기록·접촉 시간, 매몰(0.7), 화산탄 충돌 기록 — **화상·흡입 등 생리 피해는 계산하지 않음**(Phase 33–34).

## 28. 다중 재해

바람(화산재 이류, 대류 계수), 비(화산재 세정, 물), 홍수(용암–물), 지진(가열된 집 붕괴), 산사태·지형 변형(같은 Phase 21 엔진의 다른 원천 — 용암 바닥은 모든 원천을 포함한 실행 지형에서), 화재(같은 열 노드), 구조 붕괴(무너지면 장애물 해제). 테스트 5조합(장부 닫힘). 순서 의존: 열 시스템 안에서 열 런타임 → 화산 → 화재 → 열 단계(같은 단계 열원), 지형 반영은 다음 단계(Phase 22와 같은 한 단계 지연).

## 29. 질량·에너지 장부

**질량**: supplied = lavaSupplied + bombsLaunched + ashReleased(대기분 포함); 보유 = mobile + solidified + bombsInFlight + bombsDeposited + bombsCaught + ashAirborne + ashDeposited + ashCaught + outLava + outBombs + outAsh; residual = 차이(측정 10⁻¹³–10⁻¹⁵). gas는 별도.
**에너지**(기준 = 대기 기준 온도의 현열 + 잠열): supplied = 용암 + 화산탄 + 화산재(플룸) 에너지; = 내부(이동 + 고온 퇴적) + 비행 중 + toGround + toObjects + toWater + toAir + radiated + outflow + plumeHeat(미해결 — 층 위 플룸) + residual. 정보: latentReleased, potentialReleased(중력 위치에너지 감소 — 점성 소산, 운동량은 관성 없는 모델이라 추적 안 함). 열 세계: `ThermalLedger.volcanic` = toGround + toObjects + toWater + toAir + radiated(하늘로 나간 복사는 열 장부 `radiationSky`).

## 30. 피해 귀속

### 38.2 벤치마크로 찾아 고친 문제

1. **최악 스텝 258 ms(14번, 타는 숲)** — 복사 묶음 수신체 목록이 같은 스텝에 일제히 재구성되고, 열 단계가 매 스텝 Map과 쌍 배열 정렬로 수천 개 객체를 할당. 고침: 재구성을 스텝당 12개로 분산(키로 시차), 셀·칸 누적은 재사용 타입 배열, 물체·엔티티는 공간 격자로 검색 → 같은 장면 최악 62 ms(부하 7–13), 단독 측정 8 ms(유동 2.0, 냉각 3.1, 열 1.3 ms).
2. **냉각 비용(뉴턴 12회 반복)** — 이전 표면 온도에서 시작(웜 스타트).
3. **1시간 분출의 냉각** — 움직이지 않는 용암도 0.1 s마다 계산 → 1초 주기·셀별 마지막 냉각 시각으로 정확히 적분(퇴적층과 같은 주기).
4. **1시간 분출의 유동** — 공여 셀마다 하위 단계마다 η·τ_y·크러스트를 다시 계산하고 모든 이동 용암을 순회 → 호출당 한 번(온도는 하위 단계 사이에 바뀌지 않음, 새로 닿은 정점은 섞인 온도로), 깨어 있는 공여 셀 목록만 순회. 19번 재측정(부하 [10, 8.3, 9.9]): **245.7 → 188.8 ms/s**, 유동 135.2 → 94.3, 냉각 60.0 → 52.6, 열 35.6 → 30.6 ms/s — 결과(공급 14 976 t, 고화 357.5 t, 잔차 5·10⁻¹² / 1·10⁻¹¹)는 그대로. 1시간 뒤 활성 7641·고온 8101 정점에서 1배속 실시간의 19 %(16배속이면 시뮬레이션이 느려지고 UI는 멈추지 않음 — 프레임당 물리 예산).
5. (정확성, 시뮬레이션에서) 비행 중 화산탄의 장부 이중 계산, 나노그램 잔여 막의 열 이득 폭주, 비우는 셀의 반올림 에너지, 용암 ↔ 퇴적층 양방향 과전달 — §10.

## 39. 과학적 검증

**질량** — 분출 질량 = 공급 체적 × 체적 밀도를 정확히 기록(불규칙 단계 합 = 총량 1e-9); 흐름 중 보존(순수 테스트 잔차 < 10⁻¹², 실행 10⁻¹³); 고화 후 유지(정지 = 같은 정점으로 질량 이동, 두께 = 질량/ρA); 경계 유출 기록(열린 가장자리 테스트); 화산재 이동·퇴적 보존(공중 + 지면 + 지붕 + 유출 = 방출, 분출 중 매 순간 닫힘 — 비행 중 화산탄 이중 계산 버그를 이 검사로 찾음).
**열에너지** — 열용량·온도: Phase 26 엔탈피 표 왕복(500–1150 °C 0.1 K), 잠열 = 표의 액상선–고상선 차; 냉각 시 내부 에너지 감소(장부 항목 > 0); 받은 열 = 잃은 열(열 장부 `volcanic` = 화산 장부 전달 열, 1e-9; 열 세계 잔차 < 10⁻⁹); 고화의 잠열은 표에 포함되어 같은 장부(정보용 방출량).
**유동** — 평지: 대칭 확산 후 항복으로 정지(비대칭 < 10⁻⁶, 정지 후 면 계산 0); 경사: 하류로 진행; 점성 차(안산암 ≪ 현무암), 냉각(1110 °C < 1170 °C 진행), 정착 후 지형 갱신 멈춤(게시는 변화가 있을 때만); 수렴: 격자 1 / 0.5 m 전면 20 % 이내, 시간 단계 0.1 / 0.05 s 10 % 이내.
**기존 시스템** — 물 질량 보존(호수 체적 2 % 이내 — 퇴적이 밀어낸 몫 포함, Phase 21 경로가 수심 보존); 화재 열 중복 없음(입사 열유속 = 용암 단계 1회, 연소열은 별도 계정); 구조 파괴 원인(가열된 건물 → volcano, 타면 fire, 지붕 화산재 = causeHazard volcano, 무관한 열원 근처 지진 붕괴는 열 실패로 세지 않음); 원본 월드 복원(fingerprint·지형 높이); 객체 ID 독립성(다른 ID 같은 해시); 결정론(같은 계획 같은 필드·같은 해시, 초기화 재실행 같은 해시).

검증하지 않은 것: 실제 용암류 관측(도달 거리·속도·두께)과의 비교 — 이 모델의 어떤 결과도 측정과 대조해 보정하지 않았습니다(`validated: false`).

## 43. 과학적 한계

- 축약된 국소 분출 모델 — **실제 분화 예측·용암류 도달 예측에 사용할 수 없음**; 재난 대응·대피 계획·구조물 안전 판단 불가.
- 공급량은 지정값: 마그마 저장소 압력·화도·지각 파괴·분출 역학을 계산하지 않음.
- 용암은 깊이 평균 Bingham 판 흐름(관성 없음, 셀 단위 근사): 3차원 비뉴턴 유동·용암 동굴·제방 구조·팽창·분기 돌파 없음; 정밀 다상 CFD가 아님.
- 결정은 온도의 선형 함수, 기포·탈가스·조성 변화 없음; 안산암 열물성은 현무암 값(약한 근거), 액상선·고상선 가정.
- 크러스트는 단순 경계층(한 평균 온도 + 경계층): 두께 방향 온도 분포를 풀지 않으며 표면이 관측보다 다소 뜨거움(§14); 고화된 퇴적은 다시 흐르지 않음; 퇴적층들은 한 층으로 섞임(온도 평균).
- 높이맵: 오버행·동굴·수직 절벽 없음, 퇴적 다짐·침식 없음, 고화 시 열수축 없음.
- 화산재: 지정 방출 높이(플룸 상승·난류·우산 구름 없음), 3등급 크기·밀도·확산계수·세정계수 가정, 응집·재부유 없음.
- 화산 가스: 장부 수량만 — 농도·화학·독성 없음.
- 용암–물: 막비등 계수 하나(약한 근거), **끓음·증기·폭발적 상호작용 없음** — 물이 100 °C를 넘어도 계산상 액체로 남음(HUD에 보고).
- 화산탄: 가정한 발사 범위, 비행 중 냉각 없음, 충돌 손상 지수 없음(기록만).
- 사람의 화상·흡입 피해 없음(Phase 33–34); 차량 손상은 접촉·고정·매몰 기록뿐.

- 200 m 월드에서 대규모 화산 전체를 재현할 수 없음.

## 44. Phase 29 (Atmosphere, Pressure & Atmospheric Removal) 호환
