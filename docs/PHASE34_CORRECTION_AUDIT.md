## 3. H1 — `src/human/balance.ts` `stepBalance`

- **재현:** `control: 0`, 기울기 모멘트 20 N·m → `cap = 0`, `demand = cm / 0 = Infinity`. 부하 없음(`cm = 0`)에서는 `'standing'`.
- **실제 경로:** `PhysiologySystem`은 `BALANCE[cap]`과 `canStand = cap !== 'unableToAct'`를 같은 줄에서 함께 정하고, `HumanSystem`은
  `canStand = false`이면 `stepBalance`를 부르기 전에 몸을 놓습니다(원인 'physiological'). 따라서 0은 시스템에서 `stepBalance`에
  도달하지 않습니다(BALANCE 범위 {1, 1, 0.8, 0.5, 0}). 직접 호출(시험·향후 코드)에서만 무한대가 생깁니다.
- **의미 정의:** 발목 모멘트를 전혀 쓸 수 없음 = 자세 제어 없음 → 서 있는 모델이 적용되지 않으므로 그 스텝은 균형 상실('fall')입니다.
  교정 모멘트 0, 요구도는 물리적 지지 용량(W·모서리 거리) 대비 요청 모멘트로 보고합니다(유한). ε 나눗셈은 쓰지 않았습니다.
- **정상 범위:** `control` 없음과 `control = 1`이 비트 단위로 같음(시험), 0.5는 같은 요청에 요구도 2배·모멘트 절반에서 포화(시험).

## 4. H2 — `src/physiology/engine.ts` 선량 적분

- 흡입 의존 항(CO·CO₂·O₂ 결손·흡입 연기·가스 FED)은 표본이 호흡 중일 때만 0이 아니고, 이전 표본과 사다리꼴로 적분됩니다. 전환이
  일어난 구간에서는 이전 표본(호흡)과 현재 표본(잠김)의 평균 — **전환 시각을 구간 중앙으로 둔 것**과 같습니다. 실제 전환 시각은 표본
  사이 어디인지 모릅니다(기도 판정은 0.1 s 표본).
- **시험 결과(수정 전 코드에서 통과):** 1000 ppm CO에서 잠김 1.0 s + 0.3 s 두 번 → 선량 = 1000 × (호흡 시간) 정확히(전환 두 번의 ±r·dt/2가
  상쇄), dt 0.05 s에서도 같음; 0.1 s 간격 반복 잠김에서 정확; 저산소 O₂ 결손 선량도 같음; 잠긴 동안 O₂ FED·흡입 연기 질량 불변.
- **호흡 비의존 경로는 계속:** 방향성 복사 선량은 잠긴 동안에도 쌓이고(시험: 5 kW/m²에서 ∫q^{4/3}dt 정확), 공기 중 연기 노출 ∫C dt도 계속
  (기도 위치의 농도 — 흡입량과 별개). 호흡 열손실(현열·잠열)은 잠긴 동안 0(시험).
- **한계(문서화):** 잠긴 도중의 스냅숏에서는 선량이 기도 시계(누적 잠김 시간, 구간 전체를 현재 상태로 셈)보다 정확히 r·dt/2 많습니다
  — 전환 시각 해상도(0.1 s)의 절반. 잠김이 끝나면 차이가 닫힙니다(시험). 결함이 아니므로 코드를 바꾸지 않았습니다.

## 5. H3 — 밀폐 구획 O₂와 사람별 호흡

- **재현:** 0.02 m³(O₂ ≈ 0.17 mol)에 사람 4명, 교환 0, 900 s. 수정 전: 사람들이 '호흡으로 마신 O₂' 합 0.73 mol, 구획이 내준 O₂ 0.43 mol —
  구획은 재고에서 잘라냈지만(clamp) 사람 장부는 요구량 전부를 공기에서 마신 것으로 기록했습니다(존재하지 않는 O₂).
- **수정(`PhysiologySystem`):** 한 생리 스텝에서 구획마다 거주자의 호흡 O₂ 수요를 모은 뒤, 재고가 부족하면 모두에게 같은 비율
  f = 재고 / 수요를 배분(수요 비례 — 순회 순서와 무관)하고, 각자의 나머지 (1 − f)·수요는 몸 저장분에서 쓴 O₂(`o2Debt`)로 기록합니다.
  CO₂ 배출은 대사량(RQ × 실제 O₂ 소비)이라 바꾸지 않았습니다. 구획 장부 `clamped`는 이제 "몸 저장분이 메운 부족량"입니다.
- **수정 후:** Σ(사람 o2 − o2Debt) = 구획 o2Taken (1e-9), 구획 O₂ ≥ 0, 부족분 > 0 확인. 생성 순서를 뒤집어도 사람별 O₂가 같음(위치별 비교).
- 호흡하지 않는 사람(기도 잠김)은 수요 0 — 몸 저장분만 씀(기존). 구획에 들고 나는 사람은 그 표본의 위치로 정해집니다(표본 단위).
- 공급 지표는 다음 표본의 구획 조성(O₂ ≈ 0)에서 나오므로 고갈이 그대로 반영됩니다.

## 6. H4 — 밀폐 구획 조성·압력

- `total = pV/(RT)`는 **일정 압력·체적·온도**에서의 총 몰수입니다. O₂·CO₂만 추적하고 나머지(N₂·Ar)는 암묵적으로 `total − O₂ − CO₂`이며,
  호흡으로 줄어든 몰수(RQ 0.85 < 1)는 외부와 통하는 틈으로 보충된다고 봅니다(외부 저장소 근사). 이 가정에서 `o2/total`, `co2/total`은 몰분율
  그대로이고 합 ≤ 1입니다(시험: 1000 s 강제 소비 후에도 0 ≤ x ≤ 1, O₂ + CO₂ + 초기 불활성 몫 ≤ 1).
- 환기 교환은 정확한 지수 이완 n_ref + (n₀ − n_ref)e^{−λt/3600}(시험, 1e-9).
- 구획 온도는 생성 시 고정(구역 공기 온도 또는 열 모델 기준). 사람 열에 의한 구획 가열은 일방향 결합이라 반영하지 않습니다(한계).
- 결함이 아니므로 코드를 바꾸지 않았습니다.

## 7. H5 — 생리 시계

- **스케줄러 계약 확인:** `ctx.time` = 이 물리 스텝의 시작 시각(물리 스텝·postPhysics 뒤에 `time += dt`), interval N 시스템은
  `stepIndex % N == 0`인 스텝(0, 6, 12, …)에 `dt × N`을 받습니다. 생리 표본은 물리 스텝 뒤에 찍히므로 표본 시각 = `ctx.time + dt/N`(올바름).
- **결함:** 첫 호출(스텝 0, 경과 1/60 s)에서 0.1 s를 적분 → 생리가 항상 5 스텝(0.083 s) 앞서 적분됐습니다. 수정 전 시험: 1/60 s 뒤 CO 선량
  100 ppm·s(기대 16.7), 표본 시각 0.9167 s에 적분 시간 1.0 s.
- **수정:** 이전 표본 시각부터 적분(`h = t − lastTime`, 첫 호출은 실행 시작부터 → 1/60 s; 이후 0.1 s). 구획도 같은 h.
- **수정 후:** 모든 표본에서 적분 시간 = 생리 시각 = 표본의 시뮬레이션 시각(1, 10, 37.3 s), 시뮬레이션 시각보다 0.1 s 미만 뒤(표본 간격),
  4 s + 6 s = 10 s 한 번(비트 동일, 일시정지·재개), 리셋 뒤 시계 0에서 다시. 배속은 스텝 수만 바꾸므로(스텝 기반) 같은 결과.

- **수정:** 출처 항목 `co`, `co2` 추가 — `reference`(기준 공기, 가정) / `fire.sootRatio` / `fire.o2Deficit`(추정) / `zone`(실험 경계 조건) /
  `confined` / `buriedUnknown`. 인스펙터는 추정 출처에 '(추정값)'을 붙이고, CSV는 `src_co`·`src_co2` 열과 머리말 설명, JSON은
