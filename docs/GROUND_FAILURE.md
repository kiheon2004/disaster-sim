# Phase 22 — Sinkhole & Landslide Physics

지반이 **스스로 무너지는** 단계입니다. Phase 21의 지형 변형 엔진은 "지면이 어떻게 움직이는지"를 입력으로 받았습니다. Phase 22는 그 원인을 계산합니다.

- **싱크홀**: 숨은 공동 위 덮개(지붕)의 안정성 → 플러그 붕괴 → 벽 붕괴로 함몰이 넓어짐.
- **산사태**: 사면 안정성(무한사면 안전율, 강우 침투, 지진 Newmark 변위) → 파괴된 토층이 흘러내려 퇴적.

결과는 Phase 21과 같은 경로로 지형·충돌체·물 바닥·건물 기초·도로·렌더링에 **원자적으로** 반영됩니다. 월드 문서는 바뀌지 않습니다.

모든 모델은 **교과서적 단순 모델**이고, 대표 물성은 문헌 범위의 대표값입니다. 결과는 "이 입력에서 이 단순 모델이 내놓는 답"이지 실제 부지의 예측이 아닙니다(§26). 근거가 경험식인 값(Newmark 파괴 임계값, Voellmy ξ, 충격 계수 α)은 그렇다고 표시합니다.

## 2. Phase 21 잔여 작업

### 2.1 피해 원인 귀속 (커밋 da7f029, 21d775d)

**원인 분석**: 모듈형·일반 건물의 붕괴 경로가 피해 이벤트에 "마지막으로 하중을 준 채널"이 아니라 바람 경로의 기본값을 쓰고 있었습니다. 바람 0 m/s에서도 지진·홍수·지반으로 건강도가 소진된 건물이 `wind`로 기록됐습니다. 차량이 토사에 밀려 다른 물체와 충돌하면 그 충돌도 바람으로 기록됐습니다.

**수정**
- 붕괴 경로마다 건강도를 소진시킨 **지배 해저드**(earthquake / flood / ground)를 붙입니다. 단, 바람 피로가 실제로 작용 중이면(하중비 > 피로 시작값) 바람이 유지됩니다 → 기존 바람 골든 결과 불변.
- 특정 이벤트 없이 상태만 바뀐 경우 `MetricsSystem`은 바람이 그 물체를 거의 누르지 않을 때(하중비 < 0.3)에만 실제로 피해를 준 채널로 대체합니다.
- 모든 피해 기록에 `contributors`(그 순간 해저드별 누적 피해), `origin`(최초 원인 = 최대 기여), `source`(지반 원인 현상, 예 `landslide:p1`)가 추가됩니다(CSV/JSON 열 추가).
- `ForceLedger`의 `pushedBySediment`로 토사에 떠밀린 차량의 이동·충돌은 `ground`로 귀속합니다.

**회귀 테스트**(`attribution.test.ts` 4개, `groundFailure.sim.test.ts` 2개): 바람 0 + 홍수, 바람 0 + 지진, 바람 0 + 침하, 바람 + 지진 + 홍수(모든 이벤트가 작용 중인 해저드를 가리키고 기여 이력이 남음), 침하 + 산사태(바람 0, 바람 귀속 0), 도로 차단 실행의 피해가 모두 `ground`·`landslide:`.

### 2.2 첫 변형 프레임 지연 (커밋 1fabe16)

`scripts/probe-first-frame.mjs`로 첫 실행 프레임을 셰이더 / Rapier / 메시 / GC / 캐시로 분해해 측정했습니다.

### 2.3 런타임 상태 구조와 중간 저장

- 저장은 항상 **원본 월드 + 실험 계획**(v7)입니다. 시뮬레이션은 문서를 쓰지 않으므로 저장된 프로젝트는 언제나 t = 0에서 다시 시작합니다.
- 실행 중 저장/내보내기를 누르면 "원래 월드와 실험 계획만 저장되었습니다. 실행 중 상태(변형된 지형·토사·물·피해)는 저장되지 않습니다 — 실행 중간 저장은 지원하지 않습니다." 안내가 뜨고, 저장 버튼 툴팁도 실행 중에는 같은 내용을 표시합니다(KO/EN).
- `src/simulation/runtimeState.ts`: 나중에 중간 저장을 추가할 때 필요한 상태를 구성요소별로 분류합니다 — `document`(이미 저장됨), `derived`(재계산 가능: 이벤트 진행, Phase 21 엔진·변위장), `state`(반드시 저장: 시계·RNG, 엔티티 상태, 잔해, 도로, 물 격자, **GeoField 전 배열 + 수지 + 모델 단계**, 결과 기록), `external`(Rapier 바디·접촉 — 엔진 스냅샷 API 필요). `SimulationController.runtimeState()`가 실행 중 크기를 측정하고, 테스트가 지반 상태가 `state`로 잡히는지 확인합니다.

- 겉보기 점착력(모관 흡입력)은 m → 1에서 사라집니다(포화되면 모래성이 무너지는 이유).

## 4. 공유 지반 상태장 (`GeoField`)

지형의 1 m 정점 격자 위 배열(정점당):

| 배열 | 의미 | 단위 |
|---|---|---|
| `material` | 역학 프로파일 | – |
| `thickness` | 활동면/암반 위 토층 두께 | m |
| `water0`, `waterRise` | 초기 지하수위 비 m₀, 침투로 인한 상승 | – |
| `strength` | 시드 공간 변동 배수 | – |
| `bed` | t = 0 이후 정적 지면 변화(침식 < 0) | m |
| `loose`, `looseMass` | 퇴적된(이미 느슨해진) 재료 | m, kg |
| `h`, `mass`, `mu` | 이동층 두께(부피 증가 반영)·질량·바닥 마찰 | m, kg, – |
| `qx`, `qz` | 이동층 면 플럭스 | m²/s |
| `fs`, `nmV`, `nmD` | 마지막 안전율, Newmark 상대속도·변위 | –, m/s, m |
| `owner`, `evaluate`, `failed` | 지배 현상, 평가 대상, 파괴됨 | – |

- **지형 기여 G = bed + h** — 움직이는 토사도 표면이므로 충돌체·렌더·물 솔버가 모두 봅니다. 이 G가 Phase 21 엔진의 원천 하나(`GroundFailureSource`, 전 격자, version = `field.rev`)로 들어갑니다.
- **수지(Float64)**: 이탈(in-situ 체적·질량, 부피 증가 후 체적) = 이동 + 퇴적 + 월드 밖 유출 + 잔차(반올림). 공동으로 떨어진 플러그는 별도(`intoCavity`) — 지표가 아니라 지하로 갑니다.
- **이중 부피 증가 방지**: 퇴적물이 다시 움직이면 `loose`에서 먼저 떼어 그 자체 밀도로 이동(다시 부풀리지 않음). 그 아래 원지반만 B배.

## 5. 싱크홀 모델 (`sinkhole.ts`)

높이장은 공동을 담을 수 없으므로 **공동은 숨은 상태**입니다: 반경 a, 높이 h_c의 원통이 두께 H의 덮개 아래에 있습니다.

1. **지붕 안정성 — 플러그 파괴**(원통 측면 연직 전단; CIRIA C574, Waltham et al. *Sinkholes and Subsidence* 2005 ch. 8):
   FS = 2πaH·(c + K₀·σ′ᵥ·tanφ) / [πa²·(γH + q)], σ′ᵥ = (γ − m·γw)·H/2, K₀ = 1 − sinφ(Jáky).
   임계 반경 a_c = 2H·(c + K₀σ′ᵥtanφ)/(γH + q). c = c′·변동 + 겉보기 점착력·(1 − m). q = 플러그 위 하중(건물 기초압, 고인 물, 퇴적물, 지정 하중).
2. **발생 방식**(모두 물리량 입력): `growth` 공동 반경 증가 a(t) = a₀ + 속도·t(용해·침식 자체는 계산 안 함 — 속도가 입력), `supportLoss` 지붕 저항의 **지정** 감소 L(t)(라벨 표시), `water` 덮개의 지하수위 상승(비가 오면 침투도 합산), `load` 지표 하중 증가 q(t). 모든 방식이 건물·물·퇴적 하중을 함께 느낍니다.
3. **발생(FS < 1)**: 플러그(반경 a)가 d = h_c − (B − 1)·H 만큼 낙하 — 공동 높이에서 부풀어 오른 플러그가 차지하는 부분을 뺀 값. **d ≤ 0이면 공동이 막혀(choke) 지표 함몰 없음**(보고). 낙하는 자유낙하 운동학 d(t) = d·min(1, (t/t_f)²), t_f = √(2h_c/g) — 애니메이션 속도 선택이 아님.
4. **점진적 벽 붕괴**: 매 갱신 함몰 벽을 Culmann 절토 한계로 검사(H_c = (4c/γ)·sinβ·cosφ/(1 − cos(β − φ)); 연직이면 Rankine 높이). 벽 높이에서 안정한 경사를 넘는 부분의 절반(모래더미 전도 규칙)이 떨어져 토사 흐름으로 바닥에 쌓입니다.
5. **형상은 결과**: 점성토 덮개는 가파른 낙하형 함몰(dropout), 사질토는 안식각까지 퍼진 그릇형, 시드 변동이 있으면 불규칙, 벽 붕괴가 진행되면 가장자리가 점진적으로 넓어짐(`expansion` 이벤트). 형상을 고르는 파라미터는 없습니다.
6. **구조물**: 플러그 위 기초는 지지 상실(`supportLoss` 방식에서는 지지력 배수), 낙하하는 지면을 따라 Phase 21 기초 반응(접지율·β) → 기초 파괴 마일스톤. 지붕 위 건물은 하중 q로 지붕을 더 빨리 무너뜨립니다(테스트).

미리보기(`SinkholeModel.predict`): a_c, FS₀ → FS_end, 낙하 d 또는 막힘, 예상 함몰 반경(사질토: a + d/tanφ), 낙하 시간.

## 6. 산사태 모델 (`landslide.ts`)

**발생 영역**(원 또는 다각형, 최대 64점)과 **퇴적 영역**(흐름이 정하는 결과)을 구분합니다.

1. **무한사면 안전율**(Skempton & DeLory 1957; Duncan, Wright & Brandon ch. 6):
   FS = [c + (γ − m·γw)·z·cos²β·tanφ] / [γ·z·sinβ·cosβ]. β = **현재** 지면 경사(다른 현상이 사면을 바꾸면 반영 — "사면 변경" 유발), z = 토층 두께, m = m₀ + 지정 상승 + 침투 상승. 길이 ≫ 깊이인 얕은 평행 활동에만 유효.
2. **유발 요인**: `rain`(침투 → 걸린 지하수위 Δm = I/(n·배수비율)/z), `saturation`(m을 목표까지 지정 상승), `earthquake`(Newmark), `slope`(사면 변경 — 항상 평가됨), `user`(시작 시 영역 전체 **지정** 파괴, 라벨 표시). 모든 메커니즘은 유발 요인과 무관하게 항상 평가됩니다.
3. **Newmark 강체 블록**(Newmark 1965; Jibson 1993/2011): a_c = (FS − 1)·g·sinβ, 지반가속도의 사면 하향 성분이 a_c를 넘는 동안 미끄러짐, 영구변위 D를 이중 적분. **D ≥ 임계값(기본 0.1 m, 경험적: Wieczorek et al. 1985 / Jibson & Keefer 1993의 5–10 cm)이면 파괴.** 60 Hz 매 스텝.
4. **파괴**: FS < 1 또는 D ≥ 임계 → 활동면 위 토층 전체가 부피 증가해 이동층이 됨. 바닥 마찰 tanφ′·(1 − r_u), r_u = m·γw/γ(포화된 토사가 더 멀리 감). 제거되면 위쪽 단애가 가팔라져 다음에 파괴(후퇴 파괴, 발생 영역 안에서만).
5. **순서 의존성**: 젖은 뒤 지진이 오면 건조할 때 지진보다 Newmark 변위·파괴량이 큼(테스트).

미리보기(`LandslideModel.preview`): 현재 지형에서 영역 정점별 FS(유발 요인의 지하수위 기준), 최소 FS, 불안정 정점 수, 예상 붕괴 체적.

## 7. 토사 흐름 (`granular.ts`)

깊이 평균 Voellmy 유동(RAMMS::Debris Flow, DAN3D 계열; Hungr 1995, Christen et al. 2010)의 가장 단순한 명시적 형태 — 물 솔버(Phase 14)와 같은 면 플럭스 local-inertial 형식(Bates et al. 2010):

- q ← q − g·h_f·∂s/∂x·cos²β·Δt (압력 + 중력, 사면 방향 항의 수평 투영)
- Coulomb 바닥 마찰: |q|를 μ·g·h_f·cos²β·Δt만큼 줄이되 방향을 바꾸지 않음 → 표면 경사 tan⁻¹μ(안식각)에서 정지
- Voellmy 난류항: q ← q / (1 + g·|q|·Δt/(ξ·h_f²)), ξ 기본 400 m/s²(**경험적 보정값**, 보통 100–1000)
- 각 면 플럭스는 한 셀에서 빼서 이웃에 더함 + 유출량을 셀 보유량으로 제한(양수성) → **부피·질량이 반올림 오차까지 보존**. 열린 가장자리는 유출 기록.
- **운동량은 질량과 함께**: 하위 스텝 사이에 이어지는 면 플럭스 q = h·u는 면의 흐름 깊이가 줄면 q·h_f/h_f,prev로 줄입니다(남은 층은 유량이 아니라 속도를 유지). 이것이 없으면 빠져나간 셀의 얇은 꼬리 막이 본체의 유량을 물려받아 10–25 m/s로 달렸습니다(§18).
- 모든 면이 REST_TIME(0.5 s) 동안 **1 cm/s 미만**(U_REST)인 셀은 정적 퇴적물로(표면은 바뀌지 않음). 안식각 근처의 명시적 마찰 갱신은 플럭스가 1e-5 m²/s 수준에서 0이 되지 않아, 이 문턱이 없으면 정착한 함몰이 영원히 "움직이는" 상태였습니다.
- CFL 0.4 하위 스텝, 속도는 **면의 깊은 쪽 깊이**로 계산(받는 쪽의 거의 0인 깊이로 나누면 젖음 전선에서 km/s 속도가 나와 시간 간격이 무너졌음 — §18). 실행은 토사가 움직이는 동안 계획된 끝을 넘어 최대 300 s까지 연장됩니다(정지 전 종료 방지).
- **지형 동기화 허용치 1 mm**: 상태장(진실, 수지 정확)은 모든 변화를 갖고, 지형·충돌체는 어딘가에서 1 mm 넘게 어긋날 때만 다시 맞춥니다. 1 mm 미만의 크리프는 상태장에 쌓였다가 다음 실제 변화와 함께 반영됩니다(지형 ↔ 상태장 차 ≤ 1 mm, 테스트).
- 함몰 벽은 같은 마찰계수로 움직이기 시작하고 멈추므로(정지/동마찰 이력 없음) 안식각 근처에서 0.3 m/s 이하로 천천히 흘러 정착까지 60–100 s 걸립니다(모델 특성, §22).

포함하지 않는 것: 경로상 침식(entrainment), 별도 유체상, 이방성 토압.

## 8. 물과의 상호작용

- 토사(G = bed + h)는 Phase 21 바닥 갱신 경로로 물 바닥이 됩니다 — **수심 보존 = 물 질량 정확**. 호수에 들어간 퇴적물은 물을 밀어내 수위를 올립니다(테스트: 시간 평균 수위 상승, 체적 오차 < 1e-6; 브라우저 7.4e-14).
- 하천 차단: 퇴적물이 수로 바닥을 올리면 같은 경로로 물이 막히고 상류에 고입니다(별도 규칙 없음 — 지형이 바뀐 결과).
- 강우 → 침투(Phase 14 버킷) → 지하수위. 침투 속도는 Phase 14 설정(`infiltrationScale`)을 따릅니다. 테스트는 시뮬레이션 시간 절약을 위해 10배를 쓰며 이는 설정값으로 명시합니다.
- 고인 물은 지붕 하중 q에 포함됩니다.

## 9. 오브젝트 상호작용 (`objects.ts`, `SedimentForceSystem`)

토사는 **연속체**(깊이 평균층)이며 입자별 강체가 아닙니다.

| 대상 | 법칙 |
|---|---|
| 동적 바디(차량·잔해·쓰러진 시설물) | 항력 ½·ρ_d·C_d·A·\|u_rel\|·u_rel을 매 스텝 `ForceLedger` 원천 `sediment`로(물 항력과 같은 법칙), ρ_d = 셀 질량/체적 |
| 사람 | 안정성 비 max(항력/(μW), 전도 모멘트/복원 모멘트) ≥ 1 → 넘어짐(원인 `ground`) |
| 건물 | 정지토압 ½·K₀·γ_d·d²·B + 동압 α·ρ_d·u²·h_f·B(α = 1, 문헌 범위 0.7–5의 하단: Hübl et al. 2009)을 구조계 수평 저항(홍수·지진과 같은 용량)과 비교, 0.5 초과분이 피해 누적 → 지반 채널 |
| 가로등·표지판·담장·나무 | 기초 모멘트 vs 바람 설계 모멘트 → 전도(자유 바디가 됨) |
| 매몰 | 물체 높이의 일정 비율 이상 덮이면 `BURIED`(사람 0.7, 차량 0.6, 소형 구조물 0.8) |
| 도로 | 퇴적 두께 ≥ 0.3 m → 통행 불가(원인 기록, 도로망 불변) |
| 기초 | **지면 자체**(bed)를 따라감 — 위에 쌓인 퇴적물은 기초를 올리지 않고 하중·매몰로만 작용 |

포함하지 않는 것: 개별 바위 충격, 마모, 물체에 의한 흐름 차단, 벽면 압력 분포(합력 하나).

## 10. 지형·충돌체·도로 갱신 (Phase 21 경로)

- 원천 하나(`GroundFailureSource`)가 전 격자를 덮지만 반응은 **실제로 지면이 바뀐 발자국 아래에서만** 실행합니다(1 m 격자 스캔). 전 격자 사각형 때문에 모든 오브젝트를 깨우고 다시 맞추던 문제를 수정했습니다.
- 원래 지면 지지력은 필요할 때만(`engine.originalSampler()`) 계산합니다. 사전 계산(priming)은 지정 원천에만 적용합니다.
- Phase 21의 로그·`deformPeak` 마일스톤은 지정 원천에만 붙습니다(지반 붕괴는 자체 마일스톤).

- 도로: Phase 21 단차·경사 판정 + 퇴적 두께 판정. 두 판정이 같은 표면에서 함께 걸리면 Phase 21 갱신이 도로 상태를 다시 만들면서 퇴적 정보를 지우던 버그를 브라우저 검증에서 찾아 수정했습니다(퇴적 원인 보존, 차단을 한 번 기록).

9. 지면 프로브: 지반 재료·경사·토층·지하수위·안전율·높이 변화·원인 `p1 · 싱크홀`
10. 타임라인 `sinkholeInit`·`sinkholeExpansion`·`foundationFailure`, 로그 번역
11. 실행 중 저장 → 원래 월드만 저장, "실행 중간 저장은 지원하지 않습니다" 안내, 런타임 상태 구조에 `groundFailure: state`
12. 초기화 → 원래 지면 정확 복원, 나가면 지문 불변
13. 산사태 다각형 발생 영역을 지도 클릭 4번 + Enter로 그림
14. 안전율 지도 미리보기: 최소 FS 0.67, 불안정 576/576, 예상 1,152 m³; 진행 시간 6 s 입력
15. 실행: 포화 상승으로 사면 파괴, 흐름 화살표 184개, 수지 잔차 −3.2e-5 m³ / 1,325 m³
16. 토사가 정지해 산기슭에 퇴적(이동 0.6 m³), 원본 월드 불변
17. 산기슭 도로가 퇴적물로 통행 불가(도로 패널), 도로망 불변, 바람 귀속 없음
18. 호수로 들어간 산사태: 물 체적 변화 7.4e-14(상대), 수면 아래 퇴적 417 m³
19. 지진 + 젖은 사면: Newmark 변위 5.4 cm(임계 5 cm) → 709 정점 파괴, HUD 표시
20. 비 + 지진 + 싱크홀 + 산사태(바람 0): 피해 해저드 `ground`·`flood`만(바람 0)
21. 싱크홀 + 다각형 산사태 저장·불러오기(스키마 v7)
22. 꺼진 싱크홀·산사태는 아무 일도 하지 않음(지반 상태장·HUD 없음)

검증 중 발견해 고친 것: 발생 방식을 바꾸면 새 입력이 비어 비활성으로 남던 것(기본값 채움), Phase 21 도로 갱신이 퇴적 원인을 지우던 것(막힌 도로가 집계되지 않음), 지면 프로브가 홍수·지정 변형 때만 열리던 것, HUD·로그가 내부 이벤트 id를 쓰던 것(→ 인스턴스 id), 토사가 아직 움직이는데 실행이 끝나던 것(최대 300 s 연장). 긴 연속 실행 중 한 번 브라우저 탭이 닫힌 적이 있으나(해당 시나리오 단독 실행 정상) 이후 두 차례의 KO/EN 전체 실행은 모두 22/22였습니다.

## 22. 과학적 한계

- 모든 안정성 모델은 **한계평형 단순 모델**입니다: 무한사면(얕은 평행 활동만 — 회전·깊은·암반·3차원 쐐기 활동 없음), 플러그(아칭·지붕 휨 무시), Culmann(평면 파괴).
- 대표 물성은 문헌 범위의 중간값입니다. 실제 사면·공동은 부지 조사로 정해지며 값의 범위가 넓습니다.
- 공동은 원통 하나(크기·높이 입력), 용해·침식·지하수 흐름은 계산하지 않습니다(성장 속도가 입력).
- 지하수위는 걸린 지하수 버킷(침투량/(n·배수비율)/z)입니다 — 침투 흐름·배수·압력 확산 계산 없음.
- Newmark는 강체 블록·한 방향(하향)입니다. 파괴 임계 변위·Voellmy ξ·충격 계수 α는 **경험값**입니다.
- 토사 흐름은 단상 Voellmy(경로 침식·유체상 분리·입자 분급 없음), 높이장(오버행·터널 없음), 연직 기둥 근사. 정지/동마찰 이력이 없어 안식각 근처의 정착이 실제보다 느립니다(함몰 벽 60–100 s).
- 건물 토압은 합력 하나로 구조계 수평 저항과 비교합니다(파괴 메커니즘·벽 국부 파괴 없음).
- 결과는 입력에 대한 모델의 반응이지 실제 사건의 예측이 아닙니다. UI·가정 목록·배지가 이를 표시합니다.

## 23. 알려진 제한사항

- 실행 중간 상태 저장 미지원(§2.3).
- 암반 사면 파괴(낙석·전도·쐐기) 미구현 — 암반 셀은 파괴되지 않고 경고.
- 산사태 발생 영역 밖으로는 후퇴 파괴가 번지지 않습니다(흐름이 지나가는 경로 침식 없음).
- 싱크홀 벽 붕괴 검사는 모델 이웃 영역(최대 반경 + 2H + 2 m) 안에서만.
- 브라우저 장시간 검증 중 한 번 탭이 종료된 적이 있습니다(같은 시나리오 단독 실행은 정상, 재실행 22/22 통과) — 원인 미확정, 메모리 관찰 대상.

## 24. Phase 23 호환성 (충돌·크레이터·분출물)

- **충돌 크레이터**: 지정 변위장 대신 크레이터 형상(굴착 + 테두리 융기)을 GeoField에 `release`(굴착 → 이동층, 수지 기록)·`deposit`(분출물 퇴적)으로 넣으면 수지·충돌체·물·건물·도로·렌더가 그대로 동작합니다. 크레이터 벽은 싱크홀 벽과 같은 Culmann 검사로 자연스럽게 무너집니다.
- **분출물(ejecta)**: 탄도 비행 후 착지 위치에 질량·체적을 `deposit` 또는 이동층으로 넣는 입력 — 질량 보존 수지에 바로 들어갑니다. 고속 착지 충격은 §9의 동압 경로(α·ρu²)를 재사용할 수 있습니다.
- **충격 하중**: 지진 경로(지반가속도장)에 충격원을 추가하면 Newmark 산사태 유발이 그대로 동작합니다.
- 필요한 확장: 수평 변위·오버행이 없는 높이장 한계, 증발·용융 같은 상변화는 별도 모델.
