# Phase 27 — Fire, Combustion, Smoke & Fire Spread

화재·연소·연기·화재 확산을 **Phase 26 열물리 엔진 위에** 계산하는 단계입니다. 새 온도 엔진은 없습니다: 연료가 Phase 26 노드의 엔탈피로 데워지고,
발화하면 연료 질량이 줄어든 만큼만 화학에너지가 열로 바뀌어 **같은 노드·구획·공기층**에 들어가며, 그 열이 Phase 26의 전도·대류·복사로 퍼져
다른 연료를 데우고(확산), 부재 온도가 Phase 25 구조 엔진으로 이어집니다.

> §1은 구현 전에 쓴 분석, 나머지는 구현·측정·검증 결과입니다. 숫자는 모두 이 저장소의 테스트·벤치마크로 재현됩니다(§46).
> **축약 연소 모델입니다. 화학반응·실내 CFD를 풀지 않으며 실제 건축물의 화재 안전 설계·위험도 평가·인명 안전 판단에 쓸 수 없습니다.**
> 사용자가 조작하는 것은 교육·시각화용 초기 발화 위치·시각, 환경 조건, 재료·시나리오뿐입니다. 연료 배합·점화 장치·확대 최적화 기능은 없습니다.

### 1.2 열원(26)과 연소열(27)의 차이

- **열원**: 사용자가 정한 출력(W)/에너지(J)/온도 — 연료가 없음, `ThermalLedger.added`.
- **연소열**: 연료 질량 감소 Δm × 유효 연소열 ΔH_c,eff. 산소·연료가 허락하는 만큼만 생기며, 장부 `ThermalLedger.combustion` = 화학 장부의 방출량과 정확히 같음.
- 같은 에너지가 두 장부 계정에 들어가지 않습니다(열원 입력 ≠ 연소열).

### 1.3 연료 질량·화학에너지 장부

`초기 화학에너지(등록된 연료) = 남은 화학에너지 + 방출` (방출 = Σ ΔH_c,eff·Δm), 방출 = 열 노드로 간 열 + (흡수되지 않은 복사 등 Phase 26 손실 계정).
연료 질량: `등록 = 남음 + 소비`; 소비 = 기체(추적하지 않음) + 연기 그을음(추적). 연료가 불에 탄 노드는 질량이 줄고 그 질량의 현열은 생성 기체와 함께 기체 노드로 이동(열 보존).

### 1.4 갱신 순서 (계획)

```
ThermalSystem (0.1 s)
  0  FireWorld.preStep : 개구부(구조 상태) → 구획 환기; 연료 항목 생성(LOD 세분된 건물·나무·더미)
  1  연소: 상태 전이(발화 판정: 표면 온도 + 입사 열유속 + 지속 + 연료 + 산소), 연소율 = min(연료 제어, 산소 제어), 연료·O₂ 감소, HRR
  2  열원 입력: Phase 26 열원 + 연소열(SourceStep, 기하는 점원 모델 재사용)
  3  열전달 (Phase 26 그대로 + 화재 시에만: 구획 기체 복사, 개구부 질량 유동, 물 접촉 냉각)
  4  연기·산소 운반(구획 → 외기, 공기층 이류·배기)
  5  재료 계수(26) + 목재 탄화 단면 + 유리 열파손
StructuralCollapseSystem → 재분배·붕괴 → (다음 열 스텝에서) 개구부 변화·잔해 연료 이동
```

### 1.5 건물 구획과 구조 부재의 관계

구획 = 모듈형 건물의 층(Phase 26 구획 노드 재사용). 경계: 그 층의 외벽·창·문(외기), 위·아래 슬래브(다른 구획), 지붕(최상층 외기).
개구부 면적은 **현재 구조 상태**에서 계산: 파괴·탈락한 창/문/외벽·지붕 면적 + (초기 설정의 열린 창). 슬래브가 파괴되면 위아래 구획이 그 면적으로 연결.
수용물(가구 등) 연료는 구획에 하나(EN 1991-1-2 Annex E 화재하중 밀도 × 바닥 면적). 실내 칸막이·계단은 모델에 없으므로 층 하나가 한 구획입니다.

### 1.6 LOD 정책

Phase 26 건물 LOD(건물 노드 → 부재 노드)를 유지합니다. 연료 항목·화재 구획은 **세분된 건물에만** 있습니다. 세분 조건(26 + 27): 2 K 이상 가열, 열원·화재의 강한 가열 영역(≥ 1 kW/m²),
붕괴 모델, **초기 발화 대상**. 세분 전에는 연료가 화학적으로 손대지 않은 상태라 옮길 연료·화학에너지가 없고(등록 시점에 장부에 기록), 열에너지는 Phase 26 규칙대로 정확히 분배됩니다.
LOD를 낮추지는 않습니다(연료·산소·에너지 보존 문제 회피).

### 1.7 원본 월드 복원

연료·화재·연기·산소는 모두 런타임(`env.fire`)에만 있고 설계·문서를 쓰지 않습니다. 초기화 시 버리고 다시 만듭니다 → 같은 조건이면 같은 발화·확산·붕괴(테스트·브라우저).

## 2. Phase 26 잔여 작업

### 2.1 LOD와 국소 점화 (설계 §1.6 구현)

Phase 26 건물 LOD(건물 노드 → 부재 노드)는 그대로 쓰고, 화재가 다음 조건에서 세분을 앞당깁니다.

| 세분 조건 | 위치 |
|---|---|
| 2 K 이상 가열·열원의 강한 가열 영역(≥ 1 kW/m²)·붕괴 모델 (Phase 26) | `ThermalRuntime.prepare/buildGeometry` |
| **점화 대상**: 점화 구 반경 + 1 m 안 객체 (활성화 + 세분) | `FireRuntime.applyIgnition` |
| **화염의 강한 가열 영역**(점원 χQ/(4πr²) ≥ 1 kW/m²) / 도달 범위(≥ 0.1 kW/m²)의 활성화 | `FireRuntime.pointGeom` |

판단 근거는 시간 대신 **열유속·연료 상태·착화 가능성·구획 온도·부재 노출·인접 화재·화염 범위**입니다: 연료 항목은 세분된 건물에서만 등록되고(등록 시 연료·화학에너지가 장부에 들어감), 착화 판정(§5)은 입사 열유속 이력·연료·산소·함수율로 합니다. 세분 시 열에너지는 Phase 26 규칙(열용량 비례 분배, 정확)대로, 연료·화학에너지는 아직 손대지 않은 상태로 등록되므로 **LOD 전환에서 열에너지·연료 질량이 보존**됩니다(테스트: 원장 잔차 1e-9 이하). 거친 노드로 되돌리지 않습니다.

### 2.3 2노드 전도 오차가 구획·부재 온도에 주는 영향 (측정)

|---|---|---|---|---|
| 콘크리트 200 mm | 10 min | 49 / 39 | 134 / 57 | 0.990 / 1.000 |
| | 30 min | 114 / 93 | 342 / 143 | 0.944 / 0.989 |
| | 60 min | 183 / 183 | 498 / 272 | 0.891 / 0.939 |
| 목재 100 mm | 30 min | 160 / 90 | 298 / 99 | 0.639 / 0.346 |

- 콘크리트: 2노드 표피는 양쪽 면 5 cm 층을 한 온도로 보므로 노출면 온도를 크게 낮게 보고(30 min 143 vs 342 °C), 단면 평균은 초기 −23 %에서 60 min 0 %로 수렴. 강도 계수는 **최대 5 %p 덜 감소**(비보수적) — Phase 26의 12 %/4 % 반무한 오차가 실화재 노출에서는 표면 층 해상도 부족으로 나타납니다. 한계로 기록(§39), 구획 가스 온도는 벽 표면 온도를 통해 간접 영향만 받습니다(벽이 열을 덜 흡수 → 가스가 약간 뜨거움, 보수적).
- 목재: 2노드는 수분 증발 구간(99–120 °C)에서 오래 머물러 평균 온도는 낮지만, Annex B 계수가 표피 전체에 적용되어 강도는 **더 많이 감소**(보수적). 착화 후에는 §15의 탄화 단면이 대신합니다.

## 3. 연소 상태 (`src/fire/FireWorld.ts`)

연료 항목(SoA) 하나의 상태: 재료, 처음·남은 연료 질량, 수분, 연소 면적(전체 관여 시), 관여율, 연소 중인 질량(얇은 연료), 열유속-시간 적분(파일럿/자연), 입사 열유속, 파일럿 여부, 잠김 비율, 비, 질량감소율, HRR, 누적 방출 에너지, 착화 시각, 탄화 깊이, 연소 위치(방/실외), 원천(점화 원인: 시나리오·받은 열·잔해). 연료 온도는 **Phase 26 열 노드의 온도**(실내 가연물은 방 가스)이며 따로 두지 않습니다.

상태: `unheated → heating → pyrolysis → ignited → burning ⇄ decaying → extinguished / burnedOut`. 허용 전이표(`ALLOWED`)에 없는 전이는 예외를 던지고(테스트), `burnedOut`은 최종입니다. 연료 질량은 감소만 합니다(재생 없음; 잔해 더미로의 이동은 같은 질량을 옮기는 것이며 장부에 기록).

## 5. 착화 (온도만으로 판단하지 않음)

| 연료 | 조건 (모두 만족) |
|---|---|
| 두꺼운 고체 | FTP = ∫(q″_inc − q″_cr)² dt ≥ (π/4)kρc(T_ig − T₀)² (파일럿: 12 kW/m²·350 °C, 자연: 25 kW/m²·500 °C), 또는 노드 ≥ 500 °C; q < q_cr 동안 FTP 감소; 물에 반 이상 잠기지 않음; 산소 질량분율 ≥ 0.14 |
| 잎 (얇은 연료) | 노출 요소: ∫(q − q_cr) dt ≥ ρ_p/σ·Q_ig(M) (함수율 M에 따라 증가), 또는 노드가 함수율 30 % 이하로 마르고 300 °C(파일럿)/450 °C; 산소 |
| 실내 가연물 | 방에 화염(파일럿) + 바닥 입사 ≥ 12 kW/m², 또는 ≥ 20 kW/m², 또는 가스 ≥ 500 °C; 산소 |

- **입사 열유속** = 이 단계에 열원·화염이 실제로 놓은 에너지 ÷ (방사율 × 수열 면적) + 방 가스(ε_gσ(T_g⁴−T∞⁴) + 10(T_g − T_s)). 에너지는 수열체 중심 거리로 분배(보존)하고, 착화 판정용 열유속은 **가까운 면**(중심 거리 − 화염 쪽 반폭, 나무는 수관 중심)에서 평가합니다.
- **파일럿**: 연소 중인 방, 또는 화염 영역(0.5L + 0.5D + 0.5 m) 안. Phase 26 열원은 파일럿이 아닙니다(자연 착화 조건).
- 프레임레이트와 무관(고정 0.1 s 열 단계), 객체 ID와 무관(등록 순서 = 열 바디 순서), 난수 없음.
- 시나리오 점화: 점화 구 안 연료를 파일럿 화염으로 점화(실내 가연물은 t² 성장 시작, 고체는 0.1 m², 수관은 5 %). 연료 없음·너무 젖음·잠김이면 **이유와 함께 거부**(로그·타임라인·HUD).
- 측정: 목재 25 kW/m² → 130 s, 50 kW/m² → 15 s (콘 열량계 자료 범위, 테스트).

## 6. 연료 소비

질량감소 Δm이 곧 HRR(= ΔH_c·ṁ)의 근거이며, ṁ ≤ m/Δt로 남은 연료를 넘지 못합니다(무한 열원 없음). 두꺼운 고체: ṁ″ = clamp((q_fl + 0.9q_ext − εσ(T_b⁴ − T∞⁴) − L_v·ṁ_w″)/L_g, 0, cap(탄화 깊이)) × 관여 면적; 소비된 고체(Δm/(1−χ_c))가 탄화 깊이를 만들고, 탄 질량은 노드에서 빠지며 그 현열은 기체 노드로, 기화열 L_g·Δm은 휘발분과 함께 기체로 이동(열 보존). 얇은 연료: 연소 질량 풀/τ, 젖은 부분의 수분은 함께 증발(잠열은 화염 열에서, 장부 '증발'). 70 %(EN) 소비 후 감쇠, 0.1 % 이하 남으면 전소.

## 7. 화학에너지 장부 (`src/fire/ledger.ts`)

`등록 = 남음 + 방출 + 월드 밖`, 방출 = 실내 + 실외 + 외부 화염. 방출은 `ThermalLedger.combustion`과 같은 값으로 열 노드에 들어갑니다(열원 입력 `added`와 분리 — 이중 계산 없음). 받는 쪽이 없는 복사는 열 장부의 미해결 복사(정보: `combustionUnresolved`). 산소 소비 = 방출/13.1 MJ/kg, 연기 = 생성 = 방 + 공기층 + 배출 + 월드 밖, 수분 = 증발 질량 × 2.257 MJ/kg = 열 장부 `lost.evaporation`. 모든 시뮬레이션 테스트·벤치마크가 잔차를 확인합니다(화학 1e-14 상대, 연료 1e-11 kg, 연기 1e-10 kg 수준).

## 8. 열방출률

성장(t², 관여율 확산, 수관 확산), 연료 지배(RHR_f·A, 표면 에너지 수지), **환기 지배**(방 O₂가 허락하는 만큼만 실내 연소), 감쇠(EN 선형 / 연료 고갈), 소염(임계 질량감소율·함수율·물·산소). 시나리오가 HRR을 정할 수 없습니다(입력에 출력이 없음) — 연료·장부를 우회하는 경로가 없습니다.

## 9. 산소

방: 기체 질량 ρV(Phase 26처럼 부시네스크), O₂ 질량. 매 단계 외기와 정확한 지수 혼합(유입 = 개구부 Rockett 유량 + 누기) 후, **한계 질량분율 0.14 위의 O₂만** 연소에 쓸 수 있음 → 밀폐된 방은 누기로 들어오는 산소만큼 약하게 탑니다(테스트). 실외: 공기층 칸마다 O₂ 결손 추적자(바람 이류·부력 배출로 회복). 실내와 실외를 하나의 무한 공급원으로 보지 않습니다. 화학종·CFD·폭발성 혼합기는 계산하지 않습니다.

## 10. 건물 구획

방 = 모듈형 건물의 층(Phase 26 구획 노드): 부피, 가스 온도(노드), O₂, 연기, 바닥 면적(가연물), 둘러싼 면(부재), 개구부(창·문·외벽·지붕 부재, 측면별 면적·높이), 위아래 층 연결(파괴된 슬래브). 식별 가능한 층만 방으로 만들고 칸막이·계단은 없습니다(한계).

## 11. 구획 독립성과 개구부

개구부 면적은 **매 단계 구조 상태에서** 계산: 파괴/이탈한 창·문·외벽·지붕 + 설정의 "창 열림". 유리는 판 노드가 주변보다 70 K 뜨거우면 깨져 `detachFacade('fire')` → 개구부가 됩니다. 연결 없이 다른 방으로 열이 순간 이동하지 않습니다: 방 사이 교환은 무너진 슬래브 면적의 부력 혼합(ṁ = 0.5ρA√(gHΔT/T))으로만, 바깥과는 개구부 유량(열·O₂·연기 함께)으로만.

## 12. 화재 확산 (무작위 확률 없음)

다른 연료로의 확산은 Phase 26 전도·대류·복사 + 화염 열이 §5 조건을 만족할 때만: 화염 복사(점원 기하·투영 면적·건물 차폐·면 방향), 방 가스 복사·대류, 개구부를 통한 복사·외부 화염, 화염 영역 안 파일럿, 불붙은 잔해의 이동(§17). 측정: 마른 침엽수 5 m 간격 → 전체 연소(≈ 30 m/min), 7 m 간격 → 정지(무풍), 같은 7 m에 10 m/s 바람 → 풍하 확산(테스트·브라우저 검증).

## 13. 바람

바람은 ① 화염 기울기(Thomas: cos θ = u*^−1/2) → 풍하 수열체가 가까워짐, ② 공기층 열·연기·O₂ 결손의 이류(Phase 26 공기층과 같은 속도), ③ 표면 대류 냉각(Phase 26 hBox), ④ 실외 산소 회복. "바람이 셀수록 무조건 화재가 강해짐"으로 구현하지 않았습니다(연소율 식에 바람 항 없음). ForceLedger에 힘을 더하지 않습니다(이중 계산 없음, 중복 힘 0 확인).

## 14. 식생

나무 = 수관(잎 연료 + 수분) + 줄기(생목, 탄화). 수관 미세연료 = min(0.5 kg/m³ × 수관 부피, 수관 질량/(1+M)). 수관이 탄 비율만큼 렌더링 수관이 줄고 숯 색으로(`visual.burned`), 바람 하중 면적(areaFactor)이 줄며, 30 %에서 DAMAGED, 90 %에서 DESTROYED(원인 fire). 함수율 설정(기본 150 % 생엽 — 시나리오 점화 거부, 가뭄 20–25 %)이 착화·확산을 좌우합니다. 숲 = 개별 나무(지표 연료 없음).

## 15. 구조 화재

강재·콘크리트: Phase 26 온도 → EN 계수가 그대로 적용(방 가스 복사·화염 열로 데워짐). 목재: 탄화 깊이 ≥ 1 mm부터 EN 1995-1-2 **유효 단면법**(d_ef = d_char + k₀d₀, 기둥 4면·보 3면·벽/슬래브/지붕 1면, k₀는 전환 시점부터 20분)이 온도 계수를 **대체**(곱하지 않음 — 이중 감소 없음), 전환 시점의 값을 상한으로 하여 연속·비회복(테스트: 회복 0). 모든 변화는 `setMaterialFactor`/`addLoad`로만, 해저드 이름은 화재가 관여한 건물에서 `fire`. 부재를 직접 지우지 않습니다(완전 탄화한 비구조 외장은 `detachFacade`로 개구부가 됨). 측정(창 열림 목조 주택): 플래시오버 ≈ 13분, 첫 화재 부재 파괴 31분, 전체 붕괴 ≈ 50분.

## 16. 붕괴–화재 상호작용

벽·창·지붕이 무너지면 그 면적이 다음 단계 개구부가 되어 환기가 바뀌고, 층이 무너지면(Phase 26 `openCompartment`) 방의 열·O₂·연기가 바깥 공기층으로 가고 남은 가연물은 실외에서 탑니다. 파괴된 목재 부재는 실외 연소(잔해 화염)로 바뀝니다. 구조 그래프·방 그래프·열 노드가 같은 구조 상태에서 유도되므로 서로 모순되지 않습니다.

## 17. 불붙은 잔해

부재가 떨어지면 열 노드와 연료 항목이 함께 이동(Phase 26 파편 추적). 잔해 더미에 합쳐지면 열 에너지는 Phase 26 `mergeBody`, **연료는 더미의 연료 항목으로 이동**(같은 질량, 장부 `fuelMoved`), 타던 잔해였다면 더미가 착화(2차 점화 마일스톤). 지면에 바로 합쳐진 잔해는 열을 지면에 주고 꺼지며 남은 연료는 '남음'으로 남고, 월드를 벗어난 파편의 연료는 '월드 밖'. 총질량·연료·열·화학에너지가 보존됩니다(테스트·측정: 목조 주택 + 나무, 2000 s에 첫 더미 착화, 3200 s까지 12.9 t 이동, 이후 더미가 계속 탐).

## 18. 물과 화재

물에 잠긴 비율만큼 연소 면적이 줄고 90 % 이상이면 소염, 잠긴 면은 물과 대류(h = 500 W/(m²K), 안정 한계 내)로 열을 주고받아 Phase 26 물 열 추적자에 들어갑니다(질량·에너지 보존). 비는 실외 수관의 수분을 늘리고(소염 함수율 초과 시 소화), 두꺼운 고체의 연소율에서 L_v·ṁ_w″를 뺍니다. 증발은 연료 수분에 대해서만 계산하며(잠열 → 장부 증발 손실), 물웅덩이의 끓음·증발은 여전히 계산하지 않습니다(Phase 26 100 °C 경고 유지).

## 19. 해저드 연동

임의 발화 없음: 착화는 계산된 열유속으로만. Phase 26 열원·운석 열 몫은 **"열원·충돌 열이 연료에 불을 붙일 수 있음"**(기본 꺼짐)을 켜면 같은 착화 규칙으로 연료를 데워 불을 붙일 수 있습니다. 운석 열 몫은 지면 칸에 들어가는데 지면은 물체에 복사하지 않으므로(Phase 26 한계) 실제로 착화에 이르지 않습니다. 압력파는 열을 만들지 않습니다. 운석·압력파 에너지 장부는 그대로입니다(동일성 측정 §35).

## 20–21. 연기와 가시거리

연기 = 그을음 질량(수율 × 연소 질량): 방 노드, 공기층 칸 추적자. 방 → 개구부 유량(유입과 같은 질량 교환 비율), 방 ↔ 방(무너진 슬래브), 공기층: 바람 이류(풍상 차분, CFL), 부력 배출(√(gHΔT/T)), 월드 밖. 벽을 통과하지 않습니다. 가시거리 S = 3/K, K = 8700 m²/kg × 농도(Mulholland & Croarkin, Jin). 방 가스 방사율 ε_g = 1 − exp(−κ·3.6V/A), κ = 1862·f_v·T(Tien) — 연기가 있을 때만 방 ↔ 면 복사가 켜집니다(화재 없음 = Phase 26 그대로).

## 22. 시각화 (`src/rendering/fire`, 렌더 전용)

화염 = 계산된 화염마다 원뿔(Heskestad 높이, 화재 직경, Thomas 기울기, 연소 폭보다 넓게 그리지 않음; 깜빡임은 시각 효과). 연기 = 화염 위 플룸(밀도 = 계산된 그을음 생성률) + 공기층 연무(가시거리 < 15 m) + 방 개구부 연기(3단 투명도, 부드러운 스프라이트). 불티·바닥 빛은 시각 효과(불티 착화 없음, 명시). 부재: 연소 중 붉은 숯빛(관여율), 탄화 단면 비율만큼 숯색, 전소 숯색; 수관은 탄 만큼 축소·숯색. 인스턴스 수 상한(화염 400, 연기 1600×3, 불티 600, 표시 3000), 모든 GPU 자원 소유·해제, 내장 재질만 사용(셰이더 새로 컴파일 없음).

## 23. GUI (실험 탭, KO/EN)

## 29. 원인 귀속

해저드 `fire`(마지막에 추가 — 기존 색인 유지), 원인 `fire`(DamageCause). 화재가 관여한 건물(연료 착화·연소 방)의 온도 계수·열하중·열좌굴은 `fire`, 아닌 건물은 `thermal`; 구조 엔진이 파괴 원인(axial·bending·connection·support…)과 연쇄(trigger/root)를 기록하므로 직접 연소(나무·외장 소실), 열 약화, 붕괴, 낙하 잔해, 2차 충돌이 구분됩니다. 화재 결과를 'wind'로 귀속하지 않습니다.

## 34. 성능 구조

- 화재가 없으면 아무것도 만들지 않음(열 채널이 비활성이면 시스템도 쉼).
- 연료는 세분된 건물·활성 나무에만; 화염은 객체/층 측면별 그룹 하나; 수열체 기하는 8 m 버킷, 1초 또는 HRR 2배 변화·1 m 이동 때만 재계산; 수열체는 0.1 kW/m², 지면은 1 kW/m² 이상만(나머지는 장부의 미해결 복사).
- 입사 열유속 계산은 각 화염의 몸체 수열체(배열 앞부분)만 훑음.
- 방 개구부는 설계에서 한 번 목록화하고 상태만 매 단계 읽음.

## 39. 과학적 한계

- 축약 연소 모델: 화학 반응·화학종(CO·HCN)·독성·폭발성 혼합기·역화·훈소·숯 산화 없음; **실제 건축물의 화재 안전 설계·위험도·인명 안전 판단에 사용 불가.**
- 방 = 층 하나의 잘 섞인 1구역(연기층/공기층 분리, 칸막이·계단·문 없음), 수평 개구부(지붕·슬래브)는 수직 개구부 식과 근사 혼합.
- 실내 가연물은 노드 없는 설계화재(온도 = 방 가스), 차량·기존 단일 상자 건물·지표 연료는 연료가 아님.
- 2노드 부재는 노출면 온도를 낮게 봄(§2.3: 콘크리트 강도 최대 5 %p 덜 감소), 목재는 탄화 단면으로 보완.
- 화염 복사 = 점원(근거리 착화는 가까운 면 거리로 보정), 건물 사이 형상계수 없음, 지면은 1 kW/m² 이상만 가열.
- 불티(비화) 착화 없음(시각 효과뿐), 바람에 의한 연소율 증가 없음(기울기·이류만).
- 물: 연료 수분 증발만, 웅덩이 끓음·증기 없음, 잠긴 면 대류만.
- 프리셋의 수관 밀도·확산 속도 등은 문헌 범위 안의 가정값(표시됨).
