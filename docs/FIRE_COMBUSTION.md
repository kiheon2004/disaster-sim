# Phase 27 — Fire, Combustion, Smoke & Fire Spread

화재·연소·연기·화재 확산을 **Phase 26 열물리 엔진 위에** 계산하는 단계입니다. 새 온도 엔진은 없습니다: 연료가 Phase 26 노드의 엔탈피로 데워지고,
발화하면 연료 질량이 줄어든 만큼만 화학에너지가 열로 바뀌어 **같은 노드·구획·공기층**에 들어가며, 그 열이 Phase 26의 전도·대류·복사로 퍼져
다른 연료를 데우고(확산), 부재 온도가 Phase 25 구조 엔진으로 이어집니다.

> 구현 전에 작성한 분석(§1)과 설계(§2)로 시작해 구현·측정·검증 결과로 채웁니다.
> **축약 연소 모델입니다. 화학반응·실내 CFD를 풀지 않으며 실제 건축물의 화재 안전 설계·위험도 평가·인명 안전 판단에 쓸 수 없습니다.**
> 사용자가 조작하는 것은 교육·시각화용 초기 발화 위치·시각, 환경 조건, 재료·시나리오뿐입니다. 연료 배합·점화 장치·확대 최적화 기능은 없습니다.

### 1.2 열원(26)과 연소열(27)의 차이

- **열원**: 사용자가 정한 출력(W)/에너지(J)/온도 — 연료가 없음, `ThermalLedger.added`.
- **연소열**: 연료 질량 감소 Δm × 유효 연소열 ΔH_c,eff. 산소·연료가 허락하는 만큼만 생기며, 장부 `ThermalLedger.combustion` = 화학 장부의 방출량과 정확히 같음.
- 같은 에너지가 두 장부 계정에 들어가지 않습니다(열원 입력 ≠ 연소열).

### 1.3 연료 질량·화학에너지 장부

`초기 화학에너지(등록된 연료) = 남은 화학에너지 + 방출` (방출 = Σ ΔH_c,eff·Δm), 방출 = 열 노드로 간 열 + (흡수되지 않은 복사 등 Phase 26 손실 계정).
연료 질량: `등록 = 남음 + 소비`; 소비 = 기체(추적하지 않음) + 연기 그을음(추적). 연료가 불에 탄 노드는 질량이 줄고 그 질량의 현열은 생성 기체와 함께 기체 노드로 이동(열 보존).

### 1.4 갱신 순서 (계획)

```
ThermalSystem (0.1 s)
  0  FireWorld.preStep : 개구부(구조 상태) → 구획 환기; 연료 항목 생성(LOD 세분된 건물·나무·더미)
  1  연소: 상태 전이(발화 판정: 표면 온도 + 입사 열유속 + 지속 + 연료 + 산소), 연소율 = min(연료 제어, 산소 제어), 연료·O₂ 감소, HRR
  2  열원 입력: Phase 26 열원 + 연소열(SourceStep, 기하는 점원 모델 재사용)
  3  열전달 (Phase 26 그대로 + 화재 시에만: 구획 기체 복사, 개구부 질량 유동, 물 접촉 냉각)
  4  연기·산소 운반(구획 → 외기, 공기층 이류·배기)
  5  재료 계수(26) + 목재 탄화 단면 + 유리 열파손
StructuralCollapseSystem → 재분배·붕괴 → (다음 열 스텝에서) 개구부 변화·잔해 연료 이동
```

### 1.5 건물 구획과 구조 부재의 관계

구획 = 모듈형 건물의 층(Phase 26 구획 노드 재사용). 경계: 그 층의 외벽·창·문(외기), 위·아래 슬래브(다른 구획), 지붕(최상층 외기).
개구부 면적은 **현재 구조 상태**에서 계산: 파괴·탈락한 창/문/외벽·지붕 면적 + (초기 설정의 열린 창). 슬래브가 파괴되면 위아래 구획이 그 면적으로 연결.
수용물(가구 등) 연료는 구획에 하나(EN 1991-1-2 Annex E 화재하중 밀도 × 바닥 면적). 실내 칸막이·계단은 모델에 없으므로 층 하나가 한 구획입니다.

### 1.6 LOD 정책

Phase 26 건물 LOD(건물 노드 → 부재 노드)를 유지합니다. 연료 항목·화재 구획은 **세분된 건물에만** 있습니다. 세분 조건(26 + 27): 2 K 이상 가열, 열원·화재의 강한 가열 영역(≥ 1 kW/m²),
붕괴 모델, **초기 발화 대상**. 세분 전에는 연료가 화학적으로 손대지 않은 상태라 옮길 연료·화학에너지가 없고(등록 시점에 장부에 기록), 열에너지는 Phase 26 규칙대로 정확히 분배됩니다.
LOD를 낮추지는 않습니다(연료·산소·에너지 보존 문제 회피).

### 1.7 원본 월드 복원

연료·화재·연기·산소는 모두 런타임(`env.fire`)에만 있고 설계·문서를 쓰지 않습니다. 초기화 시 버리고 다시 만듭니다 → 같은 조건이면 같은 발화·확산·붕괴(테스트·브라우저).
