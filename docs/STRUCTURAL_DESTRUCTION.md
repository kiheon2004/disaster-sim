# Phase 25 — Advanced Structural Destruction, Progressive Collapse & Debris Physics

사용자가 만든 모듈형 건물(Phase 17)이 재난으로 손상될 때 **부재 단위의 파괴, 하중 재분배, 연쇄·부분 붕괴, 낙하 잔해, 2차 피해**가
계산되도록 하는 구조 파괴 엔진입니다. **구조공학 설계·안전 진단·붕괴 예측용 인증 도구가 아닙니다**(§37).
계산값과 시각적 근사를 구분해 표시합니다.

> 이 문서는 구현 전에 작성한 분석(§1–§2)과 설계로 시작해, 구현·검증 결과로 채워집니다.

## 1. 기존 시스템 분석 (구현 전)

### 1.2 Phase 24 외벽 파괴가 구조 연결을 바꾸는가?
예 — 외벽(내력벽)이 면외로 파괴되면 `failMembers`로 같은 하중 경로 재해석을 거칩니다(지지를 잃은 위 부재 낙하, 수직 부재 과하중 파괴).
그러나 (1) 보·슬래브·접합부 과하중은 검사하지 않고, (2) 층 붕괴는 40 % 경험 규칙에 의해 즉시 일어나며, (3) 낙하가 아래층에 주는 충격은 없습니다.

### 1.3 이번 Phase에서 새로 필요한 것
1. 명시적 **구조 그래프**(부재·접합부·지지 관계·대체 지지 경로)를 설계당 한 번 만들고 공유.
2. **증분 하중 경로 해석**(변화한 영역만): 지지 상태는 아래→위, 하중은 위→아래로 변화량만 전파.
3. 모든 하중 부재(보·슬래브 포함)와 **접합부**의 수요/용량 검사, 갑작스러운 손실의 **동적 증폭**.
4. 파괴와 낙하의 분리: **낙하 블록의 시간 전개**, 아래층 충돌의 **운동량·에너지 수지**로 정지/연쇄 판정.
5. 질량이 보존되는 **잔해**(Rapier 조각 / 집계 잔해 더미 / 구조 내부에 쌓인 잔해) 장부.
6. 잔해 → 건물 부재·차량·사람·도로의 **2차 피해**와 원인 사슬 기록.
7. 지반 변형 → **기초 부재 지지 상실**.
8. 인스펙터·오버레이·타임라인·결과·편집 미리보기.

## 2. Phase 24 성능 점검 (구현 전 비용 분석)

| 항목 | 현재 비용 / 위험 |
|---|---|
| 구조 재해석 | `failMembers` 한 번에 전체 해석 최대 7회 → 아파트 ~24 ms, 타워 ~200 ms (스텝 하나에) |
| 손상 상태 갱신 | 지진 부재 평가는 층 피크가 늘어난 층만 (저렴) |
| 렌더링 | 부재 행렬 재작성은 건물 rev 변화 시 (건물 단위) |
| 충돌체 수명 | 층 붕괴마다 건물 충돌체 재생성(1회) |
| 잔해 | 최대 320 동체, 덩어리당 질량 자름, 잠든 조각 조용히 제거 |
| 메모리 | 부재 상태 typed array, 설계 공유 |
| GPU | 파편 InstancedMesh 1개(320) |

Phase 24 기준(1000동 압력파 최악 스텝 75 ms)의 주 비용은 압력파 응답이고, 붕괴 경로의 전체 재해석은 큰 건물에서 스파이크를 만듭니다.
→ 설계: 그래프 캐시 + 증분 해석 + 이벤트 구동 + 건물당 스텝당 재분배 1라운드 + 동체 상한·집계. 기능이 쓰이지 않으면(파괴 없음) 비용 0.
측정 결과는 §33.

## 3. 설계 개요

```
src/structure/            (순수 계산, Rapier·React 없음)
  graph.ts       구조 그래프 (CSR typed arrays, 설계+스케일당 1회, 공유)
  capacity.ts    부재·접합부 용량, 동적 증폭 Ω, 변형 용량
  solver.ts      증분 지지/하중 해석, 수요/용량, 재분배 라운드
  falling.ts     낙하 블록 충돌: 완전 비탄성 충돌 + 강소성 흡수 에너지
  ledger.ts      질량·운동량 장부
  preview.ts     편집 모드 "부재 제거 미리보기"(대체 경로 해석)
src/simulation/structure/ (런타임 통합)
  StructureRuntime / CollapseSystem / debris / rubble / secondary / foundation / roads
```

상태 전이:

```
INTACT ─(손상 ≥ 0.3)→ DAMAGED ─(≥ 0.7)→ SEVERE
  │                       │                │
  └──────(용량 초과 / 지지 상실 / 접합부 파괴 / 충돌)──────→ FAILED (하중 안 받음)
FAILED → DETACHED (접합 해제, 같은 스텝) → FALLING (구조 내부 낙하 블록 또는 Rapier 조각)
FALLING → RESTING (아래층 위에 정지: 그 층의 정적 하중이 됨) | SETTLED (지면 잔해 더미 / 정지한 조각)
```
