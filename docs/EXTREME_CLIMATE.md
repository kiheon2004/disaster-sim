# Phase 30 — Extreme Climate, Humidity, Snow, Ice & Water Phase Change

폭염·한파를 설정하면 공기·지면·물·구조물의 온도가 바뀌고, 그 결과로 **수증기 이동, 증발·응결, 강설·적설·압밀, 결빙·해빙,
지반 동결, 융설수, 구조 하중**이 기존 물리 시스템(Phase 14 홍수, Phase 26 열, Phase 27 화재, Phase 29 대기)을 통해 일어나게 하는 단계입니다.

> §1은 구현 전에 쓴 분석과 설계, §2부터는 구현·측정·검증 결과입니다.
> **국소 축약 기후 모델입니다. 일기예보·기후 예측 모델이 아니며 건축·도로·기상 안전 판단에 쓸 수 없습니다.**

### 1.3 에너지 소유권

| 에너지 | 소유 | 비고 |
|---|---|---|
| 공기·지면·물·물체·구획의 현열 | **Phase 26 열 세계** (기준 대비 E) | 기후 강제는 공기층 칸에 열을 넣고 뺄 뿐(계정 `climate`) |
| 덮개(눈+얼음) 엔탈피 | `ClimateWorld` 덮개 노드(셀당 1노드, 0 °C 액체 기준 U) | 동결분의 −L_f 포함 → 상변화 중 온도 고정(엔탈피법) |
| 수증기 잠열 | `ClimateWorld` (L_v·m_v) | 증기의 현열은 공기 노드의 열용량에 포함(건조 공기 근사, ≤ 2 %) |
| 토양 얼음 잠열 | `ClimateWorld` (−L_f·m) | 결빙 = 지면 층 E에 +L_f·dm, 융해 = −L_f·dm (투영 엔탈피법) |

**공통 기준**: 물 물질은 "기준 온도 T_ref의 액체 = 0 J/kg". 덮개의 전역 에너지 = U + M·c_w·(T_m − T_ref). 저장소 사이 질량 이동은 (질량, 그 저장소의
비엔탈피 × 질량) 쌍으로만 하고, 잠열 이동은 열 장부 `latent` 계정으로 기록합니다. 기후 장부 + 열 장부를 합한 전체 에너지가 외부 입력
(태양, 하늘 장파 손실, 공기층 강제, 강수 엔탈피, 증기 경계 잠열)만으로 닫혀야 합니다(테스트).

### 1.4 갱신 순서 (계획)

```
prePhysics   GroundContactSystem   유효 마찰(지면 재질 × 젖음 × 눈·얼음)          ← 기후 덮개 상태(한 스텝 전)
             WaterSolverSystem     기후 강우(대기 중 깊이), 얼음 하중·마찰·결빙 차단, 동결토 침투 감소
postPhysics  … DamageSystem
             ThermalSystem (0.1 s)
               0 ThermalRuntime.prepare
               1 AtmosphereRuntime.prepare
               2 ClimateRuntime.prepare     강제 경로(기온·습도·태양·강수·구름) → 공기층 경계 교환/처방 기온(계정 climate)
                                            → 하늘 유효 온도·셀별 태양 흡수·덮개 마스크·잠열 수송 계수를 열 지면 스텝에 넘김
               3 VolcanoRuntime.prepare / FireRuntime.prepare
               4 ThermalWorld.step          지면 스텝(1 s)에서 노출 셀의 태양·하늘 장파·대류·증발 잠열(선형화 표면 균형)
               5 FireRuntime.after
               6 AtmosphereRuntime.after
               7 ClimateRuntime.after       (지면 스텝이 돈 경우) 강수 분할 → 덮개 갱신(암시 1노드: 지면·물·공기·하늘·태양·승화)
                                            → 상변화 투영(물 결빙/해빙·끓음·토양 동결) → 압밀·알베도 → 배수(융설수 → 홍수)
                                            → 증발 질량 정산(물·토양·덮개 → 수증기) → 물체(지붕·수관·차량) → 날림 눈
                                            매 스텝: 수증기 수송(대기 면 속도 또는 평균 바람)·경계 혼합·포화 조정(응결)·Kessler 강수
                                            → 하중(5 s, 변화량 양자화) → 도로·마찰·노출 → 장부·통계·마일스톤
               8 VolcanoRuntime.after / ThermalRuntime.after
```

반복 순서는 셀·칸 인덱스(행 우선)·물체 삽입 순서뿐 — 객체 ID 무관.

### 1.5 모델 선택

| 항목 | 선택 | 근거 / 대안 |
|---|---|---|
| 포화 수증기압 | 물: Murphy & Koop (2005) 식(10), 얼음: 같은 논문 식(7) — 123–332 K. 범위 밖은 끝값 + 경고 | Magnus는 −40 °C 아래 오차 큼 |
| 습도 상태 | 보존량 = 증기 질량 m_v. q = m_v/m_air, e = q·p/(0.622 + 0.378q), RH = e/e_s(T), 이슬점 = e_s⁻¹(e) | RH는 입력이 아니라 파생(배경 공기의 RH만 입력) |
| 표면 증발 | Chilton–Colburn 유사: 질량 전달 계수 h_m = h_c/(c_p·Le^(2/3)), Le = 0.85 — **기존 대류 계수(자연 + 바람 함수)를 그대로** 사용. 토양: Sellers 등(1992) 토양 저항 r_s = exp(8.206 − 4.255·W) | Penman은 별도 공기역학 저항이 필요 — 같은 h_c를 써야 현열·잠열이 일관 |
| 응결 | 공기층 칸의 포화 조정(뉴턴 반복, 잠열로 기온 상승 포함), 표면 응결(이슬·서리) = 음의 증발 | 구름 미세물리 없음 |
| 강수 생성 | 외부 강수(입력) + 응결수의 Kessler (1969) 자동변환 k(q_c − 0.5 g/kg), k = 10⁻³ s⁻¹ | |
| 비/눈 분할 | 습구 온도 T_w: 0 °C 이하 전부 눈, 2 °C 이상 전부 비, 사이 선형(50 % ≈ 1 °C — Ding 등 2014, Sims & Liu 2015). 사용자가 상(눈/비)을 고정할 수 있음(어는 비 = 비 고정 + 영하 지표) | 한 강수를 한 번만 나눔 |
| 덮개(눈+얼음) | 셀당 1노드 엔탈피(U, 0 °C 액체 기준), 동결 비율 → 상변화 중 0 °C 고정, 액체 보유 5 %(초과 배수), 눈 위 얼음/물 위 얼음 구분은 질량 태그 | 다층 적설 모델(SNTHERM·Crocus) 아님 |
| 신설 밀도 | Anderson (1976) ρ = 50 + 1.7·(T − T_f + 15)^1.5 (T ≤ T_f + 2), CLM 4.5 | |
| 압밀 | CLM 4.5 (Oleson 등 2013, Anderson 1976): 파괴적 변태 + 과하중(점성 η₀ = 9·10⁵ kg·s/m²) + 융해 | 결정 변태 모델 아님 |
| 눈 열전도도 | Calonne 등 (2011) k = 2.5·10⁻⁶ρ² − 1.23·10⁻⁴ρ + 0.024 | |
| 알베도 | 지표 재질 표, 물 0.06, 얼음 0.35, 눈 Douville 등 (1995) 노화(건조 −0.008/일, 습윤 τ = 0.24/일, 0.50–0.85, 강설 갱신), 화산재 혼합 | |
| 태양 | 적위·시간각(Cooper 1969), 맑은 하늘 직달 I_b = 1361·0.7^(AM^0.678)(Meinel & Meinel 1976), 산란 ≈ 0.1·I_b·sin β, 구름 Kasten & Czeplak (1980) (1 − 0.75N^3.4). 그늘 = 지형·건물 높이장 광선 진행(태양이 1° 움직일 때마다) | 정밀 복사 전달 없음 |
| 하늘 장파 | Brutsaert (1975) ε_clear = 1.24(e/T)^(1/7)(e hPa), 구름 (1 + 0.22N²)(Bolz) → T_sky = ε^¼·T_a | |
| 호수 결빙 | 물 노드가 0 °C 아래로 가면 초과 냉각만큼 결빙(투영 엔탈피법), 얼음은 덮개로 — 위 공기·하늘, 아래 물(0 °C 접촉). 물 노드는 완전 혼합(4 °C 밀도 최대·성층 없음) | 성층 호수 모델 아님 |
| 얼음 아래 흐름 | 얼음 무게는 수면 압력(뜬 얼음 = 같은 질량의 물 수두), 얼음 밑면 마찰(Sabaneev 합성 조도, 얼음 n = 0.02), 액체 < 5 mm인 결빙 칸은 흐름 차단 | 얇은 물 솔버의 정확한 얼음 밑 흐름이 아님 |
| 토양 동결 | 열 모델 4층의 토양수(선행 θ₀ + 침투분)를 층 온도의 투영 엔탈피법으로 결빙·해빙(어는점 0 °C, 미동결수 곡선 없음), 침투 임피던스 10^(−7Q) (Hansson 등 2004) | 강도·투수성 일률 증가 가정 안 함 |
| 동결융해 | 셀(지표층에 물·얼음이 있을 때 0 °C 교차)·도로·건물 외피의 주기 수를 세고 누적 지수(ASTM C666의 300주기 기준)로만 보고 — 강도 감소는 넣지 않음 | 균열 전파 모델 없음 |
| 공기층 강제 | (a) **flux**: 배경(자유 대기) 기온·습도가 프로파일을 따르고, 층은 경계층 혼합 시간 τ_mix(기본 900 s, 보정 안 됨 — z_i/w* 규모, Stull 1988)로 이완 + 경계 유입 공기가 배경 상태, 하늘 장파가 배경 습도·기온에서. (b) **prescribed**: 층 기온을 매 스텝 프로파일 값으로 고정 — 넣고 뺀 열을 외부 계정에 | 두 방식은 섞이지 않음 |
| 끓음 | 국소 기압의 끓는점(Phase 29 `boilingPoint`) 위의 물 엔탈피를 증기로 투영(제한된 상변화, 거품·폭발적 비등 없음). 삼중점(611.657 Pa) 아래는 액체 평형이 없음 → 0 °C까지 끓고 얼음으로(승화) — 경고 | 에너지 없이 물이 사라지지 않음 |
| 날림 눈 | 문턱 마찰 속도(Li & Pomeroy 1997 문턱 풍속), 도약 수송 Pomeroy & Gray (1990), 국소 풍속은 Phase 15 공간 바람(건물 후류 포함) → 1 m 격자 공여 셀 수송, 건물(막힌 칸) 앞에 퇴적 | 부유 수송·승화 손실 별도 없음 |
| 수관 차단 | Hedstrom & Pomeroy (1998) I_max = S̄(0.27 + 46/ρ_new)·LAI, 하중 > 약 30 kg/m²(수관 투영) → 줄기 파손 지표(Nykänen 등 1997, 지시값) | |
| 마찰 | 상태별 대표 계수(건조 아스팔트 0.7, 젖음 0.5, 압설 0.25, 신설 0.3, 얼음 0.1, 젖은 얼음 0.05 — 문헌 범위의 대표값) / 건조 지표 계수 → Phase 14 접촉 마찰 배율 | 실제 제동거리 예측 아님 |
| 상수 | L_v = 2.501·10⁶, L_f = 3.337·10⁵, L_s = L_v + L_f J/kg (0 °C 값, 온도 의존 무시 — 30 °C에서 L_v −3 %), c_i = 2108, c_w = 4186 | 단순 일관성을 위해 상수 |

## 2. Phase 29 잔여 검증

### 2.1 대기 질량과 수증기

- 수증기는 **별도 질량 추적자**(`ClimateWorld.vap`, 5 m 공기층 칸, kg)입니다. 건조 공기 질량은 Phase 29 `AtmosphereField.sigma`(대기 실험이 있을 때) 또는 Phase 26 공기층 열용량(ρ·H·A)이 정합니다.
- 비습 q = m_v/(m_d + m_v), 증기압 e = q·p/(ε + (1 − ε)q) — 압력 p는 대기 실험의 칸 지면 기압(있으면) 또는 기준 기압. 상대습도는 저장하지 않고 매번 계산합니다(입력은 배경 공기의 RH뿐).
- 대기 실험이 공기를 제거하면 같은 칸·같은 비율로 수증기·응결수도 빠집니다(`AtmosphereRuntime.lastRemoved` → `removeWithAir`, 물 장부 `removed`, 에너지 장부 L_v·m). 테스트: 제거 50 %에서 `removed > 0`, 장부 잔차 < 10⁻⁸.
- **알려진 단순화**: 수증기가 기둥 질량(σ)과 평균 기체상수에 더해지지는 않습니다. 10 m 층의 증기는 기둥 질량의 10⁻⁵ 규모(15 °C, RH 60 %에서 층 0.1 kg/m² ≪ 10 300 kg/m²)라 지면 기압 변화 < 0.01 Pa, 가상 온도 효과(밀도 −0.5 %)도 공기역학 힘에는 넣지 않았습니다(Phase 29 결과 불변을 우선). 수증기와 건조 공기의 상태는 서로 모순되지 않습니다 — 기압은 건조 공기 질량에서, 증기는 그 기압에서의 분압으로.

## 4. Climate Scenarios

시나리오는 **라벨 + 편집기 기본값**(`scenarioDefaults`)입니다. 물리는 필드(경로·습도·강수·태양·초기 상태)로만 정해집니다.

| 시나리오 | 입력 | 결과(계산) |
|---|---|---|
| Heatwave | 기온 경로 ↑, 습도 ↓, 태양 | 공기층·지면·물체 가열, 증발·토양 건조, 수관 수분 감소 |
| Cold Wave | 기온 경로 ↓, 밤 하늘 | 냉각, 결빙, 서리, 토양 동결, 눈 보존 |
| Rapid Cooling / Warming | 짧은 램프 | 상변화 지연(잠열) |
| Snowfall | 강수 + 형태(자동/눈) | 적설·압밀·수관 차단·지붕 하중 |
| Freezing Rain | 강수 형태 = 비, 영하 지표 | 착빙(덮개 노드에서 결빙), 노면 결빙, 수관 착빙 |
| Surface Frost | 습하고 차가운 맑은 밤 | 지표 서리(증착 → 얇은 얼음 덮개) |
| Road Icing | 비로 젖은 뒤 냉각 | 수막·도로 얼음 → 마찰 |
| Lake Freezing | 차가운 호수 + 한파 | 수면 얼음(부유) |
| Snowmelt / Thawing | 초기 눈·동결토 + 온난화 | 융설수 → 홍수, 토양 해빙 |
| Drying / Humid | 습도 경로 | 증발 / 응결·안개 |

폭염·한파의 두 방식(§1.5): `flux`(배경 공기 + 경계층 교환, 지표 에너지 수지가 그대로 작동)과 `prescribed`(공기층 온도 고정, 넣고 뺀 열은 외부 계정 `climate`). 섞지 않습니다.

## 5. Climate Time Profiles

`src/climate/profiles.ts`: 기온(과 그 모양을 따르는 배경 습도) — constant(계단), linear, smooth(3s² − 2s³), staged, cyclic(시작 = 최저, P/2 = 최고), scheduled(구간 안 = 목표). 지속 시간 뒤에는 끝값을 유지합니다. 강수 — constant, rampUp, peak, scheduled, 구간 [start, start + duration). 강수 적분은 **닫힌 식**이라 시간 간격과 무관(테스트: Δt 0.1 / 0.37 / 1 / 7.3 s에서 같은 총량, 시뮬레이션 600 s 강설 총량 = 계획량). 이벤트는 기존 스케줄러(실험 인스턴스, 상대 시작)로 들어갑니다.

## 6. Atmospheric Humidity

보존량 = 증기 질량. 비습·증기압·상대습도·이슬점은 파생(§2.1). 배경 공기의 RH만 입력이며, 입력 RH > 100 %(이슬점 > 기온)는 거부합니다. 증기 수송: 대기 실험이 있으면 그 면 속도(배경 바람 + 계산 기류), 없으면 Phase 26의 층 평균풍 — 공여 셀 상류 차분, CFL ≤ 0.9, 경계 유입 = 배경 비습(장부 `vaporIn/Out`). 연직 교환: 부력 환기(열과 같은 몫 1 − e^(−wΔt/H)) + 경계층 혼합(τ_mix), 배경 비습으로 이완. `prescribed`에서는 습도도 처방.

## 7. Saturation & Condensation

포화: IF97(≥ 0 °C, 끓음까지) / Murphy & Koop(과냉각 물, 얼음), 0.01 K 표(성능, 상대 오차 < 2·10⁻⁸). 공기층 응결은 **액체 포화**에서(빙정 핵생성 모델 없음 — 얼음 기준 과포화는 남음), 에너지 보존 포화 조정(뉴턴: c·ΔT = L·Δm, 테스트). 응결수는 칸의 저장소이며 미포화가 되면 다시 증발, 넘치면 Kessler 자동변환으로 비·눈(습구 온도)으로 떨어집니다 — 그 엔탈피는 생길 때 공기에서 빠져 "이동 중" 저장소에 있다가 지면에 도착합니다. 구름 미세물리(충돌·병합, 빙정 과정)·복사 효과 없음.

## 8. Evaporation

| 대상 | 식 | 질량 출처 |
|---|---|---|
| 홍수·호수·하천 물 | E = (h_c/(c_p·Le^(2/3)))·(q_s(T_w) − q_a)·A — 지면 스텝 안에서 물 노드의 잠열 | `WaterField.h`(장부 `evaporated`) |
| 젖은 지면 | 같은 식 × 토양 저항 몫 1/(1 + r_s·h_m/ρ), r_s = exp(8.206 − 4.255W) (Sellers 1992) | 홍수 침투분 → 선행 토양수(상부 8 cm) |
| 덮개(눈·얼음) | 승화(L_s)·액체 증발(L_v), 덮개 노드 안 | 덮개 |
| 식생 | 증산 g_c·ρ·(q_s(T_leaf) − q_a)·A_proj (g_c = 10 mm/s, 밤 10 %), 뿌리층 토양수로 공급, 건조하면 큐티클 20 %만 수관 물에서 | 토양 / Phase 27 수관 물 |

각 경로에서 (1) 질량 감소, (2) 증기 증가, (3) 잠열 이동이 함께 일어납니다(§1.3의 짝 규칙). 물이 부족하면 증발률은 그 스텝에 공급 가능한 양으로 제한(`evapMax`). 응결(이슬·서리)은 같은 식의 음수 — 이슬은 토양수로, 서리는 얇은 얼음 덮개로.

## 9. Boiling & Low Pressure

§2.2. 물 노드의 엔탈피가 국소 끓는점(IF97, 칸 기압)의 엔탈피를 넘으면 초과분/L_v만큼 증기로(물 장부 `boiling`, 증기의 현열은 공기로). 끓는 칸 수는 HUD·로그. 거품·폭발적 비등·2상 유동 없음. 테스트: 105 °C 물 → 끓는점으로 내려오고 장부가 닫힘.

## 10. Freezing & Melting

엔탈피법(Phase 26의 접근을 확장): 덮개는 U(0 °C 액체 기준)로 상태를 가져 상변화 중 0 °C에 머뭅니다(테스트: 녹는 동안 덮개 온도 = 0 °C). 물·토양수는 **투영 엔탈피법** — 스텝 뒤 0 °C 아래로 내려간 만큼만(E(0 °C) − E)/L_f 결빙, 위로 올라간 만큼만 해빙. 한 번에 전부 얼거나 녹지 않고, 진동하지 않습니다(투영 후 정확히 0 °C). 압력에 따른 녹는점 변화(−7.4·10⁻⁸ K/Pa)는 무시.

물이 전부 얼고도 남는 부족분("extra cold")은 수심 1 mm 이상의 물이면 새 얼음이 받되 주변의 가장 찬 온도(공기·지면·하늘)까지만, 얇은 막(Phase 26에서 지면과 열적으로 합쳐진 물)이면 지면 표면층이 받습니다. 몇 그램의 새 얼음이 막 전체의 부족분을 받으면 얼음이 수천 K 아래로 내려가는 수치 폭주가 생겼습니다(도로 결빙 검증에서 발견 — 공기 칸 −1745 K, 4만 K). 같은 이유로 덮개 노드는 갱신 전에 **열을 주고받는 가장 찬 대상(공기·바닥·하늘)보다 차가울 수 없고**, 그 아래 부족분은 지면 표면층으로 정확히 옮깁니다(에너지 보존).

## 11. Snowfall

외부 강수(입력, 물당량 mm/h)와 내부 강수(응결수 Kessler)를 구분해 기록합니다. 분할은 칸의 습구 온도(0–2 °C 선형) 또는 사용자 고정 형태. 신설 밀도는 그 칸 기온(Anderson). 눈은 질량(kg)으로 기록되고 깊이는 밀도로 환산 — 600 s 강설 테스트에서 질량 = 계획량.

## 12. Snow Accumulation

| 대상 | 방식 |
|---|---|
| 지면·도로 | 셀 덮개(1 m) |
| 지붕 | 건물 저장소(발자국 면적 전체), 지붕 칸(막힌 칸)의 강수를 받음 |
| 식생 | 수관 저장소, Hedstrom–Pomeroy 차단(I_max = 6.6·(0.27 + 46/ρ)·LAI, LAI 침엽 3.5 / 활엽 3(잎) 또는 0.7(낙엽기 가지)), 나머지는 아래 칸 |
| 차량 | 차량 저장소(발자국) — 차 아래 지면은 덮이지 않음 |
| 잔해 | 미지원(더미 위 강수는 그 지면 칸으로) |

저장소마다 질량·엔탈피·얼음·밀도·알베도를 가지며 같은 덮개 노드 함수로 갱신됩니다(바닥 = 물체의 열 노드: 지붕은 건물 외피 노드, 경로 열저항 2.5 m²K/W; 수관은 잎 노드; 차량은 차체).

## 13. Snow Compaction

CLM 4.5(파괴적 변태 + 과하중, Anderson 1976): 단일 층의 과하중 = 자기 질량의 절반(kg/m²). ρ' = ρ·exp(−CR·Δt), 질량 불변, 550 kg/m³(펀 전이)에서 멈춤. 융해는 일정 밀도로 질량만 빠져 깊이가 줄어듭니다. 결정 변태·층 구조는 계산하지 않음.

## 14. Snowmelt & Runoff

덮개 노드가 녹으면 액체가 생기고, 동결 눈의 5 %를 넘는 액체는 0 °C로 홍수 모델에 들어갑니다(`WaterField.h`, 장부 `melt`, 열 `c_w·m·(0 °C − T_ref)`). 이후 경사면 유출·도로변 흐름·침투·배수·홍수는 Phase 14가 그대로 계산. 눈 질량 감소 = 액체 증가(테스트: 홍수 장부 melt = 기후 장부 융설수). 홍수 모델이 꺼져 있으면 첫 융설수가 켭니다.

**융설 홍수 프리셋**: 30 cm·400 kg/m³의 숙성된 눈(초기 알베도는 밀도로 — 100 kg/m³ 0.85, 400 kg/m³ ≈ 0.62), 15 cm 동결 지면(침투 거의 없음), 1 → 12 °C·상대습도 95 %, 비 25 mm/h(45분). 적설이 비를 보유(동결 눈의 5 %)한 뒤 배수하고, 동결 지면 위로 유출되어 골짜기에 모입니다(헤드리스: 1200 s 침수 6칸, 1800 s 170칸). 처음 프리셋(60 cm·350 kg/m³, 녹은 지면, 건조해지는 공기)은 비를 적설과 토양이 모두 흡수해 홍수가 생기지 않았습니다 — 물리적으로 맞는 결과였고 프리셋이 시연 목적에 맞지 않았습니다.

## 15. Road Icing

도로 칸의 상태(눈 깊이, 얼음 두께, 수막, 덮개/지면 온도) → 상태 분류(dry / wet / snow / packed / slush / ice / wetIce / frost) → 대표 마찰 계수 → Phase 14 접촉 마찰 배율(`GroundContactSystem`, 물체 둘레 4점 평균 — 주차된 차 아래는 차가 덮음). 네트워크 도로 구간마다 `RoadSegmentState.climate`(눈·얼음·수막·노면 온도·마찰·상태), 눈 ≥ 0.25 m → 통행 불가 표시(지시값). 색은 계산 상태에서만.

**포장면 수막**: Phase 14 우수 배수구는 포장 칸의 물을 용량(30 mm/h)까지 전부 가져가 노면에 얼 물이 남지 않았습니다. 기후 실험 중에만 배수구가 0.5 mm(`PAVEMENT_FILM`, 포장 함몰 저류 — SWMM 불투수면 1.3–2.5 mm의 아래쪽)를 남깁니다(`WaterField.drainKeep`, 기본 0 → Phase 14 산술 그대로). 아스팔트의 작은 투수성(Phase 14 버킷)은 그대로라 비가 그친 뒤 노면이 0 °C에 이르기 전에 수막이 스며들 수 있습니다 — 도로 결빙 프리셋은 노면이 얼 때까지 약한 비(3 mm/h, 30분)가 이어지는 조건입니다(헤드리스: 1200 s 0.3 mm, 1800 s 0.68 mm 유리 얼음, 접촉 마찰 배율 1.27 → 0.18).

**접지된 얼음**: 홍수 솔버의 얼음 하중은 뜬 얼음의 흘수이고, 물이 흘수보다 얕으면(바닥에 닿은 유리 얼음) 하중은 물 깊이까지만입니다(h = 흘수에서 연속). 0.1 mm 막 위에 미터급 수두가 생겨 CFL 부분 스텝이 폭주하던 문제를 고쳤습니다.

## 16. Lake & River Ice

물 노드가 0 °C 아래로 가면 부족 엔탈피만큼 결빙(물의 질량에서 — 중복 생성 없음), 얼음은 덮개로(물 위 얼음, 아래 물과 접촉 1000 W/(m²K) — 계면은 0 °C). 홍수 솔버: 얼음 무게는 수면 압력으로(뜬 얼음 = 같은 질량의 물 수두 → 얼음 가장자리에서 가짜 흐름 없음), 얼음 밑면 마찰 n² × 2.5(Sabaneev), 액체 < 5 mm인 결빙 칸은 흐름 차단. 얇은 물 솔버가 얼음 아래 흐름을 정확히 표현하지 않는 단순화된 경계 조건입니다. 성층(4 °C 최대 밀도)·얼음 파괴·유빙 없음.

## 17. Ground Frost & Frozen Soil

열 지면 4층(0.8 m)마다 선행 토양수(θ₀·두께)가 층 온도에 따라 결빙·해빙(투영, 잠열은 층 E). 상부 두 층의 얼음 비율 Q로 침투 용량 × 10^(−7Q)(Hansson 등 2004). 동결 깊이·동결 칸 수 보고. **강도·투수성의 일률 증가는 넣지 않았습니다**(지반 실패 모델의 점착력 변화 없음 — 해빙수 침투가 기존 경로로 수위를 올림). 홍수 모델의 사건 침투분은 동결하지 않는 별도 수분으로 취급(버킷 모델 — 층 구조 없음, 명시).

**동결 판정**: 층의 물 중 25 % 이상이 얼음이면 동결층으로 셉니다(`FROZEN_ICE_FRACTION` — 침투 계수 10^(−7·0.25) ≈ 0.02, 사실상 불투수, Lundin 1990). 동결 깊이 = 동결층의 가장 깊은 바닥. 표면 두 층(8 cm, Phase 26 표면 재질)의 선행 수분은 재질 투수성에 비례합니다(아스팔트 0.11·θ₀, 암반 0.18·θ₀ — 포장·암반은 물을 거의 갖지 않음). 극한 한파 프리셋(−25 °C, 바람 4 m/s): 표층이 0 °C에 머물며 약 350 W/m²로 얼어 1시간 무렵 동결층이 됩니다(Stefan 해 ≈ 3 cm/h와 같은 크기).

## 18. Freeze–Thaw Effects

지표층에 물·얼음이 있는 칸이 동결 → 해빙될 때마다 주기를 셉니다(셀별 `ftCycles`, 도로·인스펙터·결과). ASTM C666의 300주기 기준으로 보면 한 실행(수 주기)의 영향은 무시 수준이므로 **강도 감소는 적용하지 않고 누적 지수만** 보고합니다(균열·서리 융기 없음).

## 19. Solar Radiation

§1.5의 식. 셀 입사각(지형 경사), 그늘(지형 + 건물·벽 높이장 광선 진행, 태양이 1° 움직일 때만 재계산), 지표 재질 알베도 / 물 0.06 / 얼음 0.35 / 눈 노화 알베도(+ 화산재). 물체: 윗면(fOut·Atop·sin β) + 옆면(Av/π·cos β) 직달 + 산란, 알베도 0.3 — `SourceStep`(`solar` 계정). 시각·위도·연중 일은 입력, 지방 태양시 기준(균시차·경도 보정 없음). 정밀 복사 전달 없음.

## 20. Surface Energy Balance

노출 지표(지면 스텝, 1 s): S(흡수 단파) − εσ(T_s⁴ − T_sky⁴) − h_c(T_s − T_a) − L·E − 전도(표면층 반저항) = 0, 잠열을 T_s에 대해 선형화. 덮개 표면: 같은 균형을 덮개 노드에 대해(암시). 계정: 태양(열 `solar` / 기후 `solar`), 장파 손실(열 `lost.radiationSky` / 기후 `longwave`), 대류·전도(내부 이동), 증발·응결 잠열(열 `latent`), 결빙·융해 잠열(열 `latent` / 기후 덮개 U), 공기층 강제(`climate`). 열원·용암·태양이 같은 칸을 데워도 각자 한 번씩만 들어갑니다(덮인 칸에 떨어지는 열은 덮개가 받음 → `cover −`).

## 21–23. Heatwave · Heatwave & Fire · Cold Wave

- 폭염: 공기층 가열(강제), 지표·건물·도로(아스팔트 알베도 0.08) 가열, 증발·토양 건조, 수관 수분 감소. 기온만으로 식생·건물이 파괴되지 않습니다(LOD: 기후의 균일 가열은 부재 세분을 유발하지 않음, EN 강도 계수는 100 °C 아래 1).
- 폭염 + 화재: 수관 함수율(기후가 추적, Phase 27 `water` 배열과 동기)이 내려가면 기존 착화 관계(Q_ig = 581 + 2594·M kJ/kg, 소화 함수율 0.3)에 반영됩니다. 살아 있는 수관은 60 % 아래로 마르지 않으므로(가정 하한) **폭염만으로는 수관이 착화 가능 함수율(< 30 %)에 이르지 않습니다** — 착화원이 필요. 연소열 장부는 그대로.
- 한파: 공기·지표·건물·물 냉각, 결빙, 서리, 눈 보존. `prescribed`에서 빠진 열은 `climate`(외부)로.

## 24. Buildings & Structural Loads

지붕 저장소 질량 × g를 지붕 부재(MT_ROOF)에 면적 비례 정적 하중으로(Phase 25 `addLoad`, 해저드 `climate`) — 5초마다, 변화가 부재 용량의 2 %·0.05 kPa를 넘을 때만, 0.4 kPa 미만은 넘기지 않음(성능 선별). 파괴·진행성 붕괴는 기존 구조 엔진. 붕괴(층 붕괴)하면 지붕 눈은 발자국 칸의 덮개로 질량·엔탈피 그대로 이동(테스트: 물 장부 잔차 유지). 레거시 건물은 하중 보고만. 열수축은 부재 열 세분된 건물에서만 Phase 26 구속 하중으로(기후 하중으로는 세분하지 않음).

## 25–27. Vegetation · Vehicles · People

- 식생: 표면 온도(Phase 26 잎 노드), 수관 함수율, 눈·얼음 하중(kg/m²) → 20 kg/m² 이상에서 부러짐(지시값, Nykänen 1997), 쓰러진 수관의 눈은 땅으로. 열·냉 스트레스는 노드 온도로만 보고(생리 모델 없음).
- 차량: 접촉 마찰(눈·얼음·수막), 차체 위 눈 저장소, 차체 온도(Phase 26). 타이어 모델·제동거리 없음 — 마찰 계수만.
- 사람: 기온 노출(최저·최고), 발밑 상태(눈·얼음), 접촉 마찰, 이동 제한 표시(눈 ≥ 0.3 m 또는 얼음, 지시값). 저체온·열사병·동상·탈수는 Phase 34 — 수치로 표시하지 않음.

## 28–30. Flood & Rain · Atmosphere · Volcano

- 홍수: 외부 강수는 한 번만 분할 → 비는 `WaterField.h`(장부 `rain`, 기후 비는 따로 추적해 장부에서 구분), 눈은 덮개. Phase 14의 비 이벤트는 그대로 비이며 영하 지표에 떨어지면 결빙(물 노드 투영). 동결토 침투 감소, 융설수, 수면 얼음 결합.
- 대기: §2.1, 증기는 대기 면 속도로 운반, 칸 기압으로 포화·끓는점, 제거와 함께 빠짐, 대기의 자유 대기 온도 변화(단열)는 배경 기온에 더해짐.
- 화산: 용암·분출물 열이 덮인 칸에 오면 덮개가 받음(융해 → 융설수 → 홍수 → 용암–물 열교환은 Phase 28), 화산재가 눈 알베도를 낮춤(질량 0.5 kg/m² 규모의 지수 혼합). 증기 폭발·빙하 상호작용 **미지원**.

## 31. Multi-Hazard Scenarios

피해의 1차 원인(해저드)과 원인(cause)을 구분해 기록합니다: 적설 하중 붕괴 = 해저드 `climate`, 부재 파괴 원인은 구조 엔진의 것(휨·축·전단), 수관 파손 = `snowLoad`/`iceLoad`. 결합은 모두 기존 경로(§28–30, 지진 + 적설 건물 = 같은 구조 모델에 정적 하중이 더해진 상태로 지진). 검증 장면은 §44–46.

## 32. Water Mass Ledger

final = initial + 강수 + 날림 눈 유입 − 유출 + 증기 유입 − 유출 − 공기와 제거 + 홍수 유입(비·원천·경계, 기후 비 제외) − 홍수 유출(경계·배수구) + 수관 물(증산·건조). 저장소: 증기, 응결수, 이동 중 강수, 덮개(눈·얼음·액체), 물체 저장소, 선행 토양수, 토양 얼음, 홍수(표면수 + 사건 침투분 — float64 장부 값). 내부 이동(증발·응결·결빙·융해·배수·승화·증착·증산·끓음·날림)은 총량만. 한 물질은 한 저장소에만 있습니다.

## 33. Energy Ledger

열 장부(Phase 26) + 기후 에너지 장부(덮개 U_g, 증기 L_v·m, 토양 얼음 −L_f·m, 이동 중 강수): 열 장부는 계정 `climate`(강제), `solar`(노출 지표·물체), `latent`, `cover`, `waterMass`로, 기후 장부는 `solar`(덮개), `longwave`, `precip`(외부 강수·날림 눈 엔탈피), `vaporIn/Out`, `removed`, `toThermal`(= 열 장부 latent + cover + waterMass)로 각각 닫힙니다. 둘의 합이 전체 에너지입니다. 잠열은 상변화 질량에만 붙고(엔탈피 상태), 온도 변화와 따로 다시 더하지 않습니다.

GUI(HUD·결과·프리셋 가정 목록)에도 같은 내용이 표시됩니다.

- 국소 축약 기후 모델입니다(1 m 덮개·5 m 공기 기둥·0.8 m 열 지면). 실제 일기예보나 장기 기후 예측 모델이 아닙니다 — 강제 경로는 사용자가 정한 입력입니다.
- 구름 미세물리는 Kessler 자동 변환(응결수 → 강수) 하나뿐입니다. 빙정 과정·구름 복사·정밀 강수 생성 없음, 강수는 떨어지는 시간 없이 지면에 도달합니다(입자는 시각 효과).
- 정밀 대기 복사 전달 없음: 하늘 온도는 Brutsaert 경험식, 맑은 하늘 일사는 Meinel·Kasten 경험식, 구름은 Kasten–Czeplak 계수.
- 눈은 칸당 단일 엔탈피 노드(층 구조·결정 변태·깊이 서리·눈사태 없음). 압밀은 CLM 4.5 경험식.
- 빙하 유동 없음. 호수 얼음의 기계적 파괴·유빙·성층(4 °C 최대 밀도) 없음, 얼음 아래 흐름은 얇은 물 솔버의 단순화된 경계 조건.
- 지반 동결융해는 4층 열 지면의 토양수 상변화와 침투 계수뿐 — 동상(frost heave)·균열·강도 변화는 계산하지 않습니다(동결융해 주기 수만 보고).
- 도로 마찰은 노면 상태별 대표 계수(Wallman & Åström)의 배율입니다. 타이어 모델 없음 — 실제 타이어·도로 마찰 예측에 사용할 수 없습니다.
- 포장면 수막(0.5 mm)은 고정된 함몰 저류값입니다. 아스팔트의 투수성은 Phase 14 버킷 그대로입니다.
- 저압·극저온: 포화 표는 150–400 K, 대류·증발 상관식은 연속체 범위, 삼중점 아래에서는 물이 0 °C까지 끓고 언다는 단순화.
- 수증기는 공기 기둥 질량·가상 온도에 더하지 않습니다(§2.1, 습윤 공기 밀도 효과 없음).
- 사람: 기온 노출과 이동 제한만 — 체온·동상·열사병 같은 열생리는 Phase 34 범위입니다.
- 실제 건축(적설 하중 설계)·도로 관리·기상 안전 판단에 사용할 수 없습니다.

## 49. Phase 31 (Variable Gravity) 호환

이번 Phase에서는 중력을 바꾸지 않습니다. 중력이 들어가는 곳을 정리해 두었습니다.

| Phase 31이 쓸 것 | 현재 위치 | 메모 |
|---|---|---|
| Gravity-Dependent Atmospheric Pressure | Phase 29 `AtmosphereField`(정수압 척도 높이 g), 기후의 기둥 질량 `layerMass(a)` | 수증기 질량은 기둥 질량 비례 — g가 바뀌면 같은 경로로 따라감 |
| Snow / Ice Weight | `ClimateRuntime`의 지붕 하중 `M·GRAVITY/A`, `ClimateWorld.storeLoad(k, g = 9.81)` | 하중 경로는 이미 g 인자를 받음 |
| Structural Gravity Loads | 지붕 부재에 `addLoad`(양자화 0.4 kPa) — Phase 23 구조 모델 | 같은 함수에 g 전달 |
| Water Hydrostatic Pressure | 홍수 솔버 `G`, 뜬 얼음 하중 = 흘수(질량/ρ_w — g와 무관한 수두) | 수두 형식이라 g 변경 시 솔버 쪽만 |
| Particle Settling | 날림 눈 도약량 `Q = 0.68·ρ·u_t(u*² − u_t²)/(9.81·u*)`(Pomeroy & Gray), 시각 입자 | 상수 9.81을 인자로 바꾸면 됨 |
| Snowfall / Rainfall Motion | 강수는 즉시 도달(낙하 시간 없음), 입자는 시각 효과 | 낙하 속도 모델이 필요하면 새로 추가 |
| Ground Contact | `GroundContactSystem` 마찰 배율(기후 노면 상태) — 수직력은 Phase 15/21 | 배율은 g와 무관 |
| Terrain / Sediment Transport | 융설수 → Phase 14 유출·침식 경로 | 기존 경로 |
| Snow compaction overburden | CLM 과하중 P_s(kg/m², 표준 중력 내포) | g 비율 곱으로 일반화 가능 |
