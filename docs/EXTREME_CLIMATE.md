# Phase 30 — Extreme Climate, Humidity, Snow, Ice & Water Phase Change

폭염·한파를 설정하면 공기·지면·물·구조물의 온도가 바뀌고, 그 결과로 **수증기 이동, 증발·응결, 강설·적설·압밀, 결빙·해빙,
지반 동결, 융설수, 구조 하중**이 기존 물리 시스템(Phase 14 홍수, Phase 26 열, Phase 27 화재, Phase 29 대기)을 통해 일어나게 하는 단계입니다.

> §1은 구현 전에 쓴 분석과 설계, §2부터는 구현·측정·검증 결과입니다.
> **국소 축약 기후 모델입니다. 일기예보·기후 예측 모델이 아니며 건축·도로·기상 안전 판단에 쓸 수 없습니다.**

### 1.3 에너지 소유권

| 에너지 | 소유 | 비고 |
|---|---|---|
| 공기·지면·물·물체·구획의 현열 | **Phase 26 열 세계** (기준 대비 E) | 기후 강제는 공기층 칸에 열을 넣고 뺄 뿐(계정 `climate`) |
| 덮개(눈+얼음) 엔탈피 | `ClimateWorld` 덮개 노드(셀당 1노드, 0 °C 액체 기준 U) | 동결분의 −L_f 포함 → 상변화 중 온도 고정(엔탈피법) |
| 수증기 잠열 | `ClimateWorld` (L_v·m_v) | 증기의 현열은 공기 노드의 열용량에 포함(건조 공기 근사, ≤ 2 %) |
| 토양 얼음 잠열 | `ClimateWorld` (−L_f·m) | 결빙 = 지면 층 E에 +L_f·dm, 융해 = −L_f·dm (투영 엔탈피법) |

**공통 기준**: 물 물질은 "기준 온도 T_ref의 액체 = 0 J/kg". 덮개의 전역 에너지 = U + M·c_w·(T_m − T_ref). 저장소 사이 질량 이동은 (질량, 그 저장소의
비엔탈피 × 질량) 쌍으로만 하고, 잠열 이동은 열 장부 `latent` 계정으로 기록합니다. 기후 장부 + 열 장부를 합한 전체 에너지가 외부 입력
(태양, 하늘 장파 손실, 공기층 강제, 강수 엔탈피, 증기 경계 잠열)만으로 닫혀야 합니다(테스트).

### 1.4 갱신 순서 (계획)

```
prePhysics   GroundContactSystem   유효 마찰(지면 재질 × 젖음 × 눈·얼음)          ← 기후 덮개 상태(한 스텝 전)
             WaterSolverSystem     기후 강우(대기 중 깊이), 얼음 하중·마찰·결빙 차단, 동결토 침투 감소
postPhysics  … DamageSystem
             ThermalSystem (0.1 s)
               0 ThermalRuntime.prepare
               1 AtmosphereRuntime.prepare
               2 ClimateRuntime.prepare     강제 경로(기온·습도·태양·강수·구름) → 공기층 경계 교환/처방 기온(계정 climate)
                                            → 하늘 유효 온도·셀별 태양 흡수·덮개 마스크·잠열 수송 계수를 열 지면 스텝에 넘김
               3 VolcanoRuntime.prepare / FireRuntime.prepare
               4 ThermalWorld.step          지면 스텝(1 s)에서 노출 셀의 태양·하늘 장파·대류·증발 잠열(선형화 표면 균형)
               5 FireRuntime.after
               6 AtmosphereRuntime.after
               7 ClimateRuntime.after       (지면 스텝이 돈 경우) 강수 분할 → 덮개 갱신(암시 1노드: 지면·물·공기·하늘·태양·승화)
                                            → 상변화 투영(물 결빙/해빙·끓음·토양 동결) → 압밀·알베도 → 배수(융설수 → 홍수)
                                            → 증발 질량 정산(물·토양·덮개 → 수증기) → 물체(지붕·수관·차량) → 날림 눈
                                            매 스텝: 수증기 수송(대기 면 속도 또는 평균 바람)·경계 혼합·포화 조정(응결)·Kessler 강수
                                            → 하중(5 s, 변화량 양자화) → 도로·마찰·노출 → 장부·통계·마일스톤
               8 VolcanoRuntime.after / ThermalRuntime.after
```

반복 순서는 셀·칸 인덱스(행 우선)·물체 삽입 순서뿐 — 객체 ID 무관.

### 1.5 모델 선택

| 항목 | 선택 | 근거 / 대안 |
|---|---|---|
| 포화 수증기압 | 물: Murphy & Koop (2005) 식(10), 얼음: 같은 논문 식(7) — 123–332 K. 범위 밖은 끝값 + 경고 | Magnus는 −40 °C 아래 오차 큼 |
| 습도 상태 | 보존량 = 증기 질량 m_v. q = m_v/m_air, e = q·p/(0.622 + 0.378q), RH = e/e_s(T), 이슬점 = e_s⁻¹(e) | RH는 입력이 아니라 파생(배경 공기의 RH만 입력) |
| 표면 증발 | Chilton–Colburn 유사: 질량 전달 계수 h_m = h_c/(c_p·Le^(2/3)), Le = 0.85 — **기존 대류 계수(자연 + 바람 함수)를 그대로** 사용. 토양: Sellers 등(1992) 토양 저항 r_s = exp(8.206 − 4.255·W) | Penman은 별도 공기역학 저항이 필요 — 같은 h_c를 써야 현열·잠열이 일관 |
| 응결 | 공기층 칸의 포화 조정(뉴턴 반복, 잠열로 기온 상승 포함), 표면 응결(이슬·서리) = 음의 증발 | 구름 미세물리 없음 |
| 강수 생성 | 외부 강수(입력) + 응결수의 Kessler (1969) 자동변환 k(q_c − 0.5 g/kg), k = 10⁻³ s⁻¹ | |
| 비/눈 분할 | 습구 온도 T_w: 0 °C 이하 전부 눈, 2 °C 이상 전부 비, 사이 선형(50 % ≈ 1 °C — Ding 등 2014, Sims & Liu 2015). 사용자가 상(눈/비)을 고정할 수 있음(어는 비 = 비 고정 + 영하 지표) | 한 강수를 한 번만 나눔 |
| 덮개(눈+얼음) | 셀당 1노드 엔탈피(U, 0 °C 액체 기준), 동결 비율 → 상변화 중 0 °C 고정, 액체 보유 5 %(초과 배수), 눈 위 얼음/물 위 얼음 구분은 질량 태그 | 다층 적설 모델(SNTHERM·Crocus) 아님 |
| 신설 밀도 | Anderson (1976) ρ = 50 + 1.7·(T − T_f + 15)^1.5 (T ≤ T_f + 2), CLM 4.5 | |
| 압밀 | CLM 4.5 (Oleson 등 2013, Anderson 1976): 파괴적 변태 + 과하중(점성 η₀ = 9·10⁵ kg·s/m²) + 융해 | 결정 변태 모델 아님 |
| 눈 열전도도 | Calonne 등 (2011) k = 2.5·10⁻⁶ρ² − 1.23·10⁻⁴ρ + 0.024 | |
| 알베도 | 지표 재질 표, 물 0.06, 얼음 0.35, 눈 Douville 등 (1995) 노화(건조 −0.008/일, 습윤 τ = 0.24/일, 0.50–0.85, 강설 갱신), 화산재 혼합 | |
| 태양 | 적위·시간각(Cooper 1969), 맑은 하늘 직달 I_b = 1361·0.7^(AM^0.678)(Meinel & Meinel 1976), 산란 ≈ 0.1·I_b·sin β, 구름 Kasten & Czeplak (1980) (1 − 0.75N^3.4). 그늘 = 지형·건물 높이장 광선 진행(태양이 1° 움직일 때마다) | 정밀 복사 전달 없음 |
| 하늘 장파 | Brutsaert (1975) ε_clear = 1.24(e/T)^(1/7)(e hPa), 구름 (1 + 0.22N²)(Bolz) → T_sky = ε^¼·T_a | |
| 호수 결빙 | 물 노드가 0 °C 아래로 가면 초과 냉각만큼 결빙(투영 엔탈피법), 얼음은 덮개로 — 위 공기·하늘, 아래 물(0 °C 접촉). 물 노드는 완전 혼합(4 °C 밀도 최대·성층 없음) | 성층 호수 모델 아님 |
| 얼음 아래 흐름 | 얼음 무게는 수면 압력(뜬 얼음 = 같은 질량의 물 수두), 얼음 밑면 마찰(Sabaneev 합성 조도, 얼음 n = 0.02), 액체 < 5 mm인 결빙 칸은 흐름 차단 | 얇은 물 솔버의 정확한 얼음 밑 흐름이 아님 |
| 토양 동결 | 열 모델 4층의 토양수(선행 θ₀ + 침투분)를 층 온도의 투영 엔탈피법으로 결빙·해빙(어는점 0 °C, 미동결수 곡선 없음), 침투 임피던스 10^(−7Q) (Hansson 등 2004) | 강도·투수성 일률 증가 가정 안 함 |
| 동결융해 | 셀(지표층에 물·얼음이 있을 때 0 °C 교차)·도로·건물 외피의 주기 수를 세고 누적 지수(ASTM C666의 300주기 기준)로만 보고 — 강도 감소는 넣지 않음 | 균열 전파 모델 없음 |
| 공기층 강제 | (a) **flux**: 배경(자유 대기) 기온·습도가 프로파일을 따르고, 층은 경계층 혼합 시간 τ_mix(기본 900 s, 보정 안 됨 — z_i/w* 규모, Stull 1988)로 이완 + 경계 유입 공기가 배경 상태, 하늘 장파가 배경 습도·기온에서. (b) **prescribed**: 층 기온을 매 스텝 프로파일 값으로 고정 — 넣고 뺀 열을 외부 계정에 | 두 방식은 섞이지 않음 |
| 끓음 | 국소 기압의 끓는점(Phase 29 `boilingPoint`) 위의 물 엔탈피를 증기로 투영(제한된 상변화, 거품·폭발적 비등 없음). 삼중점(611.657 Pa) 아래는 액체 평형이 없음 → 0 °C까지 끓고 얼음으로(승화) — 경고 | 에너지 없이 물이 사라지지 않음 |
| 날림 눈 | 문턱 마찰 속도(Li & Pomeroy 1997 문턱 풍속), 도약 수송 Pomeroy & Gray (1990), 국소 풍속은 Phase 15 공간 바람(건물 후류 포함) → 1 m 격자 공여 셀 수송, 건물(막힌 칸) 앞에 퇴적 | 부유 수송·승화 손실 별도 없음 |
| 수관 차단 | Hedstrom & Pomeroy (1998) I_max = S̄(0.27 + 46/ρ_new)·LAI, 하중 > 약 30 kg/m²(수관 투영) → 줄기 파손 지표(Nykänen 등 1997, 지시값) | |
| 마찰 | 상태별 대표 계수(건조 아스팔트 0.7, 젖음 0.5, 압설 0.25, 신설 0.3, 얼음 0.1, 젖은 얼음 0.05 — 문헌 범위의 대표값) / 건조 지표 계수 → Phase 14 접촉 마찰 배율 | 실제 제동거리 예측 아님 |
| 상수 | L_v = 2.501·10⁶, L_f = 3.337·10⁵, L_s = L_v + L_f J/kg (0 °C 값, 온도 의존 무시 — 30 °C에서 L_v −3 %), c_i = 2108, c_w = 4186 | 단순 일관성을 위해 상수 |

### 1.6 장부

- **물 질량 (kg)**: 대기 수증기, 응결수, 액체 표면수(홍수), 눈, 얼음, 물체 위 눈·얼음, 토양수(침투분 + 선행), 토양 얼음, 수관 물(화재) /
  경계 강수, 경계 증기 유입·유출(이류·혼합), 공기와 함께 제거, 홍수 경계 유출·배수구, 홍수 사건 비·원천, 수치 잔차.
  final = initial + 외부 유입 − 외부 유출 (+ 잔차). 저장소 사이 이동(증발·응결·결빙·융해·배수·침투)은 내부 이동 총량으로만 기록.
- **에너지 (J)**: 현열(열 세계), 증발·응결 잠열, 융해·결빙 잠열, 태양 입력, 공기층 경계 가열·냉각(강제), 장파 손실, 전도·대류(내부 이동),
  이류(경계 출입), 외부 입력(강수 엔탈피), 미해결(구름 없는 응결수의 복사 등 없음 — 0), 잔차.
- 잠열은 상변화 질량에만 붙고 온도 변화와 따로 다시 더하지 않음(엔탈피 상태 → 이중 계산 불가).

### 1.7 결정론·원본 보존·호환

- 기후 상태는 런타임에만(`env.climate.rt`, 열 세계 배열); 원본 문서·지형·건물은 읽기만.
- **기후 실험이 없으면 모든 결합 배열·훅이 `null`/`undefined`** → 기존 코드 경로 그대로 → Phase 29와 비트 동일(식별 벤치 `IDENTITY_CLIMATE`, 빌드 a1a3e1e와 비교).
- 스키마 v7 유지: 기후 스펙은 실험 인스턴스(zod), 런타임 상태(덮개·증기·토양 얼음·장부)는 저장하지 않음(실행 중간 저장 미지원 안내 그대로).

### 1.8 성능 원칙

- 덮개·토양 동결은 10 × 10 셀 타일 단위 활성(덮개·물·영하 셀이 있는 타일만), 표면 과정은 1 s(지면 스텝과 같은 주기), 공기 수증기는 0.1 s.
- 그늘·경사는 태양이 1° 움직이거나 지형·건물이 바뀔 때만, 물체 저장소는 1 s, 구조 하중은 5 s마다 변화가 양자(용량의 2 %·0.05 kPa)를 넘을 때만,
  0.4 kPa(EN 1991-1-1 지붕 H 범주 q_k — 모든 지붕의 설계 하중) 미만 적설은 구조 모델에 넘기지 않음(성능 선별 — 명시된 근사).
- 기후의 균일 온난화로 건물 열 LOD가 세분되지 않게: 기후 실험 중 세분 기준 = 국소 기온과 25 K 이상 차이(열원·용암·화재의 강한 가열 영역 규칙은 그대로).
  기후 하중으로 구조 모델이 생겨도 그 자체로는 열 세분하지 않음.
- typed array, 작업 배열 재사용, 통계는 읽을 때.

### 1.9 하지 않는 것 (명시)

구름·강수 미세물리, 대기 복사 전달, 다층 적설(결정 변태), 빙하 유동, 호수 얼음 파괴·유빙, 성층 호수, 상세 동결융해 균열·서리 융기,
동결토 강도 증가, 실제 타이어 마찰·제동거리, 인체 열생리(Phase 34), 증기 폭발·화산–빙하 상호작용, 기후 변화 예측.
