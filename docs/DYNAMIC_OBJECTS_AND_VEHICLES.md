# 동적 물체·차량 동역학 (Phase 35)

설정 `settings.simulation.vehicles = { model: 'dynamics', … }`일 때만 켜지는 차량 동역학과, 새로 놓을 수 있는 수동 동적 물체(Level 1)의
설계·구현·검증 보고서입니다. 설정이 없으면 차량은 Phase 0–34의 강체 그대로이고 결과가 비트 단위로 같습니다(§35).
교육·탐구용 축약 모델이며 실제 제조사 차량의 성능·충돌 시험 결과를 재현한다고 주장하지 않습니다. 모든 계수는 단위·기본값·범위·출처·
수준(A 보존·강체 역학 / B 교과서 차량 동역학·측정 크기 / C 명시적 교육용 가정)과 함께 `src/vehicle/params.ts`에 있습니다(부록).

## 1. 개발 목적

**구동 토크 → 바퀴 회전 → 타이어 슬립 → 접지력 → 차체 가속·회전 → 충돌·전복·손상 → 탑승자·주변**의 인과를 수치 모델로 잇습니다.
차량의 움직임은 언제나 Rapier 강체 하나의 6자유도 운동이고, 그 위에 바퀴별 서스펜션·타이어·바퀴 회전·구동계·제동·조향·공기 저항을
힘으로 더합니다. 위치를 옮기거나 방향을 돌리는 코드는 없습니다(자동 운행도 입력만 만듭니다).

## 2. 기존 차량 모델 (Phase 0–34)

`src/objects/definitions/car.ts`: sedan/suv/truck, 길이·너비·높이, 질량 L·W·H·120 kg, 상자 충돌체 2개(차대는 지면까지 — 바퀴는
그림), 마찰 0.7, 반발 0.1, 바람 저항(Cd 0.9 실루엣). 구동·제동·조향·바퀴 상태 없음. 손상은 접촉력/(m g 30)의 건강, 1 m 이동(MOVED),
전복(위 축 y < 0.35), 침수·매몰. 이 경로는 설정이 없을 때 그대로입니다. 사전 감사 전문: 작업 기록 `audit-core.md`, `audit-hazards-ui.md`.

## 5. 질량과 관성 (수준 A)

국소 좌표: +X 앞(길이), +Y 위, +Z 오른쪽(오른쪽 = 앞 × 위; 따라서 +Y 둘레 양의 회전 = 좌회전). 원점은 정지 차고에서 차체 중심 아래 지면.
질량 m(기존 L·W·H·120 kg 유지)을 차대 상자(차체의 85 %), 실내 상자(15 %), 바퀴 4개(점질량 + 축 회전 관성)로 나눕니다.

상자(가로 a·높이 b·폭 c, 질량 M)의 중심 관성: \(I_{xx}=M(b^2+c^2)/12,\ I_{yy}=M(a^2+c^2)/12,\ I_{zz}=M(a^2+b^2)/12\);
부품 위치 d만큼 떨어지면 \(I \mathrel{+}= M(|d|^2\mathbf 1 - d d^T)\)(평행축 정리, 곱 관성 포함). Rapier에는 대각 성분을 주고 곱 관성의 최대
크기를 보고합니다(실내 상자가 앞뒤로 비켜 있어 작은 \(I_{xy}\)). 질량 중복 없음: 충돌체 밀도 0 + `setAdditionalMassProperties`(시험:
부품 질량 합 = m, 1e-9). 세단 4.5×1.8×1.45 m: m 1409 kg, 질량중심 (−0.03, 0.62, 0) m, \(I\) = (520, 2559, 2290) kg·m².

## 6. 무게중심과 정적 하중 (수준 A)

질량중심 높이 \(h\)·축간거리 \(L\)·윤거 \(t\)(변형별 비율 — 세단 L = 0.6·길이, t = 0.86·폭, 일반값). 평지 정적 하중: 앞 축
\(F_f = m g (x_c - x_r)/L\), 좌우 반씩(시험: 합 = m g, 질량중심 모멘트 평형, 시뮬레이션 10 s 정지에서 ΣF_z = m g, 앞 축 몫 손계산과 일치).

## 7. 바퀴

바퀴별 상태: 회전 속도 ω, 회전각(그림용), 조향각, 접지, 압축, 압축 속도, 스프링 힘 F_s, 법선 하중 F_z, F_x, F_y, κ, α, 미끄러짐,
구동·제동 토크, 잠김, 접지점·법선·힘. 바퀴는 별도 강체가 아니라 **레이**입니다(스트럿 위 끝에서 −up 방향, 길이 L_free + R). 바퀴는
사람·탑승자를 맞추지 않습니다(바퀴로 사람을 넘지 않음 — 차대가 사람과 충돌, §22). 바퀴 회전 그림은 이 ω를 적분한 값입니다.

## 8. 서스펜션 (수준 B)

\(F_s = k x + c \dot x\)(+ 행정 끝의 단단한 범프 스톱 10k), \(x = L_{free} + R - d_{hit} \ge 0\), \(\dot x = -(v_{mount} - v_{surface})\cdot up\),
인장 없음(\(F_s \ge 0\)). 모서리 질량 \(m_c\)과 승차 진동수 f(세단 1.4 Hz)로 \(k = m_c (2\pi f)^2\), \(c = 2\zeta\sqrt{k m_c}\)(ζ 0.3).
정적 압축 \(g/(2\pi f)^2\) = 0.127 m. 지면 반력: 스트럿이 F_s를 up 방향으로, 질량 없는 바퀴의 링크가 나머지를 받으므로 지면 법선 하중
\(F_z = F_s/(up\cdot n)\)이고, 차체에는 접지점에서 \(F_z n + F_x \hat x + F_y \hat y\)를 줍니다(스트럿 힘을 기울어진 차체 축 방향으로 주면
가속 중 0.4° 피치에서 87 N의 가짜 수평력이 생기는 것을 시험으로 찾아 고침, §37).

## 9. 타이어 슬립 (수준 B)

바퀴 좌표: x = 바퀴 방향(조향 반영)을 접지면에 투영, y = n × x(바퀴 왼쪽). 접지점 속도 \(v = v_c + \omega\times(p - c) - v_{surface}\).
정상 슬립: \(\kappa = (R\omega - v_x)/\max(|v_x|, |R\omega|, v_\epsilon)\), \(\alpha = \operatorname{atan2}(v_y, |v_x| + v_\epsilon)\)(표시용).
힘에는 **과도 슬립**(이완 길이 σ, Pacejka 2012 7장)을 씁니다: \(\sigma_x \dot\kappa' + |v_x|\kappa' = R\omega - v_x\), \(\sigma_y\dot\alpha' + |v_x|\alpha' = v_y\).
정지에서도 정의되고(트레드 변형), 경사면 정지 마찰을 줍니다. 저속(|v_x| < 2 m/s)에는 트레드 감쇠 \(\sqrt{(C/\sigma)\,m_c}\)(ζ ≈ 0.5, 가정)를
가중 \(1 - |v_x|/v_{low}\)로 더합니다.

## 10. 타이어 힘 (수준 B / C)

선형 요구 \(s = (C_\kappa\kappa', -C_\alpha\alpha')\), \(C_\kappa = 16 F_z\), \(C_\alpha = 10 F_z\)/rad(일반 승용 타이어 크기).
- 모델 A `linear`: \(F = s\)(마찰 한계 없음 — 작은 슬립 기준·시험용).
- 모델 B `saturating`(기본): 브러시(Fiala) 곡선 \(\varphi = |s|/(3\mu F_z)\), \(|F| = \mu F_z(3\varphi - 3\varphi^2 + \varphi^3)\)(φ < 1),
  φ ≥ 1에서 미끄러짐 — μ가 미끄럼 μ(0.8 μ, 가정)까지 줄어듦(φ 1→2). 방향은 s. 실측 Pacejka 계수를 쓰지 않으며 실차 정밀도를 주장하지 않습니다.

## 11. 마찰 원

구동·제동과 코너링은 같은 \(\mu F_z\) 예산을 나눕니다(결합 슬립 벡터 하나에 곡선 적용 — 시험: 임의 조합에서 \(|F| \le \mu F_z\), 방향 = 요구 방향).

## 12. 구동계 (수준 B 구조, C 제원)

엔진 전부하 토크 T_max(ω ≤ P/T), 이후 P/ω, ω_max에서 0. 크랭크 속도 = max(ω_idle, 구동 바퀴 평균 |ω| × 기어 × 종감속) — 공회전 아래는
클러치/컨버터 미끄럼으로 공회전 토크 전달(미끄럼 열은 모델링 안 함). 자동 변속: **도로 속도**(차체 속도/R)로 0.85 ω_max 위 올림, 0.4 ω_max
아래 내림, 한 기어 최소 1 s, 변속 0.25 s 무토크(바퀴 헛돔으로 기어가 올라가 토크가 끊기던 사냥 현상을 시험에서 찾아 고침). 효율 η,
FWD/RWD/AWD(AWD 50:50), 축 안은 개방 차동(같은 토크 — 접지 약한 바퀴가 헛돔). 구동 일 = Σ T ω(연료·배터리 에너지 없음).

## 13. 제동

바퀴별 쿨롱 토크(페달 × T_b,max, 앞 65 %): 바퀴를 멈출 수 있지만 거꾸로 돌리지 않음 → 잠김 표시. 주차 브레이크(뒤 바퀴), P단(구동 바퀴)
고정 토크. ABS(기본 켬): 계산된 바퀴 슬립 κ < −0.15에서 그 하위 스텝 제동 해제, −0.08 위에서 다시(2상태 슬립 제어). 저속 정지: 쿨롱
토크가 ω를 0으로, 타이어 변형이 차체를 정지 마찰로 붙잡음.

## 14. 조향

목표 δ = 입력 × δ_max × min(1, 12/v)(속도 제한), 속도 제한 조향 각속도, Ackermann: \(\cot\delta_o - \cot\delta_i = t/L\)(시험). 방향 변화는
조향각이 만든 타이어 횡력의 결과뿐이며 요 각속도를 직접 주지 않습니다(시험: 정상 선회에서 \(a_y = v r\), \(\Sigma F_y \approx m a_y\)).

## 15. 차체 운동

Rapier 강체 하나(6자유도, 감쇠 0 — 손실은 공기·구름·타이어·댐퍼). 차량용 적분기를 따로 두지 않습니다. 결합 순서: 스텝 시작 상태 →
바퀴·타이어 N 하위 스텝(차체 속도 고정, 연산자 분할) → 하위 스텝 평균 힘을 이 스텝 동안 일정하게 → Rapier 적분.

## 16. 공기 저항 (수준 B)

차체 축별: \(F_x = -\tfrac12\rho C_d A_f |v_r| v_{r,x}\), \(F_z = -\tfrac12\rho C_y A_s |v_r| v_{r,z}\), \(v_r\) = 압력 중심 속도 − 국소 바람,
압력 중심에 작용(롤·요 모멘트). ρ: 대기 실험이 있으면 그 값, 없으면 1.225(가정 표시). 물에 잠긴 몫은 빼고(물 항력이 대신). 차량 모드에서
이 힘이 기존 차량 바람 항력을 **대체**합니다(바람 시스템이 차량 모드 차를 건너뛰고, 같은 'wind' 출처를 한 번만 청구 — 중복 0, 시험).

## 17. 구름 저항

\(F_{rr} = C_{rr} F_z\)를 바퀴에 \(C_{rr}F_z R\)의 쿨롱 토크로 — 굴러갈 때만 저항하고 정지한 차를 움직이지 않음. \(C_{rr}\): 포장 0.012, 자갈
0.02, 흙 0.05, 잔디 0.06, 모래 0.15, 진흙 0.1(Wong 2008 크기), 눈 깊이 m당 +0.6(0.3 m 상한, 가정).

## 18. 전복

상태 upright / twoWheels / onSide / onRoof를 국소 중력에 대한 차체 자세와 바퀴 접지로 판정(0.5 s 유지해야 바뀜 — 출렁이는 몸체가 매 스텝
바꾸지 않음). 바퀴별 법선 하중으로 횡하중 이동비 LTR = |ΣF_z,좌 − ΣF_z,우|/ΣF_z를 계산(정적 기준 \(2h\tan\theta/t\)). 기울기만으로
판정하지 않고, 실제 강체 회전이 상태를 만듭니다. 정적 안정 계수 \(t/2h\)(세단 1.25)가 노면 μ(≤ 0.9)보다 커서 평지의 승용차는 넘어지기
전에 미끄러집니다 — 시험은 마찰 한계가 없는 선형 타이어와 측방 중력(경사대)으로 합니다(§37).

## 19. 충돌

Rapier 접촉 솔버가 모든 충돌을 풉니다. 차량 모드 차는 접촉 상세(힘 벡터·접촉점·법선)를 받고 상대별 **에피소드**(간격 ≤ 2 스텝 연결, 최대
30 스텝)로 묶습니다: 충격량 \(J = \Sigma F\Delta t\)(Rapier 보고 F = 그 스텝 솔버 충격량/Δt — 평균 힘과 충격량을 구분), 최대 힘, 충격량
가중 접촉점, 충돌 전·후 속도와 Δv, 첫 법선 방향 접근 속도, 운동에너지(병진 + 회전) 전·후. 접촉력 임계 2.5 m g 아래(정지 접촉)는 엔진이
보고하지 않습니다(한계).

## 20. 차량 손상 (수준 C, 교육용)

충돌 시험 자료가 없으므로 에피소드 Δv를 등가 충돌 속도의 대리값으로 씁니다: 누적 지표 \(\sqrt{\Sigma\Delta v^2}/20\) m/s, 단계
damaged ≥ 3, severelyDamaged ≥ 7, disabled ≥ 12, destroyed ≥ 20 m/s(가정). 능력: severely 구동 0.6·조향 0.8·제동 0.8, disabled 0·0.3·0.5,
destroyed 0. 지붕으로 뒤집히면 구동 불가, 흡기 침수 시 엔진 정지(§25). 운동에너지 손실을 모두 차체 변형으로 보지 않습니다 — 상대·지면·회전·
마찰·진동·솔버 소산으로도 가며 "차량이 잃은 운동에너지"로만 보고합니다. 차량 손상이 기존 건강(health)의 단일 소유자입니다(이중 감소 없음).

## 21. 탑승자 (Level A 축약)

`occupants: [{ human, seat, restrained }]`(확장 인체 모델의 사람만). 착석 중 사람 몸은 Rapier에서 **비활성**(충돌 없음 — 차체와 중복 충돌
없음)이고 좌석 위치로 옮겨집니다(그림·생리 표본용; 충돌 물리를 구현했다고 주장하지 않음). 하중: 좌석이 차를 따른다고 보고 에피소드 Δv와
최대 가속도(Δv/지속, 매 스텝 차체 가속도)를 기록. 벨트 안 맨 탑승자는 Δv ≥ 8 m/s 충돌 또는 옆/지붕 전복에서 차 밖으로(가정 규칙): 좌석 옆
위치·차의 그 점 속도로 몸이 다시 활성화되고 Phase 33이 이어받습니다(OCCUPANT_EJECTED). Level B(좌석·벨트 강체)는 구현하지 않았습니다.

## 22. Phase 33 연결

차량 → 사람: 차대와 사람 캡슐의 Rapier 접촉 → 사람 쪽 Phase 33 접촉 에피소드(상대 = 차, 구획 위험 지표, IMPACT/INJURED/FALLEN). 차량은
사람에게 체력 감소를 더하지 않습니다. 동력 주행 중 차가 일으킨 타격의 위험원은 새 hazard **'vehicle'**(이전에는 'wind'로 떨어짐). 바퀴 레이는
사람을 맞추지 않으므로 넘어진 사람을 바퀴가 타고 넘지 않습니다(한계).

## 23. Phase 34 연결

운전석 탑승자의 `physiologySnapshot`(없으면 Phase 33 능력): 최종 능력 normal/stressed 1, impaired 0.8, severelyImpaired 0.4, unableToAct 0 →
입력(가속·제동·조향)의 크기만 줄이고, 0이면 페달을 놓습니다(조향은 그대로). 차량 속도를 직접 바꾸지 않습니다(시험: CO 구역에서 운전자
행동 불가 → 구동 토크 0). 착석 중 생리 표본은 좌석 위치에서.

## 24. 지진

기존 SeismicForceSystem의 지반 관성력(−m a_g, groundMotion 출처)이 차체에 그대로 작용하고, 차량 모델은 아무것도 더하지 않습니다(시험: 중복
0). 바퀴 하중 변화·미끄러짐·전복은 그 힘의 결과. 기존의 시각적 흔들림(차체 롤·피치 그림)은 차량 모드에서 끕니다 — 차체 자세가 곧 물리입니다.

## 25. 홍수

기존 WaterForceSystem의 부력(봉인 부피 × 잠긴 비율, ρ g V, 가변 중력의 g)·물 항력이 그대로. 부력이 차를 띄우면 서스펜션이 늘어나 F_z가
줄고(시험: ΣF_z + 물 힘 = m g ± 0.4 %), 바퀴가 떨어지면 구동이 아무것도 밀지 못합니다(시험: 떠 있는 동안 전·무 가속 이동 차이 < 0.3 m).
흡기 침수 정지(가정): 수면이 차체 높이 절반에 닿거나, 부력 ≥ 90 % 무게로 바퀴 없이 1 s 떠 있으면 → VEHICLE_STALLED, 구동 불가. 기존 물
모델에서 세단은 약 0.3–0.6 m에서 뜹니다(봉인 부피 0.6 V).

## 26. 강풍

§16의 차량 공기역학이 국소 바람(바람장 + 대기 흐름)으로 측력·요·롤 모멘트를 만듭니다. 기존 차량 바람 항력과 중복 없음(시험).

## 27. 토석류·산사태

기존 SedimentForceSystem의 수평 항력(sediment 출처)이 그대로. 매몰(Phase 22)도 기존 규칙. 차량 모델은 추가 힘을 주지 않습니다.

## 28. 폭발

기존 BlastSystem의 면 충격량 + 폭풍(blast 출처)이 압력 중심에 — 병진·회전 충격량이 차체 운동과 전복을 만듭니다(재사용).

## 29. 구조물 붕괴

붕괴 파편·잔해와 차의 접촉은 Rapier가 풀고, 차량 에피소드가 그 결과를 읽습니다. 차가 구조물을 칠 때: 모듈러 건물 부재·가로등·표지판·벽·
나무를 Phase 25 타격 모델에 **차를 타격체로** 넘깁니다(E = J²/2m 대 부재 여유 / 기초 모멘트, 에피소드당 한 번 기록 — 시험: 가로등).

## 30. 화재

차량 모드는 화재와 결합하지 않습니다: 기존처럼 차는 열체(표면 온도)만 받고 연료·배터리 연소·폭발을 만들지 않으며, 온도 임계로 폭발을
생성하지 않습니다(한계 §41). 탑승자의 열 노출은 Phase 34가 좌석 위치에서 계산.

## 31. 결빙·적설

바퀴 접지점마다 지면 종류의 타이어 μ(포장 0.9 — Wallman & Åström 2001, 비포장 크기)에 기후 덮개 상태(Phase 30)를 같은 방식으로 섞음:
젖음 ×0.5/0.7, 눈 0.3, 다진 눈·진창 0.25, 얼음 0.1, 젖은 얼음 0.05, 서리(덮개 비율). 기후 없이 물막 ≥ 5 mm면 젖음. 눈 깊이로 구름 저항 증가.

## 32. 가변 중력

Rapier 균일 중력 + Phase 31 공간장 차이(gravityField 출처) 그대로 — 차량은 무게를 더하지 않습니다. 서스펜션·법선 하중은 실제 중력의 결과
(시험: 달 1.62 m/s²에서 ΣF_z = m·1.62, 압축 = g/ω²). 무중력에서는 하중 0 → 접지 0. 측방·반전 중력은 경사대 시험(§18).

## 33. 극한 천체 중력

Phase 32 KDK 적분·조석·포획을 그대로 씁니다. 바퀴 레이로 떠 있는 차는 솔버 접촉이 없어 "자유 비행" 몸체로 분류되어 중력 증분만 KDK로
바뀝니다(서스펜션·타이어 힘은 Rapier가 그대로 적분 — 결과 영향 없음, 기록). 포획되면 몸체가 사라지고 차량 상태는 동결, 착석 탑승자는 풀려납니다.

## 34. 에너지 장부

차량별(J): 구동 일, 제동·구름·타이어 미끄럼(F·v_slip)·댐퍼·공기 소산, 충돌로 잃은 운동에너지, 스프링 저장. 기계 에너지 E = 병진 + 회전 +
바퀴 회전 + 위치(국소 g) + 스프링; 잔차 = ΔE − (구동 − 소산 합 − 충돌 손실). 잔차에는 재난 힘의 일, 솔버 접촉·반발, 과도 타이어 변형 에너지,
연산자 분할 오차가 들어갑니다(장기 실행에서 크기 확인, §40).

## 35. 결정론

모든 차량은 id 순서로 처리, 입력은 스텝 경계에서만 반영(시간 프로그램·실시간 입력 동일 경로), 난수 없음. 시험: 같은 실행 두 번 비트 동일,
생성 순서를 뒤집어도 위치가 1 mm 이내(Rapier 내부 순서 차이 — 비트 동일이 아닌 허용 오차 동일).

동일성(차량 설정 없음, 기준 Phase 34 수정 `487035b`, Phase 35 `381bfa3`): 기존 장면 32/32 + Phase 31 장면 20/20 + 의도 변경 장면 1/1 =
**53/53 차이 0**, 미분 검사 **44/44 차이 0**, Phase 33 사람 장면 **22/22 동일** — 새 잎(키)도 0개(새 hazard 'vehicle'과 엔티티 필드는 차량
실행에서만 생김). 수동 물체 6종은 새 객체 종류라 기존 세계에는 없습니다.

## 36. 수치 안정성

찾은 문제와 해결: (1) 정지·저속에서 트레드 변형과 바퀴 관성이 강성 진동자 → 바퀴 회전과 종방향 슬립을 함께 **암시적**으로 풀고 저속 트레드
감쇠; (2) 미끄러짐 영역에서 할선 강성이 토크를 과대 → 미끄럼 중에는 마찰력을 상수로 한 명시적 갱신; (3) 헛도는 바퀴로 변속 사냥 → 도로 속도
기준; (4) 기울어진 차체 축의 스트럿 힘 → 지면 반력. 하위 스텝 기본 8(1/480 s), 1–32 설정. 고속 충돌: CCD 켬(작은 물체 관통이 완전히 없어진다고
주장하지 않음). 시간 간격: 물리 스텝은 1/60 s 고정(컨트롤러)이라 1/120·1/240 비교는 하위 스텝 수렴으로 대신했습니다(§37).

## 41. 과학적 한계

- 교육용 축약 모델: 특정 차량의 성능·제동 거리·충돌 결과를 예측하지 않음. 변형별 제원은 일반값.
- 바퀴는 레이: 측면으로 장애물에 걸리지 않음, 바퀴로 사람·잔해 덩어리를 타고 넘는 접촉은 근사(사람 제외), 단차는 서스펜션 행정 안에서만.
- 타이어: 브러시 곡선 + 이완 길이, 실측 계수 없음, 노면 μ는 표 값. 온도·마모·공기압·캠버 없음.
- 서스펜션: 독립 스프링·댐퍼, 롤 센터·안티롤 바·지오메트리 없음.
- 구동계: 클러치·컨버터 미끄럼 열, 엔진 관성, 차동 잠금, 견인 제어 없음.
- 탑승자: Level A(좌석 고정 + 규칙 기반 이탈), 벨트·좌석·에어백 물리 없음, 부상 판정 없음.
- 손상: Δv 대리 지표, 변형·부품 파손 기하 없음. 화재·연료·배터리 연소 없음.
- 물: 기존 물 모델(선형 부력, 고정 작용점, 파랑 감쇠 없음) — 뜬 차가 오래 출렁임.
- 수동 물체: 구름 저항 없음(공이 평지에서 계속 굴러감), 열·화재 없음.
