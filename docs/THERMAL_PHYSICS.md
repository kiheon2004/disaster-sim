# Phase 26 — Thermal Physics, Heat Transfer & Temperature Simulation Engine

월드 전체에 **일관된 열물리 상태**(온도·열에너지)를 도입하는 단계입니다. 사용자가 놓은 열원이 지형·물·대기·건물 부재·차량·식생·잔해를 데우고,
그 열이 **전도·대류·복사**로 이동하며, 필요하면 구조 부재의 **열팽창·구속 열하중·온도에 따른 강도 저하**가 Phase 25 구조 파괴 엔진을 거쳐
부분 붕괴로 이어집니다. **연소·화염 전파·연기·산소 소비는 없습니다**(Phase 27).

> 이 문서는 구현 전에 작성한 분석(§1)과 설계(§3)로 시작해 구현·측정·검증 결과(§2, §4–§46)로 채웠습니다.
> **축약 열전달 모델입니다. CFD·고해상도 열유동 해석이 아니며, 실제 건축물의 내화 성능·안전성 판단에 사용할 수 없습니다**(§42).

## 2. Phase 25 잔여 작업

### 2.1 구조 재분배의 시간 해상도 (측정)

열에 의한 강도 저하는 초–분 단위로 진행되고, 구조 엔진은 건물당 스텝(1/60 s)당 재분배 1라운드입니다. 측정용 옵션
`CollapseModel.roundsPerStep`(기본 1 — 결과 불변)을 추가해 **같은 가열 시나리오**(RC 아파트, 1100 °C 구가 1층 기둥을 감쌈)를
"스텝당 1라운드"와 "스텝 안에서 더 할 일이 없을 때까지(최대 50)"로 비교했습니다(`src/simulation/thermal/redistribution.test.ts`).

| 항목 | 1라운드/스텝 (정책) | 끝날 때까지 |
|---|---|---|
| 열로 유발된 첫 파괴 | 842.80 s, 슬래브 휨 | 842.80 s, 같은 부재·원인 |
| 재분배 연쇄(843.2 s 이전 기록) | 동일 집합 | 동일 집합 |
| 전체 기록 | 39 부재 | 33 부재 |
| 연쇄 완료 시각 | 844.05 s | 844.07 s |

차이는 **하류의 낙하 블록 충돌 1건**(6 부재)입니다: 블록이 한 스텝 늦게 만들어지면 아래층에 닿는 속도가 미세하게 달라지고, 그 층이
용량 경계에 있었기 때문에 한쪽에서만 파괴됩니다. 즉 1라운드 정책은 **원인·순서·시각(1스텝 이내)에는 영향이 없고**, 임계 근처의 충돌
결과만 바꿀 수 있습니다. 열 시간척도(분)에 비해 무시할 수 있는 시간 차이이므로 **정책은 바꾸지 않았습니다**(기존 붕괴 결과·결정론 유지).

### 2.2 레거시 건물과 잔해

- **레거시(Phase 0–16) 건물**: 부재 모델이 없어 외피(0.1 m 껍질)/내부 2노드 열 상태와 바닥 접촉 전도만 가집니다. **온도 의존 강도·열하중·열 파괴는
  계산하지 않습니다** — 모듈형 건물보다 정밀도가 낮으며 인스펙터에 그렇게 표시됩니다.
- **집계형 잔해 더미**: 더미마다 열 노드(질량 = 더미 질량, 일정 비열 880 J/(kg·K), 지면 접촉)를 갖습니다. 부재가 더미에 들어가면 그 에너지가
  **그대로 이동**하고, 더미가 커지면(차가운 질량 추가) 열용량만 커집니다(에너지 불변 → 혼합 온도). 수문 차단·블록 회전은 추가하지 않았습니다.
- **레거시 덩어리 파편**은 열 노드를 갖지 않습니다(그 열은 건물 노드에 남음).

### 2.3 성능 기준과 무열(無熱) 실행

- Phase 25의 100/500/1000동 장면을 같은 기계에서 **Phase 25 빌드와 번갈아** 측정: 헤드리스 ±4 % 안(잡음), 브라우저 FPS 동등(§38).
- 열원이 없는 실행은 **비트 단위로 같습니다**: 지진 연쇄 붕괴·압력파·홍수+강우·바람·운석 5개 장면의 결과 해시가 두 빌드에서 동일
  (`src/bench/identity.bench.test.ts`, `docs/bench-phase26-identity.json`). 골든 테스트도 그대로 통과합니다.

## 3. 설계 — 열 상태 아키텍처

### 3.1 노드 종류 (모델 수준을 대상별로 선택)

### 3.2 상태 변수와 단위 (§4)

- **에너지가 기본 상태입니다**: 노드마다 기준 상태(대기 기준 온도 T_ref)에 대한 엔탈피 E [J]를 저장하고, 온도 T [K]는 재료의 h(T)를 거꾸로 풀어 얻습니다.
  → 온도 의존 비열(EN 1992/1993/1995-1-2)을 정확한 에너지 보존과 함께 다룸, 열원 에너지가 그대로 더해짐.
- 표시만 °C, 계산은 K. 복사는 절대온도의 4제곱, 대류·전도는 온도 **차이**.
- 내부 에너지 장부는 "기준 상태 대비 현열"입니다(초기 0).

### 3.3 갱신 순서 (§28)

```
prePhysics  … WaterSolverSystem  ── 물 질량 이동과 같은 면 유량으로 물 열에너지 운반(추적자)
physics     Rapier step
postPhysics … DamageSystem
            ThermalSystem (6스텝 = 0.1 s마다)
              1. 열원 입력(구간 정적분: Δt와 무관하게 총 열량 일치)
              2. 열전달(Jacobi, 안정 조건으로 서브스텝) — 전도·대류·복사, 공기 이류
              3. 온도 갱신(E → T)
              4. 재료 물성 갱신(강도·강성 감소 계수, 최고 온도 기록)
              5. 열변형·구속 열하중
              6. 구조 API 호출(setMaterialFactor / addLoad / 보 열좌굴 fail) — 바뀐 부재만, 건물 활성화
            StructuralCollapseSystem ── 7. 재분배 라운드·파괴 이벤트(한 스텝 1회), 8. 낙하·잔해(열 노드 이동 훅)
            DebrisSystem, ParticleSystem, ExposureSystem(공기 온도 노출), MetricsSystem
render      9. 렌더링·인스펙터(읽기 전용)
```

열로 인한 파괴는 구조 엔진의 재분배 라운드에서 한 번만 일어납니다(열 시스템은 용량·하중을 바꿀 뿐 직접 삭제하지 않음; 보 열좌굴만 `fail` 1회).

### 3.4 활성 영역과 비용 원칙 (§37)

- 열원이 없으면 `env.thermal`은 휴면(배열 할당 없음, 시스템 `isActive` 거짓) — 기존 실행과 비트 단위 동일.
- 지형은 8×8 셀 타일 단위 활성: 열을 받거나 이웃 타일 경계에서 기준 온도를 벗어난 타일만 계산. 비활성 타일은 정확히 기준 온도이므로 교환 0 — **잘라낸 에너지가 없습니다**.
- 물체는 주변 공기·구획·접촉 지면이 0.05 K 이상 바뀌거나 열원을 받을 때 네트워크에 들어옵니다(그 전의 교환은 열이 공기에 남는 것일 뿐 사라지지 않음).
- 같은 설계의 건물은 그래프(공유)만 읽고, 부재 열 배열은 건물이 활성화될 때 만듭니다.

## 6. 열용량과 에너지

Q = m·c·ΔT (일정 c) / Q = m·∫c dT (온도 의존 c). 열원은 온도를 직접 정하지 않고 **에너지를 더합니다**. 테스트: 같은 1 MJ에서 질량 4배 → ΔT 1/4,
비열 작은 모래가 더 많이 오름, 강재 20 → 800 °C에 필요한 에너지 = ∫c dT(735 °C 피크 포함, c₂₀·ΔT의 1.3배 이상).

## 8. 대류

`convection.ts` (Incropera 7·9장): 수직면 Churchill–Chu, 수평면 가열 위 0.54·Ra^¼ / 0.15·Ra^⅓, 안정 0.52·Ra^⅕, 구 Churchill(1983),
평판 강제(층류 0.664·Re^½·Pr^⅓, 혼합 (0.037·Re^0.8 − 871)·Pr^⅓, Re ≤ 10⁸), 구 Whitaker, 혼합 (h_N³ + h_F³)^⅓.
지면·수면은 바람 함수 h_F = 3.0·U₂ (Watmuff 외 1977, 정지 공기 항은 자연대류 상관식으로 대체; 측정 범위 ≈ 7 m/s, 그 위는 선형 외삽 — 표시).
공기 물성은 막 온도의 Sutherland 식, c_p 일정. 같은 온도에서 순대류 0(테스트). **유동을 풀지 않습니다**(CFD 아님): 흐름은 국부 풍속과 부력으로만 나타납니다.
표면 노드와 공기 사이에 표면층 절반의 저항이 있어 표면 온도는 선형화된 균형식으로 제거됩니다.

## 9. 복사

- 표면 ↔ 주변: ε·σ·(T⁴ − T_ref⁴). **주변은 기준 온도**(태양·야간 하늘 없음) → 기준 온도의 월드는 정확히 평형.
- 점 열원 → 수열체: 흡수 = ε·P_rad·Ω/(4π), Ω = A_proj/r²(박스 투영 면적의 정확한 식, 반구로 상한).
  지면 셀은 f_rad·ε·A·cosθ/(4πr²). 아래쪽 물체가 그늘지게 하는 지면 몫은 균일하게 줄임(보수적 근사).
- 고온 구(지정 온도) → 수열체: ε·σ·(T_s⁴ − T⁴)·A_proj·(R/r)², 구 안은 F = 1 + 기체 대류(완전 잠김). 구는 흑체.
- 가시성: 모듈형 부재는 건물 둘레·열원 쪽 면만(열원이 실내면 그 층의 부재만), 그 밖 물체는 다른 건물 박스를 지붕 아래로 지나는 광선이면 그늘(8 m 격자 탐색).
- 흡수되지 않은 몫(반사 1−ε, 1 W/m² 미만으로 해석하지 않은 원거리, 하늘)은 장부의 `unresolvedRadiation`.
- **건물 사이 복사 형상계수는 계산하지 않습니다**: 데워진 표면은 주변(기준 온도)과만 복사 교환합니다(근사로 표시).

## 10. 열원

| 종류 | 경계조건 | 받는 쪽 |
|---|---|---|
| point | 열출력(W) 또는 총에너지(J); 복사 비율 f_rad (기본 0.35 — 발광 화염 20–40 %, SFPE 핸드북 대표값) | 복사: 보이는 표면(역제곱·투영면적·ε); 대류: 주변 공기층 칸 또는 실내 구획 |
| area | 출력/에너지 | 원판 안의 노출 지면·물(셀마다 균등) |
| surface | 출력/에너지 | 구 안의 모든 표면(지면·부재·물체·잔해), 면적 비례 |
| volume | 출력/에너지 | 구의 공기(공기층 칸 겹침 비율 또는 실내) |
| temperature | **지정 온도 K**(출력 아님) | 복사(형상계수)·대류로 교환, 공급/흡수 열은 경계 교환 |

열출력과 지정 온도는 다른 종류의 열원에만 있고 섞이지 않습니다. 한 열원 안에서 같은 수열체는 한 번만 나옵니다(가중치 합 ≤ 1). **연료·연소·화염은 없습니다.**

## 11. 시간 프로파일

순간(t = 0에 전부), 일정, 선형 상승(rampTime 후 일정), 펄스(주기마다 폭), 예약 켜기/끄기(구간 목록). 열원마다 "마지막으로 적분한 지역 시간"을
기억해 [그때, 지금+Δt)를 **정확히 적분**합니다 → 열원이 스텝 중간에 켜져도, Δt를 바꿔도 총 열량이 같습니다(테스트: Δt 0.1 / 0.37 / 1.3 / 5 s,
시뮬레이션에서 순간·펄스·예약 3 MJ 정확히). 에너지 입력이면 P₀ = E/∫s dt. 지정 온도는 T_ref + (T_s − T_ref)·(구간 평균 s).
시작·종료는 실험 계획의 시작 시각(절대/다른 현상 기준)과 지속 시간으로 정해집니다.

## 12. 솔버

- **고정 스텝**: ThermalSystem은 6스텝(0.1 s)마다(스텝 카운터만의 함수 — 결정론). 렌더링과 분리.
- **연산자 분할**: (1) 열원 투입 (2) **지면 스텝 1 s**(지중 전도·지표 교환·물·지면 접촉·구와 지면) (3) **빠른 교환 0.1 s**(물체·부재·구획·공기 배기·구와 물체/공기)
  (4) 공기층 이류. 지면의 시간상수는 분 단위이므로 1 s로 충분하며, 각 연산자는 에너지를 정확히 보존합니다.
- **명시적(전진 오일러) + 안정 조건**: 같은 평가에서 노드마다 ΣG/C(복사 4εσT³, 자연대류 4/3·h 등 접선 컨덕턴스)를 구해
  Δt·max > 0.9이면 같은 크기의 서브스텝으로 나눠 다시 평가합니다. **불안정한 스텝을 조용히 받아들이지 않습니다**(`substeps`, `maxRate` 보고; 테스트: 작은 물체 + 1500 K 구 → 서브스텝 > 1, 경계 온도 초과 없음).
- **Jacobi**: 모든 플럭스를 현재 상태에서 계산한 뒤 적용 → 방문 순서와 무관. 순회는 타일 오름차순·삽입 순서·부재 번호(id 아님).
- 공기 이류는 CFL 0.9 서브스텝의 풍상 차분, 얇은 물막(< 1 mm)은 바닥 표면층과 평형 처리(강성 회피).
- 벤치마크 전 장면에서 서브스텝 1(§38).

## 13. 열에너지 장부 (`ledger.ts`)

`최종 내부 에너지 = 초기 + 열원 투입 + 경계 공급 + 운석 투입 − Σ 손실` (+ 잔차). 내부 에너지는 **기준 상태 대비 현열**(초기 0).

| 항목 | 의미 |
|---|---|
| added | 열원 출력 전부(흡수되지 않은 복사 포함 — 그 몫은 손실 `unresolvedRadiation`) |
| boundarySupply | 지정 온도 구가 준(음수면 흡수한) 순열 |
| impactDeposit | 운석 열 몫 |
| lost.radiationSky / unresolvedRadiation / atmosphere / airAdvection / aboveLayer / deepGround / water / debris | 주변 복사, 미흡수 복사, 상층 배기, 월드 밖으로 이류, 공기층 위 대류·고층 열원 대류, 깊은 지중, 물 유출·배수, 월드 밖 파편 |
| transfers.* | 내부 이동 총량(전도·대류·복사·물 이류·공기 이류) |

밖으로 나간 에너지는 사라진 것이 아니라 **주변으로 간 것**으로 기록됩니다. 닫힌 계(테스트 옵션)는 상대 10⁻¹², 모든 시뮬레이션 테스트·벤치마크·브라우저 검증에서 상대 잔차 ≤ 6·10⁻¹⁴.

## 14. 지형 온도

4층 기둥(§3.1), 10×10 셀 타일 활성화(비활성 셀은 정확히 기준 → 잘린 에너지 없음). 표면·얕은 지중 구분. 건물 바닥 아래 셀은 공기·하늘과 교환하지 않고 기초·슬래브 접촉으로만.
**지형 변형(Phase 21–23)**: 열 기둥은 *현재 지표면에 붙어 있습니다* — 깎이거나 쌓여도 기둥 에너지가 그대로 남고(보존), 옮겨진 흙이 열을 가져가지는 않습니다(근사, 변형이 없으면 정확). 지면 수열체는 지형 rev가 바뀌면 다시 계산합니다.

## 15. 물 온도

- 물 셀마다 열에너지. 물 솔버가 **질량과 같은 제한된 면 부피**로 운반(풍상 온도, 서브스텝마다): 정확히 보존·유계, 흐름과 무관하게 퍼지지 않음(테스트: 경사면 하류만 데워짐, 물 질량 수지 불변).
- 유입(비·급수·경계)은 기준 온도, 침투한 물의 열은 지면 표면층으로, 배수·경계 유출은 손실로.
- 물 ↔ 공기(대류·복사 ε 0.96), 물 ↔ 바닥. 완전 혼합(수심 방향 층 없음). 1 mK 미만으로 열이 번진 셀은 타일을 깨우지 않음(열은 물에 남음).
- **끓음·증발·응축·결빙은 없습니다**: 100 °C를 넘으면 마일스톤·로그로 알리고 현열만 계속(Phase 30 결빙).
- 물 모델이 열 실행 중간에 켜져도 그때부터 0(기준)으로 결합. 열 배열이 없으면 솔버 산술 경로는 Phase 25와 같음(동일성 테스트).

## 16. 대기

**거친 공간장**(Coarse Spatial Field): 높이 H(기본 10 m)의 지표 공기층, 5 m 칸, 칸마다 완전 혼합 노드 ρ·c_p·H·A(기준 밀도, Boussinesq).
상층 대기 경계: 따뜻한 칸만 부력 속도 √(g·H·ΔT/T_ref)로 배기(계수 1의 차원 추정 — 보정된 연행 법칙 아님), 차가운 공기는 남음.
측면 경계: 유입은 기준 공기, 유출은 손실. 공기 온도와 표면 온도는 항상 별개입니다. 3-D 유동·압축성·층 안의 성층·수평 난류 확산(풍상 차분의 수치 확산 외) 없음.
건물 실내는 층마다 구획 노드(환기 0.5회/h, ASHRAE 침기 범위 0.2–1), 층이 붕괴하면 외기와 합쳐짐.

## 17. 바람 결합

풍속은 (1) 물체·부재 표면의 강제대류(국부 풍속), (2) 지면·수면 바람 함수(2 m 풍속), (3) 공기층 이류(층 중간 높이의 평균 바람)에만 쓰입니다.
**표면 대류와 온도장 이류를 구분**하며, 열 시스템은 힘을 읽지도 만들지도 않습니다(ForceLedger 중복 0, 테스트·브라우저 12).

## 18. 건물 열 모델

모듈형 건물(LOD 세분 후): 부재마다 노드(기둥·보·벽·슬래브·지붕·외장·창·문), 공유 설계·그래프는 읽기 전용, 런타임 배열은 건물별(같은 설계 두 동이 독립 — 테스트).
면 노출: 둘레 벽·창·외장은 바깥/실내 반반, 둘레 기둥 1/4 바깥, 슬래브는 위·아래 층 실내(최상층은 바깥), 지붕 바깥/실내, 기초는 지면 접촉만, 지면 슬래브는 실내 + 접촉.
두꺼운 부재는 표면층 50 mm(피복 + 철근 영역) / 내부 2노드, 강재·유리·외장·50 mm×2 이하 부재는 1노드(EN 1993-1-2 집중 열용량법; 상자 둘레 기준 노출 = EN 상자 단면계수).
**실내 ↔ 실외 구분과 구획 노드가 Phase 27(구획 화재)의 확장 지점입니다.** HVAC·실내 기류는 없습니다.

## 19. 열팽창

ΔL = ε_th(T)·L (EN 강재·콘크리트 변형률 식, 그 밖 α·ΔT). 구분: **자유 팽창**(응력 0, 인스펙터에 ΔL), **구속 팽창**(아래), **차등 팽창**(표면/내부 온도차 → 자유 휨 곡률 κ, 표시만), **접합 구속**(아래 구속도가 연결 그래프에서 나옴).
열팽창 자체는 형상을 바꾸지 않습니다(mm 단위).

## 20. 열응력

선형 탄성·1축: N_th = r·E(T)·A·Δε, r = K_s/(K_s + K_m), K_m = E·A/L.
- 기둥·내력벽: K_s = 그 위에 걸린 보들의 3EI/L³ 합(먼 끝 핀) → `addLoad`로 하중 경로에 추가(아래 부재·기초까지 전달; 이웃 기둥의 하중 감소는 미모델 — 보수적).
- 보: 양 끝 지지 기둥·벽의 3EI/h³ 직렬 → 보 축 용량(압괴·약축 오일러, 강도·강성 계수 반영) 초과(OVERLOAD 1.25) 시 원인 `thermal`(열좌굴)로 `fail`.
- 구속도는 구조가 바뀔 때(모델 structRev) 다시 계산. 슬래브 막작용·다이어프램 구속은 없음 → 골조 구속은 **하한**이 되기 쉬워(창고 기둥 r ≈ 0.001) 설정에서 **완전 구속(상한) / 자유(하한)**를 고를 수 있습니다.
- 변화가 용량의 1 %를 넘을 때만 엔진에 반영(이벤트 구동). 다축 응력·크리프·과도 변형률·폭렬은 계산·표시하지 않습니다.

## 21. 온도에 따른 강도

`setMaterialFactor(i, f)`: 기둥·벽 f = min(k_axial·N_crush, k_E·N_buckle)/min(N_crush, N_buckle), 보·슬래브·지붕 f = k_bending(RC: 표면층 온도의 철근 k_s), 기초 1.
단면 평균은 표면/내부 질량 비율의 2구역 평균(EN 1992-1-2 Annex B 구역법의 축약). 콘크리트·목재는 도달 최고 온도 기준(냉각 후 회복 없음), 강재는 현재 온도(회복).
**손상과 중복 없음**: 계수는 잔여 강도 F·(1 − 0.3·D)와 **곱**으로 조합되는 별도 값이며 손상 지수가 아닙니다(테스트: capFactor = (1 − 0.3D)·f, D 불변).
변화 0.5 % 이상일 때만 반영. 가열된 구조물이 즉시 붕괴하지 않습니다: 경하중 창고 기둥은 690 °C에서 계수 0.23까지 떨어져도 서 있습니다(진단 실행).

## 22. 열에 의한 구조 파괴

열은 부재를 삭제하지 않습니다. 순서: 열원 → 부재 온도 → 계수(+ 구속 하중) → 다음 재분배 라운드에서 **실제 하중 ≥ 감소된 용량 × 1.25**인 부재가 기존 원인(휨·축·전단)으로 파괴 → 재분배·낙하·연쇄(Phase 25).
기록의 해저드는 `thermal`(원인 사슬의 뿌리), 피해 원인 `thermal`. 실측: RC 아파트, 1100 °C 구 → 842.8 s 슬래브 휨 파괴 → 부분 붕괴 39 부재(테스트·브라우저 18).
완전 구속 창고: 190 °C 근처에서 기둥 축 파괴(열하중), 이후 보 열좌굴.

## 23. 잔해 열 상태

분리된 부재는 자기 노드를 계속 가집니다: 건물 안 낙하·정지 블록은 그 자리, Rapier 파편은 강체를 따라감, 바깥 노출로 전환.
더미에 정착/집계되면 에너지를 **더미 노드로 이동**(질량가중 온도 = 총에너지/총열용량), 유리 미세 입자·더미 없는 정착은 그 지면 셀로, 월드 밖 파편은 손실 `debris`.
테스트·브라우저: 열 붕괴 후 더미 에너지 > 0, 장부 잔차 10⁻¹⁶ 수준.

## 24. 차량·물체

차량: 차체 껍질(질량 30 %, 2 mm 강판) + 내부, 대류·복사, 자유 팽창 ΔL(인스펙터). 엔진·연료·배터리 열폭주는 없습니다. 벽(조적 2노드), 가로등·표지(강재 1노드), 레거시 건물(§2.2).
사람: 열 노드 없음 — 노출(주변 공기 온도, 받는 복사 열유속, 최고값)만, 생리 판단 없음.

## 25. 식생

나무: 잎(캐노피 질량, u 150 %) + 줄기(생목 u 50 %) 2노드, 대기 노출·가열·냉각·열관성. **발화·연소·확산은 없으며**, 온도만으로 상태가 바뀌거나 사라지지 않습니다(테스트). 최고 온도는 Phase 27 발화 판정에 쓸 수 있게 보관됩니다.

## 26. 운석·압력파

- **Phase 23 장부 확인**: 열로 분배된 항목은 없었습니다(가열·용융은 `unresolved`). 선택 입력 `thermalShare`(기본 0, 0–50 %)가 **미해결 몫에서만**(대기 결합 몫 다음) 열 `thermal`을 가져가
  충돌 순간 크레이터 반경 안 지표층에 순간 투입됩니다(`impactDeposit`). 지진·분출물·압력파 몫과 겹치지 않습니다(테스트: 분배 합 = 충돌 에너지). 0이면 열 채널이 깨어나지도 않습니다.
- 섬광은 시각 효과이며 열입력이 아닙니다. 공중 폭발(airburst)에는 열 몫을 주지 않습니다.
- **Phase 24 압력파**: 근원 소산(강한 충격파가 남긴 열)은 장부 항목으로만 남습니다 — 화구 열은 부력으로 10 m 공기층 위로 빠지며 결합 계수의 근거가 없어 **넣지 않았습니다**.

## 27. 여러 열원

모든 열원이 하나의 열 상태에 더해지고, 열원별 투입량(장부 `bySource`)과 수열체별 기여(인스펙터: 기하 epoch별 누적)를 추적합니다.
처리 순서는 (시작 시각, 스펙 자체의 정규 문자열)로 정렬 — 추가 순서·객체 id와 무관하게 비트 동일(테스트: 순서를 뒤집은 계획, 새 id로 다시 만든 장면).

## 28. 열–구조 갱신 순서

```

  pre:  … WaterSolver(열 운반)          1 열원 입력 (구간 정적분)
  physics                               2 열전달 (지면 1 s 스텝, 빠른 교환, 이류)
  post: … DamageSystem                  3 온도 갱신 (E → T, 최고 온도)
        ThermalSystem ───────────────▶  4 재료 계수 (EN)
```

ThermalSystem: reads temperature·water·airflow·poses·structure·debris, writes temperature·structure·exposure, lagged structure·debris(이번 스텝의 붕괴 결과는 다음 열 스텝에서 반영). 파이프라인 순서 검증 통과.
한 스텝에 같은 열 효과가 두 번 적용되지 않습니다: 계수·하중은 절대값과 적용값의 **차이**만 넘기고, 보 열좌굴 `fail`은 살아 있는 부재에만 1회.

## 30. 미리보기

`ThermalTools` + `ThermalPreview`: 열원 위치·범위(원판/구), 1 W/m² 도달 반경, **실행과 같은 `groundReceivers()`**로 계산한 최대 출력 때 지면 흡수 열유속 지도(로그 색, 범례),
≥ 1/5/10 kW/m² 면적, 지정 온도 경계(구), 모델 한계·가정 목록. 문서의 건물을 알고 있어 건물 바닥은 제외하고, 실내 열원이면 "그 층의 실내·부재를 데움"으로 표시합니다.
**온도 예측이 아니라 열유속 지도**라고 명시합니다(시간·재료·손실에 따라 달라짐). 물체 그늘은 실행에서만 적용됩니다(표시).

## 31. 시각화 (`rendering/thermal`, 렌더 전용)

- 온도 열지도(활성 타일): 표면(물이면 물) / 공기층 / 최고 / 기울기(K/m); **고정 °C 범위**(0–100/300/600/1200, 자동 재조정 없음), °C/K 범례; ±0.5 K는 투명 → 뜨거운·차가운(파랑) 영역만.
- 등온선 50/100/300/600 °C, 지면 전도 열유속 화살표(−λ∇T, 로그 색), 물체 표면 온도 고리, 열원 표시.
- 부재 색: 온도 / 열응력(구속 하중/용량) / 강도 계수; 세분 전 건물은 건물 노드 온도.
- 발광(glow)은 **시각 효과 전용** — 계산된 복사(적외선)는 온도 변화로만 보입니다.

## 32. 인스펙터

물체: 표면/내부 온도·초기·변화·최고, 재료, 질량·열용량, 저장 열, 대류·복사·전도·지면 접촉 열유량(W), 열원별 기여, 자유 팽창. 레거시·LOD·나무 주석.
모듈형 건물: 가열 부재 수, 가장 뜨거운 부재, 최저 강도 계수, 열 파괴, 층별 실내 온도, 구속 모델. 부재 클릭: 위 항목 + 강도 축/휨·강성 계수, 엔진 적용 계수, 열변형·ΔL, 구속도, 구속 열하중·사용률, 휨 곡률.
지면 클릭: 깊이별 4층 온도, 아래 경계, 아래로 전도 열유속, 최고 표면 온도, 덮임 여부, 물 깊이·온도, 공기층 온도, 열원별 기여. 사람: 노출.
**계산하지 않는 항목(다축 응력, 실내 복사, 증발 등)은 표시하지 않습니다.**

## 34. 원본 월드 보존

시뮬레이션은 문서 사본에서 실행되고 열 상태는 전부 런타임(`env.thermal`)에만 있습니다. 초기화하면 열 런타임이 없어지고(t = 0) 같은 조건 재실행이 비트 동일, 나가면 지문 동일(테스트, 브라우저 25·26).

## 35. 저장·불러오기

스키마 v7 유지: 열원은 실험 인스턴스(스키마 검증, 잘못되면 그 인스턴스만 제외), 열 설정은 선택 필드 `settings.simulation.thermal`(범위 밖이면 버림 → 기본값), 운석 `thermalShare`.
v1–v7 파일은 그대로 열립니다(열 설정 없음 = 기본값; 기존 실행은 열과 무관하게 동일). **실행 중간 상태 저장은 지원하지 않습니다**. 체크포인트에 필요한 열 상태 목록은 `runtimeStateManifest`
(thermalGround·thermalWater·thermalAir·thermalBodies·thermalSources·thermalLedger)에 있습니다.

## 36. Blueprint 호환성

설계도는 `BuildingDesign` 그대로, 열은 설계·그래프를 쓰지 않습니다. 같은 설계를 여러 번 배치해도 건물별 노드·LOD·구획이 독립(테스트: 한 동만 가열, 설계 JSON 불변).
회전은 건물 자세(쿼터니언)로 처리되며 복사·붙여넣기·Undo/Redo는 문서 편집이라 열과 무관합니다.

## 44. 과학적 한계

- **축약 열전달 모델**: 집중 열용량 2노드, 4층 지중 기둥, 5 m 완전 혼합 공기층. **CFD·고해상도 열유동 해석이 아닙니다.**
- 물체 내부의 3차원 온도 분포는 계산하지 않습니다. 접촉 열저항·복사 형상계수(건물 사이)는 근사하거나 생략했습니다. 실내 표면 사이 복사 없음.
- 공기층 배기 속도·환기율·복사 비율 기본값은 차원 추정/대표값이며 보정되지 않았습니다. 아스팔트 λ·잎 λ는 약한 근거.
- 구조 열응력은 1축 탄성·축약 구속(골조 강성은 하한 경향, 완전 구속은 상한). 다축 응력·크리프·과도 변형률·폭렬·접합부 열 거동·탄화(목재 단면 감소) 없음. 조적·유리 강도 저하 없음.
- 증발·끓음·응축·결빙 없음(물은 100 °C 위에서 현열만, 표시). 태양 복사·야간 냉각 없음(주변 = 기준 온도). 지형 변형이 열을 옮기지 않음.
- 레거시 건물은 구조 열 반응 없음. LOD 세분 시 2 K 이내의 온도를 균일 분배.
- **실제 건축물의 내화 성능 인증·안전성 판단에 사용할 수 없습니다.**
- 연소·화염·연기는 Phase 27, 고급 대기 순환은 Phase 29, 극한 기후·결빙은 Phase 30.
