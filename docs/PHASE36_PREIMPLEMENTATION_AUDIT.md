## 2. 데이터 모델과 연결

- 문서 `WorldDocument`(SCHEMA_VERSION 7): objects(맵), terrain(높이 f32·지표 u8·토양 u8), landscape(층), roads(네트워크), settings, scenario(earthquake·flood·experiment.instances).
  zod 스키마가 모르는 칸을 버립니다(`serialization.ts:41-60`, `roads/schema.ts:16-40`) — 새 칸은 스키마에 넣어야 하고, 옛 빌드는 그 칸을 잃습니다.
- 시뮬레이션: `SimulationController`가 문서를 읽어 런타임(지형 복사본, Rapier 높이장, 수문 격자, 엔티티 몸체)을 만들고 문서를 바꾸지 않습니다. 편집 중 문서는
  `setLocked(true)`로 잠기고 리셋하면 원래 문서로 돌아갑니다. 지형 편집은 시뮬레이션 시작 때 복사되는 최종 높이장에 이미 굽혀 있으므로 렌더 지형 = 물리
  지형입니다(예외: 획 도중 도로 메시·객체·핀은 놓을 때까지 갱신 안 됨, 변형 중 경사 도로 선분 — 부록 terrain-roads §3).
- 실행 취소(`worldStore`): 항목 = objects 맵 참조 + roads 참조 + 지형 사각 패치 + 층 패치 + 선택적 config(settings·scenario). 상한 **100개(바이트 아님)**.
  재난 배치는 **별도** 기록(`placementStore`, 상한 100)이고 Ctrl+Z는 '재난' 탭이 열려 있을 때만 그쪽을 씁니다.
- 자동 저장: 문서가 바뀔 때마다 800 ms 뒤 `localStorage['ds.autosave']`에 전체 직렬화, 실패는 조용히 무시, 탭 닫기 때 저장 없음.

## 3. 도구별 입력 소유권 (현재)

왼쪽 `pointerdown`의 순서(부록 input §0): ① 창 캡처 — `PlacementLayer`(재난 배치·핀), 지면/변형 피커(등록 순서에 따라 바뀜) → ② 캔버스 캡처 —
`MarqueeSelect`(Shift) → ③ R3F 메시 핸들러(지면 평면, 배치 레이어, 손잡이) → OrbitControls·TransformControls 자체 리스너 → ④ 창 버블 — 각 도구의
pointerup/blur, 단축키. 카메라 잠금은 `controls.enabled = false/true`를 **주인 없이** 쓰는 6곳(35.5의 PlacementLayer만 자기 잠금만 해제).

| 도로 폭 계단 | 원인 확정(#5) | 빌드 때 유도하는 테이퍼(스키마 변경 없음), 짧으면 경고 |
| v2 1000동 비용 | 벤치가 공정하지 않음(#23) | 같은 건물·겹침 없음·지진 최대 포함·워밍업·반복·교차 순서·부하 기록 |
| 최악 스텝 9.4 s | 실제는 60 스텝 묶음(#22) | 스텝 단위 계측(시스템별 분해, 상위 5개 기록) 후 원인 판단 |
| 큰 힌지 회전 접촉 | 지면만 검사, 회전 무시 | 범위·한계 문서화, 가능하면 회전 모서리로 바닥 판정 |
| 적설 프리셋 설명 | 확정(#24) | 문구 수정 + 1 s 하중 검사 유지 |
| Chrome 메모리 압박 | 35.5 `lane.sh` | 메모리 여유를 보는 순차 러너를 저장소 스크립트로 |

## 7. 구현 계획

원칙: 기존 함수를 고치거나 확장하고, 새 모듈은 빠진 부분만. v1(구조 설정 없음) 결과는 비트 동일 — 물리 결과를 바꾸는 수정은 `structure.model = 'v2'`에서만.
저장 형식은 **SCHEMA_VERSION 7 유지**, 새 칸은 모두 선택적(없으면 기존 동작) — 옛 파일은 그대로 읽히고 그대로 저장됩니다.

**36-A 입력·수명 (기반)**
- 카메라 잠금 등록부(주인 집합 → `enabled`), drei 기즈모의 직접 쓰기 무력화, 언마운트 때 자기 잠금 해제.
- 공통 제스처 세션(pointerup·pointercancel·blur·visibilitychange·Esc·버튼 확인): Esc = 취소, 창 이탈 = 확정(일관 규칙), 언마운트·시뮬레이션 시작 = 취소.
- 기즈모 Esc 취소(시작 변형 복원), `dragging` 항상 복구. 재난 배치 ↔ 편집 도구 상호 해제, 패널 닫기 = 배치 해제, 편집기 선택 시 핀 선택 해제.
- 단축키: `e.code`, 한글 조합 중 무시, 대화상자 열림 중 무시, Shift+[ ] 수정, 피커 입력 가드.

**36-B 정밀 편집**
- 트랜잭션 API(`begin/commit/cancel`, 빈 단계 없음, 드래그 중 실행 취소 거부), 실행 취소 뒤 선택 정리, 재난 배치·실험 편집을 월드 기록으로 통합(한 스택), 문서 교체 때 정리.
- 선택: Ctrl/⌘ 토글, 같은 종류, 상자 빼기, 같은 자리 재클릭으로 겹친 객체 순환, 다중 선택 객체 클릭.
- 변형: 그룹 방향 수정(쿼터니언), 월드/로컬, 축 잠금, 경계 검사, 도로 연결 재측정(움직이면 다시 붙이거나 끊음).
- 수치: 단위, 지면 위 높이, 지형 정렬, y 하한 = 지형 최저, 다중 수치 편집. 스냅 엔진(격자·지면·객체 중심/경계·건물 외곽선·도로 노드/중심선·구조 격자,
  우선순위·허용 거리·히스테리시스·표지). 정렬: 경계/피벗 기준, 같은 회전/높이/크기.
- 자동 저장: 탭 숨김/닫기 때 저장, 실패 알림, 읽기 실패 때 백업 보존·덮어쓰기 금지, 획 도중 저장 건너뜀.

**36-C 월드 제작**
- 그룹 이름(문서 `groups`), 잠금·숨기기(객체 선택 칸 — 숨김은 편집 화면만, 시뮬레이션에는 존재), 아웃라이너(검색·필터·그룹 계층·이름·눈/자물쇠·가상화), 속성 복제.
- 배치: 붙여넣기 검사, 미리보기 사유, 차량 바퀴/사람 발 접지, 단일 배치 도로 정렬, 자연물 지표·토양·물/도로 거리 조건, 숲 설정 저장·시드 재현, 차량 설정 복제.
- 지형: 브러시 예상 변화 오버레이(영향 영역·예상 Δh), 사각 링, 획 보간, 실행 취소 바이트 상한, 객체별 지면 추종 정책(문서화 + 칸), 핀 재표시, 배치 렌더 부분 갱신.
- 도로: 폭 전환 테이퍼, 지표 id 저장 수정, `sameProfile` 비대칭 수정, 스냅 라벨 일치, 교차로 연석 옆면.
- 건물: 구조 형식 선택(실제 `STRUCTURAL_TYPES` → 시스템·재료 매핑, 'light'는 외피만), 부재 종류 변경(유효할 때만)·수치 위치, 구조 격자 확인, 가새(§6), 구조 실험장 프리셋.

**36-D 물리 정합성**: 셀 충돌체(v2), 정착 파편 재활성화·주변 몸체 깨우기, 파편 순간이동 제거(v2), 층별 변위 렌더, 잔해 시각 계수, 힌지 이벤트 기록.

**36-E 통합·검증**: Chrome S1–S20 한·영(실제 마우스), 4 해상도 화면, 기존 Chrome 24종, 전체 시험, v1 동일성(35.5 기준), 결정론, 저장 호환, 성능(객체 100–5000,

## 8. 회귀 위험

- **v1 동일성**: 충돌체 교체는 Rapier 순서를 바꾸므로 v2에만. 층별 변위·잔해 시각은 렌더 전용. 도로 테이퍼는 폭이 다른 직선 접합이 있는 네트워크에서만
  굽기를 바꿈 — 골든·내장 템플릿에는 그런 접합이 없음(부록 terrain-roads §8). 실행 취소·입력 수정은 시뮬레이션 밖.
- **v2 결과**: 셀 충돌체·파편 이동 수정은 부분 붕괴가 생긴 v2 실행의 결과를 바꿉니다(의도된 수정) — 부분 붕괴가 없는 v2 실행은 그대로여야 하고 시험합니다.
- **저장**: 새 칸이 기존 파일을 바꾸지 않도록 기본값은 "없음"(직렬화에서 생략). 옛 빌드는 새 칸(그룹 이름·잠금·숨김)을 버립니다(앞 방향 호환 한계).
- **입력**: 창 캡처 순서를 바꾸면 35.5 배치(Chrome ux355 26개)가 깨질 수 있음 → 매 단계 ux355 재실행.
- **기존 Chrome 스크립트**: 선택·단축키 동작 변경이 옛 스크립트 가정과 충돌할 수 있음 → 36-E에서 24종 재실행.
